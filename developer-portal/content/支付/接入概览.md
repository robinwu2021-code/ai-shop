# 支付接入概览

Near Pay 为第三方业务系统提供服务端支付接入。请先确认接入环境、应用与门店授权，再按完整指南对接；AppSecret 和 EncryptKey 均保存在业务服务器。

## 开始接入

阅读[外部 API 接入指南](外部API接入指南.md)，按以下顺序完成接入：

1. 申请应用，确认业务范围、环境及能力。
2. 配置回调，领取并启用密钥，完成门店授权。
3. 校对请求签名、响应验签和字段加密。
4. 创建支付单、发起支付，并处理通知和查单。
5. 完成退款、异常恢复、密钥轮换及生产验收。

## 接口范围

当前开放协议为 `/open/pay/v1`，包括门店可用支付方式、创建支付单、按业务号或支付号查询、发起支付、关闭支付单、申请退款及查询退款。具体参数、scope、状态及限制见完整指南。

应用、密钥与门店授权目前由平台办理。当前开放 API 不提供匿名注册或自行申请密钥的接口。
