# 快速开始

## 准备接入信息

确定业务范围、接入环境、调用方身份和可访问的门店。接口是否存在不代表第三方已获授权。

## 选择业务文档

- [餐饮](../餐饮/接入概览.md)
- [零售](../零售/接入概览.md)
- [服务业](../服务业/接入概览.md)
- [支付](../支付/接入概览.md)

## 处理请求结果

按具体业务文档判断 HTTP 状态和业务响应码；发生超时或结果未知时，先查询原业务结果，再依该动作的幂等规则重试。不同业务的响应结构和认证方式以各自正式契约为准。

## 接口文档范围

支付业务已提供[完整外部 API 接入指南](../支付/外部API接入指南.md)及离线示例。餐饮、零售和服务业当前提供接入概览，完整第三方接口文档将按已开放范围逐步发布；未列出的接口不能据此视为第三方可用。
