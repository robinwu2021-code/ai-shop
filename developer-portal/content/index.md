# 构建你的业务连接

欢迎来到 neargo 开发者中心。按业务选择接入方向，从身份认证、请求约定到业务流程，逐步完成系统对接。

> 第一次接入？从[快速开始](接入指南/快速开始.md)了解准备事项与阅读顺序。

## 选择业务

| 业务 | 阅读入口 | 典型场景 |
| --- | --- | --- |
| 餐饮 | [餐饮接入概览](餐饮/接入概览.md) | 菜品、点餐、厨房与结账 |
| 零售 | [零售接入概览](零售/接入概览.md) | 商品、订单、库存与售后 |
| 服务业 | [服务业接入概览](服务业/接入概览.md) | 预约、工单与履约 |
| 支付 | [支付接入概览](支付/接入概览.md) | 收款、查询、退款与回调 |

## 接入路径

1. 确认所需业务能力及授权范围。
2. 获取对应环境的接入信息和测试身份。
3. 阅读该业务的认证及请求规则。
4. 在隔离环境完成业务流程和异常处理验证。
5. 完成上线前的业务验收。

## 文档使用

通过左侧目录查找文档，或按关键词搜索。接口示例中的环境地址与身份参数需要替换为获授权的实际值。
