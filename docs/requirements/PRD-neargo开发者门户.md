# neargo 开发者门户

状态：本轮用户已授权实施（2026-11-12）。

## 一 目标
餐饮、零售、服务业、支付对外文档的统一阅读入口。采用 Raneto，无在线调试。

## 二 验收条件
- AC1：复制、新增、修改、删除 Markdown 后无需构建或重启，页面和目录随请求更新。
- AC2：按实际多层目录生成导航，支持中文路径、相对 Markdown 链接、图片、表格及代码。
- AC3：首个 HTTP 响应包含正文、页面标题、描述和 canonical；提供 sitemap 和 robots。
- AC4：品牌化界面适配桌面与手机，支持页内目录与文档搜索。
- AC5：独立发布目录、无数据库、无构建流程；提供本地运行及容器部署说明。
- AC6（用户追加）：支持中英文界面及内容、对应页面切换、独立语言网址及 SEO；保留 Markdown 直接发布。

## 三 内容范围
独立 content 目录是发布真源，仅放允许公开的资料；初始提供接入概览和四行业入口，不把内部业务文档整体发布。不新增第三方业务权限或修改支付契约。全量对外 API 内容整理属于后续内容发布工作。

## 四 边界
不部署到生产，不提供开发者账号、应用申请、密钥领取或在线 API 调试。SEO 表示可抓取的 HTML 和元信息，不保证收录或排名。
