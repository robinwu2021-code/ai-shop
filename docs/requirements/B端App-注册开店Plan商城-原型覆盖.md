## 操作方式

顶部可选择 S01–S16、角色预设、三个独立权限、语言、加载状态与主题。点击手机内操作或页面地图跳转到 P01–P25；重置会清除当前演示状态。金额、门店、日期、授权与订单均为虚构数据。当前各画面并列显示，每个画面内部可滚动，不表示最终 App 的导航实现。

## 流程和情景

| 流程 | 可点击路径 | 已演示边界 |
|---|---|---|
| FL01 | P01 → P03 → P04 → P05 → P06 → P07 → P08 | FREE 先建店；资料草稿与必填 |
| FL02 | P06 选 PRO → P07 → P16 → P18/P20 | 免费店先存在；取消后仍可进工作台 |
| FL03 | P02 → P08 | 切店清报价与选购上下文；原订单不改绑 |
| FL04 | P09 → P10/P14 → P15 → P16 → P18 | 按商品演示，不含跨店购物车 |
| FL05 | P11 → P12/P15 → P16 → P18 → P11 | 有限来源累计；交付后展示累计结果 |
| FL06 | P09 → P17 → P18/P24 | 旧 Plan 折价与端包剩余分离；零元需确认 |
| FL07 | P11 → P13 | 到期/岗位/治理区别；账号与经营台保留 |
| FL08 | P19 → P20 → P21/P22/P23 | 订单、物流、申请与退款结果为本地样例 |

## 验证与限制

- `node --test scripts/tests/b-store-plan-mall-prototype.test.mjs`：覆盖 25 个锚点、16 个情景入口、开店、三个独立权限、累计示例、切店隔离、支付未知与交付分离、数字单占用、报价和停售、加载失败、语言方向。
- `python3 scripts/gen-proto-index.py --check`：登记与 25 个锚点一致，索引已重生成。
- 浏览器按 320/375/430px × 中/英/阿检查 25 个画面：页面与内容区无横向溢出、关键行无水平重叠；人工查看 320px 中文订单、430px 英文续费确认、375px 阿语深色升级页，并验证长门店名、RTL 负数方向及支付/交付分开。原生软键盘、安全区及全部状态仍需真机复核。
- 这是一份原型，商品金额、期限与状态均为本地演示；没有真实 API、支付、订单或持久化。未来排期与升级金额均为固定样例，不是可用于结算的计算器。
- 未改正式 App、后端或真实交易；既有工作区中的其他变更仍然保留。
