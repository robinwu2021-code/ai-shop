## 〇、一句话

**物流只做一件事：把「这张运单走到哪了」这个事实，准时、省钱地交给需要它的人。**
买家要看、要被通知；商家要看；交易域要拿「签收了」去提醒确认收货和自动确认；运营要能看见哪单卡住了。

三条约束贯穿全清单（用户 2026-10-09 定）：
**快递100 额度不够，只订阅不主动查** · **状态尽量找微信要，策略可配置** · **定时作业能不用就不用**。
外加一条：**多渠道** —— 圆通直连正在接，将来更多；加一家渠道不改表、不改调用方。

## 七、运单状态口径

| 状态 | 买家看到 | 进入条件 |
|---|---|---|
| `CREATED` | 已发货 | 登记 |
| `PICKED_UP` | 已揽件 | 渠道推送或微信查询给出揽收 |
| `IN_TRANSIT` | 运输中 | 在途 / 转投 / 清关 |
| `DELIVERING` | 派件中 | 派件；子状态「投柜或驿站」显示「已到驿站 / 快递柜」 |
| `DELIVERED` | 已签收 | 签收 / 代签；**终态，不会退回** |
| `EXCEPTION` | 异常 | 疑难、退回、拒签；恢复后回到原阶段 |
| `CANCELLED` | — | 发货撤回、换单号作废旧号 |
