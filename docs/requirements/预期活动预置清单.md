## 四、落库前必须补齐的参数

| 参数组 | 必填或约束 |
|---|---|
| 经营归属 | 商家主体、参与门店、币种、出资方；首期储值只允许商家出资 |
| 规则 | 选定基础玩法、精确金额/比例/商品/数量；模板文本不能当可执行规则解析 |
| 适用对象 | 商品/项目、客户群；新客口径和沉睡周期明确，不能仅凭标签名判断 |
| 时间 | 市场时区、起止或周期；生日按本人资料筛选，不默认收集额外信息 |
| 敞口 | 名额、预算、每人次数；折扣封顶、赠品库存、团/期时限按玩法必填 |
| 权益使用 | 参与范围与权益可用范围分开，尤其充值门店与余额适用门店 |
| 叠加 | 订单活动取优后用券沿既定规则；充值不得叠加订单券、积分返利 |
| 版本 | templateCode/templateVersion用于模板升级；实例发布版本与模板版本分别管理 |
| 校验 | 能力开关、角色权限、门店准入、余额/预算/库存并发、失败恢复及对账 |

JSON的exampleText仅供解释，正式seed适配器须生成经schema校验的结构化draft。缺少规则金额、时间、范围、预算等必填项时保持草稿，不凭示例文本自动创建活动。requiredCapabilities为建议能力契约，实施时映射到已有能力注册体系，不能直接当现有能力码使用。

## 五、建议预置批次

第一批：通用满减/领券/定向券、零售基础优惠、美业体验与复购券；依据已有服务逐项完成发布、使用、统计和权限验收。美业储值并行补齐活动版本/预算预留、实收入账、会员识别授权和消费记录，能力齐备再开放。

第二批：已具备团/期和履约能力的门店开放拼团/集单；赠品活动完成库存、履约和售后；多次兑换券完成余次与预约联调。餐饮、宠物、健身等按实际入驻与行业履约能力开放。

第三批：第二件优惠、秒杀库存等完成按件优惠分摊、并发及售后专项验收后开放。抽奖、砍价、助力、自动续费、付费期限会籍、平台出资储值等不纳入本清单首期seed。

模板目录升级不改已创建活动；推荐顺序可运营配置，活动规则仍需商家确认。店主可看示例和缺失能力说明，但没有能力时不能发布。归档模板不删除已成立权益。

## 六、验收与边界

1. 40个模板编号唯一，全部可回溯基础玩法与四类机制；业态只是推荐维度。
2. 全部seedEnabled=false、publishOnCreate=false；任何配置不能仅因预置自动发券、扣预算、充值或扣款。
3. 赠送兑换券与付费会员资产分开；储值本金赠金内部记账，消费者页面不展示拆分。
4. 默认储值门店按最后成功储值/核销倒序；无储值专用二维码、无线上退款、无首期线上购买入口。
5. 本轮仅静态目录校验，不声称模板已经在真实业务链路通过验收。

### 7.1 产品抽象

次数和期限是两条独立维度，不把次卡与月卡作为互斥类型：

- COUNT：总次数N，可另配有效期；例如30次游泳，90天有效。
- PERIOD_COUNT：指定有效期+总次数；例如30天内30次餐食。
- PERIOD_DAILY：指定有效期+每日上限；例如30天内每日一餐，不承诺可补领未使用日期。
- PERIOD_UNLIMITED：期限内不限总次数，仍可能有每日/时段/容量约束；本轮不预置开放，需单独核算资源及经营限制。

以上是产品模板标签，不直接替换现有CARD/VALUE/TIMES/PERIOD字段或数据库枚举。月卡必须明确是自然月还是购买/激活日起连续若干天，不能统一写成“一个月”。售前展示价格、总次数/每日次数、适用项目门店、起算与到期规则；核销记录展示项目、时间、已用及剩余次数，不涉及储值本金赠金。

### 7.2 与活动、卡券、储值的关系

产品域定义CARD商品的总售价、次数、期限及适用规则；购买走订单与现金支付；确认收款后幂等发放个人卡实例；会员资产/服务权益模块持有余次、有效期及不可变核销流水，行业服务负责预约/餐段/入场和履约。储值账户是金额资产，这里是次数或期限权益，不把次数塞进储值金额账。

活动可以给这类产品做首购优惠或赠次，但“赠送兑换券”“购买30次卡”“充值赠金额”是三个不同业务。赠次计入付费卡实例需独立权益来源明细；现有促销模板不自动取得发付费卡权限。平台运营按产品/会员资产能力审核，不能仅因活动服务支持多次兑换就宣称付费月卡已实现。

### 7.3 待补能力与范围

需要购买订单→收款→幂等发卡→预约/使用资格校验→原子扣次→核销记录的全链路；到期、每日额度、重复核销、余次并发、冻结、停业等规则需专门验收。过期剩余次数、转让、退卡/退款、爽约、跨店与取消回补的经营规则必须明确后才开放；不沿用储值“不在线退款”一句话擅自定义所有付费卡售后。

六项均为规划草案，默认关闭，不构成本期直接开发/上线承诺。赠送的多次兑换券仍保留在原40项活动目录。
