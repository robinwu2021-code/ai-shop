# 13 · 打印域规格

> 摘要层 · 更新2026-10-23 · 设计待实施。完整入口：[打印中心独立模块方案](../technical/design/打印中心-完整方案与模块封装.md)；[开发任务](../superpowers/plans/2026-10-23-print-center-implementation.md)。旧合册保留历史背景，冲突以新稿为准。

打印是独立共用业务模块：print-api提供合同、print-domain管理场景/设备/任务/模拟/导出、print-channel适配设备与PDF；先内嵌部署。订单/行业只提供可信不可变事实，不能直接依赖打印实现。

| 能力 | 目标合同 |
|---|---|
| 场景模板 | 共用9＋餐饮7＋美业4，共20场景、40份58/80mm变体；同场景同宽选择，禁止跨场景误用 |
| 订单接线 | 子单/门店事实与ORDER_PRINT_FACT_READY同事务留存，消费侧幂等，不临时读当前订单冒充历史 |
| 任务容错 | 需求→批次→单票副本→执行→证据；UNKNOWN先核实，不盲重试 |
| 补打/加印 | 新任务关联原票，保留原内容/模板/布局快照，系统标识不可删除 |
| 模拟打印 | 独立账与fixture，PASSED是预期策略通过，不算真实出纸 |
| PDF导出 | 冻结布局生成私有PDF，支持伴随打印/手工导出；READY不代表打印完成 |
| 监控通知 | 业务事实→需求→任务→设备结果对账，打印/模拟/文件结果独立 |

数据设计：22张prn_*表，另1张ord_print_fact归订单所有者；83项候选API。16项开发任务按五阶段推进，先无硬件订单/模拟/PDF闭环，再真实云端/本地执行与多行业来源。
