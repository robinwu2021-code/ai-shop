## 1. 表清单

| 表 | V2 动作 | 关键列（V2 新增加粗） |
|---|---|---|
| `ord_order` | 沿用 | order_no · user_no · 金额四列 · currency · status · pay_channel(MIXED=数据) · pay_trade_no(MIXED 时=批次引用) · pay_scene · paid_at · pay_deadline_at(线下按门店配置) · offline_confirmed_by/at |
| `ord_sub_order` | 加列 | 履约组(fulfillment/pickup/receiver/express/verify_code) · 预约三列(slot_no/at/released_at) · **booking_hold_no** · 金额组(goods/freight/discount_p/discount_m/points/**asset_deduct_minor**/weigh_adjust → pay_amount) · 结算快照四列 · status |
| `ord_item` | 加列 | 快照组(goods/sku/title/spec/category/price) · **price_hit**(解析命中,可复现) · qty · **line_kind**(PRODUCT/FEE/GIFT) · **modifier_total_minor**(冗余校验) · amount · 计量三列 · is_gift(@deprecated→GIFT) |
| **`ord_item_modifier`** | **新建** | order_item_id · group/modifier 名号快照 · price_delta(比例已折算,可负) · **ref_no**(技师资源→提成归属) |

| `ord_status_log` / `ord_after_sale` | 沿用 | 售后增策略分流（读商品 after_sale_policy），不改表 |

## 2. 领域对象与八条不变量

```
Order(markPaid 幂等/cancel/close)  SubOrder(fulfillOnPaid: SERVICE_LIKE→FULFILLING)
OrderLine(kind, modifiers, metered; amount()=price×qty+Σdelta+adjust; refundable(): GIFT=0 含 modifiers)
PaymentSet(successSum/covers)  Payment(reverse 仅一次)
PlacementPipeline: ① resolve(hit 落快照) → ② modifier 约束 → ③ 扣配额 → ④ 锁库存 → ⑤ 落快照
                   （顺序固定：先锁库存再扣配额=配额超卖回滚库存）
```

O1 行金额=price×qty+Σdelta+adjust 且≥0 ｜ O2 modifier_total 恒等明细求和 ｜
O3 FEE 无 SKU 不锁库存不称重；GIFT 恒 0 不退钱 ｜ O4 required 组下单必已满足 ｜
O5 子单 payAmount 分解各项非负 ｜ O6 settle 需 SUCCESS 之和 ≥ 应收（足额判定归调用方）｜
O7 payment 冲正仅一次，先于退款存在性检查 ｜ O8 无 resolve 命中记录的价格拒单

## 3. Service

`OrderService`(place 五步 / **markPaid 签名永不扩** / confirmOfflinePaid / applyMeteredAdjust) ·
`PaymentRecordService`(record 幂等 / reverse / **settle**：足额→逐单 MIXED 确认) ·
`CashierService`(基座收银台：openTicket→WAIT_OFFLINE_PAY 复用) ·
`AfterSaleService`(策略分流；refundLine 含 modifier)

## 4. API 增量

```
POST /biz/payments · /biz/payments/{n}:reverse · /biz/payments:settle
POST /biz/cashier/tickets · …/:pay · …/:close

GET  /biz/payments?storeNo=&from=&to=     交班/对账
```
