# 10 · 预约资源域规格

> 与 05/06 同体裁。完整带注释 DDL 在[预约资源域V2-设计规格书](../technical/design/预约资源域V2-设计规格书.md)（含**占位七张单对标**）。

## 1. 表清单

| 表 | 关键列 | 说明 |
|---|---|---|
| `mch_resource` | resource_no · store_no · **resource_type**(TABLE/STAFF/SEAT/ROOM/VEHICLE) · name · **ref_no**(STAFF=staff_no 类型化引用) · capacity · status | 可占单元；与 `mch_station`（产出路由）两表两义 |
| `mch_resource_occupation` | occupation_no · resource_no · biz_type/biz_no · occupied_at · **released_at**(NULL=活动) | **开放占用**：开台式，条件 UPDATE，同资源活动占用至多一 |
| `mch_staff` + `mch_staff_skill` | staff_no · **user_no 可空**(技师可不登录) · level_code ｜ (staff_no, goods_no) | 档案与技能；可约查询第一层过滤 |
| `mch_schedule_rule` | rule_no · resource_no?(空=门店级) · days_mask · start/end_min · **granularity_min**(寄养=1440) · **capacity**(团课=20) · valid | 规则→滚动生成（JobHandler 幂等）；改规则只动未来未占用格 |
| `mch_schedule_change_log` | action(LEAVE/ADD/CLOSE/REOPEN) · **affected_holds**(前台据此逐个改约) | 调班留痕（上收自美业） |
| `mch_appointment_slot`（既有+2 列） | + **resource_no**(NULL=门店级旧行为) · rule_no · capacity/**booked**(不存"剩余") · status(停约不删行) | **占位计数唯一真源**；booked+=n 只能条件 UPDATE |
| **`mch_booking_hold`** | hold_no · status(HELD/CONFIRMED/RELEASED/EXPIRED) · biz_ref · **expire_at**(HELD 的 TTL) · idem_key 唯一 | 一次占位的聚合根：**N 格×M 资源×n 份原子成败** |
| **`mch_booking_hold_unit`** | (hold_no, slot_no) · resource_no · **qty** · **released_at**(先标记后减数→幂等) | 回退与释放的最小单位 |

订单侧：`ord_sub_order.booking_hold_no NULL`（单时段旧径 slot_no 原样保留）。

## 2. 领域对象与不变量

```
BookingHold(聚合根: 创建即占,第 k 单元失败前 k−1 逆序还量零残留; confirm 清 TTL; release 幂等)
Slot(capacity/booked)  Resource(occupy 条件 UPDATE)  Staff  ScheduleRule(materialize 幂等)
AvailabilityCalc.query = 技能 ∩ 排班 ∩ 余量 ∩ ceil((duration+buffers)/粒度)×resource_count
```
B1 计数条件更新 ｜ B2 hold 原子零残留 ｜ B3 释放幂等 ｜ B4 HELD 有 TTL、CONFIRMED 不过期 ｜
B5 开放占用至多一活动 ｜ B6 slot/resource 同店越权闸 ｜ **B7 零时段=放行（唯一例外）** ｜
B8 重生成不动已占用 ｜ B9 appointment_at 只由时段推出 ｜ B10 STAFF 恒容量 1

## 3. Service 与 API

`ResourceService` · `StaffService` · `ScheduleService`(adjust 返回受影响占位数) ·
`BookingService`(**唯一占位判定处**；tryBook 签名不动内部走 1 格 hold) · `AvailabilityQueryService`。
端点与报文见 [09 · API 参考](./09-API参考.md) §3。
