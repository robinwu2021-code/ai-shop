# 11 · 待整理域与事项（V2 收尾路线）

状态：**规划 · 待确认** · 创建 2026-08-28
判据：V2 目标 =「一套库、一套接口、一套逻辑，多行业同时服务」。
下表按**离目标的距离**排队 —— 不是什么都值得成册：有的差一本规格书，有的差一页对齐，有的只差一张施工工单。

产出物三档：**册**（完整方案+规格书，照商品/订单/预约的双册体裁）· **页**（一页对齐说明）· **单**（施工工单/迁移清单）。
