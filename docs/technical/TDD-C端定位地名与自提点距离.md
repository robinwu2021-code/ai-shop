# TDD-C端定位地名与自提点距离

状态：已实现（2026-09-20）
档位：2（既有 VO 加字段 · 无新端点 · 无库表 · i18n）
依据：用户 2026-09-20「1，地理定位按照地图返回真实的精准数据；2，收货地址在订单中根据实际的情况进行匹配……自提点根据地理位置进行匹配附近自提点，超过距离可以提示位置远」
创建日期：2026-09-20

## 1. 实测：错在哪

**顶栏的地名不是地图给的，是我们自己小区库里那条。** 线上用龙华文体中心的**精确坐标**
（22.657907, 114.041679）调 `GET /mp/location/resolve`：

```
innermostName = "棱镜·男生公寓(清湖地铁站总店)"
place = { name: "棱镜·男生公寓(清湖地铁站总店)", source: "COMMUNITY" }
```

那个学生公寓在 256 米外，而每个聚落的覆盖圈默认 1000 米 —— 于是「站在文体中心」被判成
「在这个公寓里」，顶栏就显示它。`CommunityServiceImpl#resolve` 落进围栏那一支写着
「不再去问地名库」，`placeAt()` 只在**没落进任何围栏**时才调。

9-03 到 9-20 之间坐标还偏几公里，所以这个缺陷被归因成了「定位不准」；
精确定位开通之后偏移没了，名字仍然是错的 —— **两件事，只修了一件**。

**两个问题被同一个名字回答了**：
| 问题 | 该由谁回答 |
|---|---|
| 按哪个聚落算能不能送到、商品池怎么筛 | 聚落（`innermostNo`，围栏判定） |
| 顶栏「我在哪」 | 地图逆地理（`place`） |

## 2. 契约

- `LocationVO.place` 改为**始终来自地名库**（`PlaceResolver`，已有 geohash 缓存 + 过期后台刷新）。
  落进围栏时也问；取不到才回落到聚落名（**宁可用聚落名，不编地名**）。
  `innermostNo / innermostName / chainNos` 一字不动 —— 商品池、自提点匹配全走它们。
- `OrderVO.Sub` 末尾加 `Integer pickupDistanceM`：这一单配到的自提点离买家多远（米）。
  `-1` = 点没标坐标（存量点手填地址建的），**不是 0**（0 会显示成「0 米」，是假话）。
  仅自提类履约有值，其余为 null。

## 3. 模块

- 后端：`CommunityServiceImpl#resolve`（围栏支补 `placeAt`）· `OrderServiceImpl#preview/create`
  （把 `pickupOptions` 里配中那条的 `distanceM` 带进子单）· `OrderVO`
- 端上：`types/trade.ts`（`pickupDistanceM`）· `pages/order-confirm`
  （取货点那一行显示距离；超过阈值多一行提示）· 三语词条

## 4. 界面规则（订单页的三种履约）

| 方式 | 地址怎么用 | 超距离怎么说 |
|---|---|---|
| 快递 | 收货地址原样用 | 不判距离（跨区本来就走快递） |
| 商家自送 | 按商家自送半径校验 | **已有**：超出直接拦，`OUT_OF_DELIVERY_RANGE` |
| 自提点 | 按买家坐标匹配最近的点（已有，按距离排序） | **本次新增**：显示距离；超过 `PICKUP_FAR_M`（2 公里）多一行「离你约 X 公里，确认方便取货」 |

提示是**提醒不是闸门**：远不等于不能选（上班路上顺路取很常见），所以不拦提交。

## 5. 测试

- 后端 `LocationResolveFlowTest`（或既有定位用例）：落进围栏的坐标，`innermostName` 仍是聚落名，
  而 `place.name` 来自地名库。消融：把围栏支的 `placeAt` 去掉 → 红。
- 后端订单用例：自提单预览带 `pickupDistanceM`，且等于配中那个点的距离。
- 端上 `c-app/tests/pickup-distance.test.ts`：距离渲染；超阈值出提示、阈值内不出；
  `-1` 不显示「0 米」也不显示提示。

## 6. 风险

- 地名库第一次见到某个格子时会**同步问一次地图**，此前落进围栏是不问的 ——
  首次进入一个新小区会多一次往返（之后走缓存）。地图不可用时回落聚落名，界面不空。
- 顶栏文案会从「棱镜·男生公寓」变成真实地名，而商品仍按那个聚落筛。
  两者不一致是**对的**，但要让人看得懂：这一版先只改地名，若测下来有人困惑，
  下一版在顶栏副行补一句「按 XX 小区供货」。

- **距离只在预览下发**，没有存进订单：它是按买家此刻坐标算的，存下来下次看又该变了。
  订单详情因此不显示距离（§2 原本写的是「preview/create」，收窄为 preview）。
- 顶栏文案这一版只改地名，没有补「按 XX 小区供货」那一行副文案（§6 里说的下一版再看）。
