## 1. 结构与来源

五个一级顺序：平台设置 → 平台商城 → 客户管理 → 商户管理 → 订单中心。最终41个目标项的落点沿最新方案，缺能力时先记录缺口，不安排虚假路由。逐项来源见[审计清单](./evidence/ops-menu-batch1-20261114/audit.json)。

导航链路：ops-web/lib/nav.ts定义结构与静态权限；lib/stores/server-menu.ts加载/覆盖服务端菜单；lib/permissions.ts及perm-map.ts执行UI权限映射；PermConfigServiceImpl读取功能点授权；RolePermResolver按数据库解析真实权限，Perms.java仅为默认兜底。独立支付另由payPerm及数据域判断。
