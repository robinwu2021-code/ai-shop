# 商城上线开关与商品清单（待定值）

状态：草稿，等用户定值
创建：2026-11-05
关联：TDD-B端收款订单与商城接口对齐；B端经营 API 文档 §5

新模型（建店自动开 FREE、方案购买、商家商城）整条链路由一组开关控制。仓库里 `application.yml` 和部署模板都没有打开，所以除本机之外的环境默认全部关闭。另外，商品目录里没有可卖的东西：本机只有一个「PRO 年度（本地测试价）」。本文分两部分：
- 第一部分：上线需要打开哪些配置，按环境写；
- 第二部分：要发布哪些方案和商品，带建议值。

`【待定】` 的项由用户给值。

## 三、发布方式

- 方案：运营端「行业方案」（`/ops/industry-plans`、`/plan-publications`）编辑草稿 → 发布。
- 商品、SKU：运营端「商城商品」（`/ops/biz-mall/catalog|products|skus|sku-versions`）编辑 → 发布版本。
- 本机的测试商品不迁到其他环境，在每个环境由运营重新录入；或者确认之后由我写一份种子脚本，经运营审核后执行。

## 四、需要用户决定

1. 166 预发布和生产各打开哪些开关（第一部分里的【待定】）。生产部署本会话不做。
2. 线下收款的银行资料。
3. 开放哪些行业；餐饮和美业是否只开 FREE。
4. PRO 的价格、周期，是否开放月付；CHAIN 是否上架。
5. 硬件和套餐的具体商品与价格；含用量的套餐要等用量功能做完。
6. 商品由运营在后台录入，还是由我写种子脚本。
