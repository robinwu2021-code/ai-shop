## §1 现状与根因

### 两个问题，不是一个

**① 撞名**（用户指出的）：「我的」上两行紧挨着，都叫「证照」——

```
资质证照
证照与账户            2 张证照
```

**② 「账户」名不副实**（查证时发现的，比①更误导）：
`entities` 页**从头到尾没有账户**。模板里只有执照清单（名称 / 默认标记 / 状态 / 几家门店）、
新增按钮、两行提示 —— 一个账户字段都没有。

**真正的账户在另一页**：`payout-account`，标题「收款账户」，从「我的 · 收款设置」进。
店主为找收款账户点进「证照与账户」，里面一个账户都没有。

### 两页各自回答什么

| 页 | 回答 | 它自己的文案 |
|---|---|---|
| `qual` | **我能卖什么品类** | 「已经能卖的类目」「还不能卖的类目」「该类目需要尚未提交的资质」 |
| `entities` | **我名下有几张营业执照** | 「新增证照要交**营业执照**」「待补**执照**」 |

### 为什么当初撞上了（不要推翻这条理由）

`entities/index.vue` 的注释写着：

> 对外不叫「主体」「实体」（老板不认识那两个词），**一律叫「证照」**

避开黑话是对的，**但「营业执照」本来就不是黑话** —— 它就印在那张纸上，
而且这一页自己的正文（`footHint`、`stPending`）早就在用这个词。
所以改成「营业执照」不是推翻那条理由，是把它执行得更彻底。

### 影响面：还有两句「指路话」

改名最容易漏的不是标题，是**别处引用这个名字的句子**：

- `goods.categoryHint`：「…通过后在**「资质证照」**中查看」
- `goods.notAuthorized`：「缺少经营这一类的资质，去**「资质证照」**里补齐后再添加」

不跟着改，它们就指向一个页面上已经不存在的名字 —— 而这类错不报错、只让人找不到路。

### 明确不受影响

路由（`/pages/qualifications/index`、`/pages/entities/index` 都不动）、
端点、权限码、两页的内容与行为、`payout-account`（真正的账户页）。

## §2 方案

### 契约变更

- **i18n 词条**（改值，不增不减键）：
  | 键 | 改前 | 改后 |
  |---|---|---|
  | `entities.title` | 证照与账户 | 营业执照 |
  | `qual.title` | 资质证照 | 经营资质 |
  | `stores.qualEntry` | 资质证照 | 经营资质 |
  | `goods.categoryHint` | …在「资质证照」中查看 | …在「经营资质」中查看 |
  | `goods.notAuthorized` | 去「资质证照」里补齐 | 去「经营资质」里补齐 |
- **端点 / 库表 / 权限码 / 配置项 / 路由**：无。

### 模块设计

| 动作 | 路径 | 说明 |
|---|---|---|
| 修改 | `b-app/src/i18n/locale/{zh-CN,en,ar}.ts` | 上表五个键 ×3 语言 |
| 修改 | `b-app/src/pages.json` | 两个 `navigationBarTitleText` |
| 新增 | `b-app/tests/license-naming.test.ts` | 判据见 §5 |
| 重跑 | `python3 scripts/gen-ui-catalog.py` | CLAUDE.md：改页面标题必须重跑并一起提交 |

**不改代码注释里的旧称呼**：`entities/index.vue` 等处的注释写着「证照与账户（03 屏）」，
那是在讲历史与产品方案编号，改了反而对不上文档。只改**用户看得见的字**。

### 明确不做

- **改路由**：`/pages/entities/index` 不动。路由是内部标识，改它要连带 `ROUTES`、
  `pages.json`、界面清单、可能还有存量深链 —— 为一次改名付这个代价不值。
- **改后端 `QualificationType` 等值域**：对外叫法变了，值域不动（它与上架校验绑着）。
- **合并两页**：它们回答的是两个问题，合了反而更难找。

## §5 对账三 · 实现 → 需求（测试）

| AC | 测试方法 | 跑过 | 消融验证 |
|---|---|---|---|
| AC1/AC2 | `license-naming.test.ts#两页标题不再都含「证照」` | 待填 | 改回旧名 → 变红 |
| AC3 | `license-naming.test.ts#指路话跟着改了` | 待填 | 留一句旧名 → 变红 |
| AC4 | `license-naming.test.ts#三语都改了_没有半套` | 待填 | 只改中文 → 变红 |
| AC1/AC2 | `license-naming.test.ts#pages_json 的标题与词条一致` | 待填 | 只改 i18n 不改 pages.json → 变红 |

**判据是「全仓没有残留」而不是「新名字在」。** 只断言新名字出现，
漏改一处旧的照样全绿 —— 而漏掉的恰恰是指路话那种没人会去看的地方。
所以每条都写成**反向断言**：旧名字在端上文案里一次都不许再出现。
