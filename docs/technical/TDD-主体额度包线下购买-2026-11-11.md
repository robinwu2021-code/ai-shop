# 主体额度包线下购买 TDD

需求、边界、线上目录核对及剩余项见 [交付清单](../handoff/offline-plan-purchase-2026-11-11/README.md)。用户确认两套套餐均需支持线下付款，真实账户后补。独立Flutter仓库已接入本轮新接口；本仓旧Vue商户端不是调用方。

- 主体容量定义沿用V150/V221，不与门店行业套餐合并。报价保存时冻结容量和周期，购买单再冻结报价版本及平台收款版本。
- 一主体一笔未处置订单，requestNo在买家范围幂等；原键不同参数拒绝。付款指引仅在原付款意图持久发出后可读。
- 私有证据绑定订单/真实门店/上传人/用途，并保留媒体引用。商家申报与资金核款分离。
- ACCEPTED动作冻结运营身份、实际款项信息和受理时间；资金IO在业务事务外，只有可信MATCHED可应用容量。明确拒绝终结REJECTED并允许纠正，未知保持ACCEPTED。
- 兑现时锁主体归属、主体订阅及订单；原owner/market/套餐基线变更、删除或归属冻结转REVIEW_REQUIRED。应用和动作终结同事务，重试不延长第二次，保留override/trial_used。新试用准确记录TRIAL来源。
- 复用原资金账本和恢复任务；主体单先分流，只有对应资金记录和持久商业结果才能acknowledge，不误交商城门店履约。
- 取消仅为商家申请，运营必须持银行核查凭证对账形成关闭栅栏；明确拒绝的对账保留动作记录。
- UNMATCHED/REVIEW_REQUIRED保留占用；本轮尚无产品内退款/协商解除路径，属于发布前必须补齐的剩余功能，不允许人工改库绕过。
