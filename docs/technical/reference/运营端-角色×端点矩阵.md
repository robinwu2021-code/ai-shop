# 运营端 · 角色 × 端点可访问矩阵

> 状态：**生成物**，随代码走。
> **勿手改** —— 由 `node scripts/gen-perm-endpoint-matrix.mjs` 生成。
> 真源：`@PreAuthorize` 注解 × `Perms.ROLE_PERMS`。
> 守卫：`packages/shared/tests/ops-perm-matrix.test.ts` 比对 fixtures 里的基线。

**这份产物的用途是权限码细化改造**（[方案](../design/权限码细化-对齐清单.md)）：
阶段 A 把 16 个粗码拆成 64 个细码，做完这份矩阵应当**零 diff**。
有 diff 就说明拆的过程中改变了谁能访问什么 —— 那不是重构，是收紧或放宽。

扫到 **154** 个 `/ops` 端点，其中 **151** 个挂了判权。
