**这份产物的用途是权限码细化改造**（[方案](../design/权限码细化-对齐清单.md)）：
阶段 A 把 16 个粗码拆成 64 个细码，做完这份矩阵应当**零 diff**。
有 diff 就说明拆的过程中改变了谁能访问什么 —— 那不是重构，是收紧或放宽。
