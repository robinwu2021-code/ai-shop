## 5. 这份索引怎么维护

**数字不要手抄。** 变了就重跑对应命令：

```bash
node scripts/check-generated-docs.mjs        # 8 个生成器的产物
node scripts/check-ops-orphan.mjs            # 做了没入口
node scripts/check-ops-contract.mjs          # 画了没后端
node scripts/check-controller-cohesion.mjs   # Controller 粒度
python3 scripts/gen-ui-catalog.py --check    # 界面清单
bash scripts/check-head-compiles.sh          # 全量测试
```

六条全绿 = 这份索引里的「守卫」列都还在守。
**这份文档本身没有生成器** —— 它是注解，结论与优先级才是要维护的东西。
