## 1. 对象定义与责任

| 对象 | 定义 | 权威系统 |
|---|---|---|
| 注册账号 / Account | 登录及身份载体，可尚无经营主体、门店或支付商户 | ai-shop账号体系；其他来源按自身认证关联 |
| 经营主体 / Entity | 承担经营及资质责任的个人或组织；不是支付商户的别名 | ai-shop经营域 |
| 经营门店 / Store | 具体经营单元，关联经营主体，并可归属品牌、连锁 | ai-shop经营域 |
| 品牌 / Brand | 经营标识及品牌门店关系 | ai-shop经营域 |
| 连锁 / Chain | 门店组织及管理范围，可能涉及不同经营主体 | ai-shop经营域 |
| 平台商户 / Merchant | 支付平台内的商户，管理支付成员、支付资料及渠道账户关联 | 独立near-pay |
| 渠道商户 / Channel Merchant | 某渠道下的收款身份/MID，与平台商户不同 | 支付域及相应渠道 |
| 收款门店 / Collection Store | 支付侧收款单元；有经营来源时按正式映射关联，不替代经营门店主档 | 独立near-pay |

注册账号、经营主体、门店、品牌、连锁、平台商户、渠道MID不假设一一对应；按正式来源关联解析。源码里旧merchantNo、mch表名、MERCHANT_*角色和权限仍可能指经营主体，本轮只修订产品术语，不批量改代码字段或表名。

经营入驻审核不等于支付进件审核；品牌/连锁成员授权不等于支付成员授权；购买经营套餐不等于创建平台商户或开通收款。目录也不新增“先审批才能注册/建店”的门槛，既有分阶段准入政策继续沿用。
