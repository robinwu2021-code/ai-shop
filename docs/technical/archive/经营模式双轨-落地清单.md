### 实现时发现的三件事

| # | 事情 | 处理 |
|---|---|---|
| 1 | **资金流那一环机器比对不了** | 库里只存 `settle_account_masked`（账户掩码）没存户名。已在接口与服务注释写明「仍需人工核对」——**假装查过比不查更危险**。要机器比对得在进件时存下户名 |
| 2 | 入参 DTO 用原始类型会把校验错误变成 500 | 端上漏传时 Jackson 抛「Cannot map null into type long」，返回 10500「系统开小差」，而真因是「税额没填」。已改包装类型 |
| 3 | 一张票覆盖**该周期全部待开票的单**，不是单张 | 写测试时按单张算金额被 70005 拒收——恰好是那条校验要防的「漏了几单」 |

### 遗留

- **导出成文件由端上做**：接口给结构化数据，格式（CSV/Excel）是展示层的事。
  若要「平台盖章」级凭证（PDF + 签名），那是另一件事，不是给接口加参数能解决的
- **对账单不含收款账户**：`MerchantQueryPort` 未暴露它。少一个字段好过跨域直连
