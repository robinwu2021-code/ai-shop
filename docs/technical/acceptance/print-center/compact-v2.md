# 小票紧凑排版 V2 验收记录

2026-10-23：当前范围的软件专项验收通过。20 场景、40 个 58/80mm 内置变体更新为 `COMPACT_V2`；另外输出 2 份补打样例。历史任务继续使用冻结布局，门店已发布模板不会自动替换。

## 排版变化

- 场景标题一次，门店名居中；正文从约 11–18mm 处开始，取消 V1 固定 40mm 头区。
- 58mm 商品名称与数量金额分行，80mm 优先同行；金额按实际字体测量后右对齐，金额数字不拆断，长编号可换行。
- 删除票面的内部行号、事实号、版本号和普通初打生成时间；完整来源数据保留在冻结快照，票面保留业务号与当前小票号。
- 支付小票保留支付时间，隐藏重复下单时间；空字段与零配送费隐藏，零实付、零退款仍显示。货币单位明确显示一次，币种不一致时阻断。
- 补打、加印、原票待核实、预结未付款等中文提示保留；副本更新受控头尾信息，业务绘图坐标保持不变。
- V2 PDF 页脚只显示“PDF副本”，导出号保留在 PDF 元数据与导出任务中；V1 页脚和元数据路径保持原样。
- 页面文字预览兼容左右单元格，保留金额、分隔线和预览警示。

同一份固定支付样例，58mm PDF 高度由 **204.2mm → 118.9mm，减少 41.8%**。这是该样例的页面几何比较，不承诺所有订单相同节纸比例。

## 启用与兼容

无已发布覆盖时，内置兜底使用新布局。已有门店模板需在小票模板页面以新版基础创建并发布新版本；固定引用旧模板版本的路由，需要显式选择新版本。不会批量修改原任务或自动补打历史订单。内容容器仍使用 `PRINT_DOC_V1` 格式与 schemaVersion=1，通过 `content.layout.style=COMPACT_V2` 识别新版语义，运行任务渲染版本记为 `PRINT_DOC_V2`。

**飞鹅 V2 紧凑布局尚不可投递。** 现有飞鹅原生适配器按文本行输出，不能还原左右分栏坐标；即使旧版 `native-profile-verified=true`，也会在网络提交前明确拒绝 V2，诊断码 `print.vendorCompactLayoutUnverified`。请继续使用经过验证的 V1 已发布模板；后续完成坐标适配及实机验证后才能开启 V2 云端出纸。本轮没有把旧验证标记当作新布局兼容证明。

本地代理使用现有坐标绘图合同，PDF 与协议软件验证通过；Windows 驱动、真实 58/80mm 打印机和私有 COS 未验收。正式来源仍只有 `ORDER_PAID`，其余 19 场景仅支持模板/样例/模拟，不能据此开启生产自动打印。

本轮未自动提交、发布模板、推送或部署。改动前已有的其他业务修改和暂存内容保留。
