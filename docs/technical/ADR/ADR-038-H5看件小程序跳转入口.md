# ADR-038 H5 看件页使用微信 URL Link 唤起小程序

状态：已实施（2026-10-15）
关联：[TDD-订单状态及时同步与发货触达](../TDD-订单状态及时同步与发货触达.md) §3.5 · [TDD-收件人物流触达与分享裂变](../TDD-收件人物流触达与分享裂变.md) §4.3

## 背景

发货短信落到免登录 H5 看件页。用户需要从该页进入小程序；收件人可能从系统浏览器打开短信。现有按钮依赖 URL Link，但生产配置仍为 stub，因而从未显示。微信真接口对看件页路径返回 `40165 invalid weapp pagepath`，对既有首页路径返回成功。

## 决策

H5 通过既有匿名 `/mp/track/mini-link` 请求 URL Link。服务端验签令牌后，生成指向 `pages/home/index?trackToken=<令牌>` 的微信 URL Link；小程序首页转入 `pages/track/index?t=<令牌>`，看件页继续要求登录并核对收件手机号。体验版生成参数用 `env_version=trial`，正式版改 `release`。生成失败时 H5 仍显示物流并明确解释无法跳转，不显示无效按钮。短信短链继续以 H5 为落点。

## 后果

首页是过渡入口，增加一次小程序内部跳转；微信将来识别看件页后可改回直达。URL Link 和看件令牌有效期默认均为五天。微信生成接口的成功只能证明链接已生成，真机唤起及登录后的看件结果仍由人工联调确认。
