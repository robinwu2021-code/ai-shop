# ADR-057：主体额度包与门店套餐共用线下资金底座

2026-11-11，按用户确认的两套套餐线下购买范围实施；线上购买不接入。

主体FREE/PRO/CHAIN控制门店及员工容量，门店商城行业套餐控制选中门店数字权益。将主体额度包伪装成门店软件SKU会混淆订单归属及兑现对象，因此保留独立主体购买单，不合并权益模型。

复用已有PlatformPaymentPort、OfflineCollectionPort、PrivateEvidencePort和stl_payment唯一资金事实。报价、订单、申报、动作及证据只是商业协调记录，不建立额外资金账本，也不引入通用outbox。核款命令在IO前冻结并持久化，未知结果恢复原命令；资金明确拒绝须终结原动作，不能无限重试错误流水。

购买快照兑现与运营手工授予分开：付费单使用冻结容量及周期，来源SELF_PAID；赠送及协议调整保留原grant入口。自动购买只接受免费/到期/试用转正及同档续费，无到期协议套餐、有效付费跨档由运营协商。没有已批准折算政策时不发明价格。

已发转账指引不代表银行无款，商家取消只能发起申请；关闭必须经过运营真实银行核查和资金关闭栅栏。收款不符、已收款但权益基线变化须保留资金及审计，不自动开通或清占用；二阶段以共享OfflineCashRefundPort落实产品内异常退款/解除路径，退款协调记录不成为第二套资金账本。只根据原实收冻结全剩余可退金额，真实线下退款凭证与银行流水经资金底座核验退清后，再经原关闭对账栅栏解除占用；保留已交付权益与后续订单。运营代购保持老板受益人与运营创建者分离，不以代购绕过原主体/门店授权、价格及套餐兑现规则。见TDD和交付清单。
