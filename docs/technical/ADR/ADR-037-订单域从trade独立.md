# ADR-037 · 订单域从trade独立

状态：目标已确认，实施中；尚未完成包迁移（2026-10-14）

用户明确要求已有订单2.0从`ai.neargo.shop.trade.order`迁到`ai.neargo.shop.order`，并授权依据[开发计划](../TDD-订单重构修复与三端接线.md)实施。

当前2.0内核含118个生产文件，状态投影、写门和行级退款部分接线，查询/下单/发货/收货仍有旁路构件。直接改包名会留下旧trade实体/Mapper依赖，因此先修主链、补接线、收拢归属，再单独迁顶层包。

订单拥有支付交易聚合、门店订单、发货单、售后及其持久化、查询/写规则和作业；购物车保留trade。资金流水、分账与追偿仍属pay，库存真源属product，跨域只通过spi。订单域迁包不新增Maven模块、数据库或微服务，不重命名既有表和端点。

迁移验收必须登记order到ArchitectureTest.DOMAINS，更新Mapper扫描、资源绑定和消费者，消除order与trade直接实体/Mapper/Service依赖。HTTP/JSON兼容继续保留；旧内部Java包名不作为外部契约。新增执行数据后回退仅关闭新创建入口，保留存量处理者。

归属真源为[迁移清单](../design/order-domain-migration-map.json)。M02包迁移与金额/状态行为变更分别提交、分别验证；本ADR不批准未知供应商垫付账户、限额或新积分资金体系。
