# ADR-038 活动归核心服务权益归支付服务

状态：用户已明确模块边界，具体实施设计待评审 · 2026-10-18

## 决策依据

用户明确“权益类在支付服务，活动类在核心服务”。既有统一活动promotion以及券模板/实例都在core，不能仅将储值迁pay而继续宣称完整符合该边界。

## 决策

核心持有活动规则、版本、参与/营销预算；pay持有券和兑换券、付费次卡/月卡、金额储值的模板/实例/余额余次/发放与使用账。core商品售价和订单仍引用pay已发布权益定义，不把活动参与预算或商品库存搬进pay。

统一UI入口与服务所有权分别处理，shop-app可承载HTTP但只作门面与可信编排。模块间使用SPI、本域Outbox/Inbox与幂等分阶段协议，不跨数据源SQL或共享事务。

## 取舍与后果

pay成为权益承诺的权威方，活动下架不改变历史权益；代价是现有pmt/mkt券模板、实例和使用记录需要迁移及兼容适配。必须建立唯一owner registry和明确批次水位，既有URL可保留但不能双写。增量迁移不能修改已应用Flyway或删除历史证据。

本决策取代ADR-037中pay拥有活动规则的提案，也取代此前赠送兑换券属于core账务的归属描述；不表示首次上线日期、月卡退费条款或模板能力已获批准。
