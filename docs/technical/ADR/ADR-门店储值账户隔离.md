# ADR · 门店储值账户隔离

状态：按用户门店版范围实施。2026-10-20。

决策：复用Pay储值账户，但唯一性为租户/商家/门店/顾客/币种；充值、余额、批次、核销、冻结及原单恢复使用同一门店维度。Core提供可信商家门店资料，BFF校验权限。不同店不能共用余额；多个方案不是多个钱包。

原因：用户明确本期仅按门店整理和开发，连锁共用搁置。原代码顾客/商家/币种共用不符合此要求。

迁移：只增加结构，不清空/复制余额。store_no为NULL仅用于保留需审计的旧账户；新账户必须绑定合法门店。存在未分配账户的资金所有人由业务拒绝继续操作，避免新旧资金混用。当前联调实例只读盘点有效储值账户为0，上线前重查。

后果：旧商家维度二进制不兼容新隔离模型，存在新门店资金后不可直接回退。连锁未来另立方案，不提前建账户组/模式切换。不得修改已应用迁移。
