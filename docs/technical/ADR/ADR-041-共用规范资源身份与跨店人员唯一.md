# ADR-041 共用规范资源身份与跨店人员唯一

- 状态：沿既有多行业资源设计实施，SHR-02a基础切片
- 日期：2026-10-21
- 需求：[美业功能矩阵D](../../requirements/美业系统-多端功能矩阵.md)
- 执行：[后端开发计划§12](../TDD-美业系统-后端开发计划.md)

mch_resource归shop-merchant，零售、餐饮、美业通过shop-base的事实合同读取。
同主体同一业务人员只有一个STAFF资源号、容量1，门店归属由有效任职决定；物理ROOM/SEAT/DEVICE资源归具体门店。
不把每店任职生成独立可约容量，不以可选账号、权限角色或旧单店预约slot代替规范资源。

数据库唯一身份不随停用/软删释放，防止同一人再开资源绕过后续跨店容量仲裁；恢复和维护写流程后续明确审计。
单SQL查询只证明当时有效范围与资源属性，不证明整个时段可约，也不替代技能、班表、hold或开放占用仲裁。
openOccupied暴露阻断事实，不外传占用凭证号。代价是消费者仍须等后续排班/组合占用正式合同才能承诺预约。

BM02-a已原子建立唯一STAFF；BM02-b资源维护只接受物理类型，资源目录按当前/未来任职查询STAFF且不按任职重复。
物理资源归属和类型不可变，容量已有历史桶后冻结；不复制人员容量或重写不可变证据。完整BM-02部署仍待班表等单元完成，见[主TDD§2.13](../TDD-美业系统-后端开发计划.md)。
