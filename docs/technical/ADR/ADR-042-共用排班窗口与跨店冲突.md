# ADR-042 共用排班窗口与跨店冲突

- 状态：沿多行业方案实施SHR-01b基础切片
- 日期：2026-10-21
- 需求：[美业功能矩阵D02](../../requirements/美业系统-多端功能矩阵.md)
- 执行：[后端开发计划§13](../TDD-美业系统-后端开发计划.md)

周班表和变更历史属于共用merchant，引用同一规范resourceNo。星期掩码按ISO，规则有效日期为开始日；跨午夜与时区不能用UTC星期直接替代。
窗口按有效任职裁剪；同店同任职可合并周规则，跨店重叠或不同任职重叠拒绝，不静默任选门店或重复生成容量。
DST端点不唯一或不存在且影响查询时拒绝，不猜测真实时刻；代价是需修改规则或未来明确偏移选择合同后才能展示该窗口。

本批只提供周班表窗口和历史数据结构；P3例外审批、变更影响协调、容量桶/占用仲裁、远程接入和写维护后续交付。
排班是资源可约计算的输入，不是容量承诺；不写旧slot，不据主档当前状态重建历史排班事实。
