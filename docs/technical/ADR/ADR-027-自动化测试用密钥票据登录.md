# ADR-027 · 自动化测试用密钥票据登录

**日期**：2026-09-27 　**状态**：已采纳 　**相关**：[TDD-密钥票据免登录](../design/TDD-密钥票据免登录.md)

## 背景

要在模拟器上连真实环境跑自动化测试（建店、建商品、运营审核、清理测试数据），而登录要验证码或密码，
自动化跑不过去。用户要求：本地用密钥免登录，同时保证线上安全。

## 决定

1. 新增一种登录方式：**Ed25519 签名的一次性票据**，入口 `POST /common/auth/automation`。
2. **私钥只在本机**（仓库外），线上只放公钥。
3. 票据有效期 ≤ 60 秒，nonce 一次性；只对**配置白名单里的账号**签发会话，权限与该账号正常登录相同。
4. 总开关默认关，关着时接口 404；开着而公钥或白名单为空则拒绝启动。
5. 每次成功与失败都写登录审计。
6. 生产 App 里不加任何「跳过登录」开关；App 只在启动参数里带了票据时去换会话，没有私钥签不出有效票据。

## 为什么

- 非对称：线上配置或整台服务器泄露，也签不出票据。
- 一次性 + 短时效：日志、抓包里截到的票据没有复用价值。
- 白名单：私钥泄露时的损失上限 = 白名单里那几个测试账号，而不是全平台。

## 代价

- 多了一条认证路径，要和正常登录一起维护（会话签发抽成了共用方法，避免两条路分岔）。
- nonce 记在单个进程的内存里：多实例部署时要换成共享存储（今天是单实例）。
- 私钥丢了只能换一对；私钥泄露要立刻关开关、换公钥。

## 不适用

- 真实用户登录：不受影响，也不能用这种方式登录白名单之外的任何账号。
