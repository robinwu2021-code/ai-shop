# ADR-039：Outbox统一投递与双库适配

状态：已确认设计，实施中。日期：2026-10-19。

平台与库存分别在自己的数据库事务内写事件，共用投递协议、重试和运行器；复用 Spring 事务、执行池和生命周期调度，当前不引入 Spring Modulith。每个消费者独立记录交付进度，跨库用原始来源事件号去重。

原因：平台表无法参与库存本地事务；只抽重试函数无法解决恢复、顺序和部分消费者成功问题；改用 Modulith仍需迁移两库数据和外部动作语义。代价是每源增加顺序、逐消费者交付和运维审计表，且历史部分成功需核实后接管。

实施与验收依据：[TDD-Outbox统一投递与封装](../TDD-Outbox统一投递与封装.md)。新模式显式开启，保持前向兼容回退，不直接交给旧发送器处理新格式记录。
