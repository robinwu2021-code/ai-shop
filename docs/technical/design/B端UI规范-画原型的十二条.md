# B 端 UI 规范 · 画原型的十二条

> 状态：**摘要 · 长期有效** · 2026-08-26
> **本文不做任何决定**，它是从真源里抽出来的**画原型时的对照表**。
> 真源：`packages/shared/src/design/tokens.ts`（色/圆角/间距）·
> `packages/ui/src/styles/base.css`（设计语言与公共积木）·
> `packages/ui/src/uno.config.ts`（类名映射）· `b-app/src/App.vue`（B 端密度覆盖）

## 零、为什么要这一份

原型是给人看的，但**它是对某一套规范的承诺**。原型里出现规范里没有的圆角、
没有的字号、规范明令不用的描边，落地时前端只有两条路：
照原型写（规范破了）或照规范写（原型白画了）。两条都不该发生。

> **这份文档是被一次真实的返工逼出来的**：2026-08-26 的进销存九屏原型
> 自造了一套样式 —— 6px/8px/22px 的圆角、到处 1px 描边、9.5px 的字。
> 十二条里踩了九条，见 §四。

---

## 一、设计语言一句话

**扁平色块**：分层靠「面色 + 色块底（tint）」，**不靠描边与阴影**；
圆角偏大、留白偏松；**强调色只用于「可点」与「状态」，不用于装饰**。

## 二、十二条

页面按 **375pt** 渲染（>600px 时固定按 375 收成居中窄栏），所以 **1rpx = 0.5px**。

| # | 规矩 | 真源 | 375pt 下 |
|---|---|---|---|
| 1 | **圆角只有五档** `sm/md/lg/xl/full` | `tokens.ts radius` | 8 / 12 / 16 / 22 / 9999px |
| 2 | **不用描边、不用阴影** 分层 | `base.css` 设计语言段 | 全局几乎没有 1px 线条 |
| 3 | **间距五档** `xs/sm/md/lg/xl` | `tokens.ts spacing` | 4 / 8 / 14 / 20 / 32px |
| 4 | **字号八档** 24/26/28/30/34/40/48/**60**rpx | `base.css` 字阶段 | 12 / 13 / 14 / 15 / 17 / 20 / 24 / **30**px |
| 5 | **最小字号 12px**（24rpx） | `.sh-chip` 注释 | 再小中文笔画糊 |
| 6 | **字重只有三种**：700 只给价格，600 只给标题与按钮，其余一律 400 | `base.css` 字阶段 | —— |
| 7 | **标签用 tint 色块**（语义色 14% 底），不是描边标签 | `.sh-chip` | `padding 4/10px` · `full` |
| 8 | **按钮是胶囊**（`full`），主按钮实心，次按钮 tint 或 faint | `.sh-btn` | `padding 15px 0` · `15px/600` |
| 9 | **危险操作描边 + 墨字**，红实心只留给二次确认 | `.sh-btn--danger` | 品牌色也是红，靠形态区分 |
| 10 | **标题与内容同属一个白块**（`sh-block`），块间距 20rpx | `.sh-block` | `radius 16px` · 块间 10px |
| 11 | **B 端密度覆盖**：卡片内边距与页边距都是 24rpx，次要文字 24rpx | `b-app/App.vue` | 12px / 12px / 12px |
| 12 | **数字加 `.sh-num`**（等宽 + RTL 下强制 LTR） | `.sh-num` | 金额、结存、差异全都要 |

## 三、画原型时直接用 app 的类名

**原型用真类名，落地就是搬**；自己起名字等于让前端再翻译一遍。

| 用途 | 类名 | 要点 |
|---|---|---|
| 卡片 | `.sh-card` | 面色 + `lg` 圆角 + `--sh-pad-card` |
| 区块（标题在块内） | `.sh-block` / `.sh-block__head` | 块内横向留白 26rpx，列表行通铺到边 |
| 标签 | `.sh-chip` `--primary` `--warning` `--danger` | 无边框，tint 底 |
| 字阶 | `.txt-hero/display/price/title/strong/body/sub/caption` | 别写 `font-size` |
| 次要文字 | `.sh-muted` | 字号走 `--sh-fs-sub` |
| 按钮 | `.sh-btn` `--soft` `--muted` `--danger` `--danger-solid` | 胶囊 |
| 表单 | `.field__label` `.field__input` `.field__area` `.field__hint` | 输入 30 > 标签 26 > 说明 24 |
| 数字 | `.sh-num` | —— |
| 分栏 | `sh-tabs`（内部就是 `.sh-chip--primary` 选中） | 与内容间距 `--sh-gap-tabs` |
| 底部菜单 | `sh-tabbar` | 高 `--sh-tabbar-h` = 124rpx = 62px |

**语义色**（不随皮肤变）：`success #12b76a` · `warning #f79009` · `danger #f04438`，
tint 一律是同色 **14%** 透明底。

## 四、上一版原型踩了哪几条

如实记下来，因为下一份原型很容易再踩一遍。

| 条 | 违反的做法 | 应该是 |
|---|---|---|
| 1 | 6px / 8px / 20px / 22px / 2px / 3px 圆角 | 只用 8 / 12 / 16 / 22 |
| 2 | 卡片、标签、输入框、tab 全部 `1px solid` 描边 + 手机外壳阴影 | 面色 + tint，不描边 |
| 4·5 | 9.5px / 10px / 10.5px / 11px / 12.5px 字号 | 八档，且不小于 12px |
| 6 | 到处 `font-weight:700`（品名、数字、标题都粗） | 700 只给价格 |
| 7 | 描边 chip（`border:1px solid currentColor`） | tint 色块 |
| 8 | 按钮 8px 圆角 | 胶囊 |
| 10 | 卡片各自独立 + 标题浮在灰底上 | `sh-block`：标题收进块内 |
| 11 | 自定义 10px/11px 内边距 | 12px（B 端覆盖值） |
| 12 | 数字没有等宽 | `.sh-num` |

**没踩的三条**：9（没有画危险按钮）、3（间距碰巧接近）、以及色值本身
（取自 `tokens.ts` 的 brand × pure，这一条从一开始就照做了）。

## 五、一条给下次的判据

**画原型前先问：这个视觉元素在 `base.css` 里有没有对应的积木？**

- 有 → 用它的类名与值，一个像素都不要改
- 没有 → 先问「是不是我想复杂了」；确实需要新积木的话，
  **它属于规范的变更，要先改真源再画原型**，不能在原型里偷偷立一个

## 六、改过什么

**2026-08-26 · 字阶加了第八档 60rpx（`.txt-mega`）。**
起因是三个页面各自越过了原来的顶格 48rpx：`order` 的应收 72rpx、
`income` 与 `points` 的结存 60rpx。**三处独立走到同一个方向，说明缺的是档不是纪律** ——
那些数不是「页面上最大的字」，是商家照着它收钱、对账的数，隔着柜台一米要读准。
取 60 顺着字阶自己的顶端比例（40→48 是 1.2，48→60 是 1.25），`order` 的 72 一并收进来。
**只加这一档**：再有页面想更大，先问它是不是也属于收款台。
