## 可复现命令

仓库已有 `food-verify` profile 可把独立 channel/server 纳入同一 reactor；无需开发机器的临时聚合 POM。

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@21 \
PATH=/opt/homebrew/opt/openjdk@21/bin:$PATH \
mvn -o -f backend/pom.xml \
  -Pfood-embedded,food-verify,commerce-embedded,food-commerce-embedded,retail-commerce-embedded \
  -pl :shop-app,:food-server -am -DskipTests test-compile

# 使用忽略的本地连接配置；业务、库存和报表仍各自独立库
scripts/test-food-local-mysql.sh 'FoodLocalStockLifecycleNativeIT'
```

发布集成形态必须显式包含 FOOD/commerce 的构建 profiles，不能把默认未包含插件的普通 shop-app 包视作本批集成产物。上面是编译命令，不是云端部署命令。
