**触达频控（14.1.4）不单独成页**：它是推送前的一层闸门，放在推送任务旁边才有意义 ——
单独一页会变成"配了没人看"的设置。

**素材的分发范围（15.1.3/15.1.4）是素材行上的字段**，不是另一张表：
一份素材投给谁，和这份素材本身是一件事。

### 1.2 关键规则（mock 层强制）

**消息**
1. 触达频控：单用户单日上限 > 0、同模板最小间隔 > 0 —— 0 等于没有频控，但界面上看着像配了
2. 推送任务必须选人群，且**预估触达数 > 0** 才能发（选了个空人群等于白发一次）
3. 工单分派必须指定处理人；**已关闭工单不能再分派**
4. 代客操作要留痕（谁、对哪个订单、做了什么）—— 矩阵 P-14.2.3 的核心就是这条

**素材**
5. 素材必须指定可见范围（全部 / 指定社区 / 指定商家），不允许"没范围"
6. 指定社区/商家时列表不能为空

**系统**
7. 皮肤只能是四套之一（与 C 端 `packages/shared` 的 SKINS 同源）
8. 汇率 > 0；**基准货币（CNY）的汇率恒为 1 且不可改**
9. 灰度比例 0–100
10. 规则文案（退款 / 自提 / 称重差价）**不能为空** —— 这三条是 C 端要展示给用户看的
