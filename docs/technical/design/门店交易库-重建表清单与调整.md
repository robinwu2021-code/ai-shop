## 4 .61 上多出、定稿没有的列（2026-11-28 用户已定）

这几列与相关的表来自旧迁移 V715（POS 活动优惠）和 V718（优惠券按行分摊与退回）。定稿已用「报价 + 分摊」记每一笔优惠，所以只补一列，其余由交易代码在切库时改用定稿里已有的结构，不照搬进来。

| 旧库里的 | 定稿里的去处 | 表结构 |
|---|---|---|
| `ord_order.pos_activity_facts_version` | `ord_price_quote.schema_version` / `engine_spec_version` | 不改 |
| `ord_order.pos_member_no` | 有账号的会员用 `ord_order.user_no`；下单时的会员身份记在报价的 `facts_snapshot` | 不改 |
| `ord_order.pos_member_at_payment` | 付款时活动分摊行已核销（`status=COMMITTED`）即按会员价成交；「老数据」标记只对搬来的历史单有意义，由交易数据搬迁处理 | 不改 |
| `ord_item.coupon_share_minor` | `ord_price_quote_line.coupon_discount_minor`，或分摊表的用券行（`allocation_kind=COUPON`） | 不改 |
| `ord_after_sale_item.coupon_return_minor` | 同名列 | **补列**（已进生成器，`n_trade_v2` 已加） |
