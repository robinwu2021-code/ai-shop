# 能力开关（A4）· 实施规格

状态：**草稿 · 待确认** · 创建 2026-08-28 · 第一梯队 #3（P0 第一块砖）
上游：核心能力清单 A4 · TDD-行业包-机制与装配 §6 · ADR-020

## 1. 表（终版 DDL）

```sql
CREATE TABLE sys_industry_capability (        -- 行业预设包（平台数据）
  industry_pkg VARCHAR(32) NOT NULL,          -- RETAIL / FOOD / BEAUTY
  capability   VARCHAR(48) NOT NULL,          -- 取值域 = Capabilities 常量类，启动校验
  default_on   TINYINT NOT NULL DEFAULT 0,
  PRIMARY KEY (industry_pkg, capability)
);
CREATE TABLE mch_store_capability (           -- 门店实际。唯一被判定代码读的表
  store_no   VARCHAR(32) NOT NULL,
  capability VARCHAR(48) NOT NULL,
  enabled    TINYINT NOT NULL DEFAULT 1,
  PRIMARY KEY (store_no, capability)
);
ALTER TABLE mch_store ADD COLUMN industry_pkg VARCHAR(32) NOT NULL DEFAULT 'RETAIL';
-- ⚠️ 加列同步实体字段（MchStore.industryPkg），否则永远读出 null
```

**种子**（数据迁移）：`RETAIL` 行按[核心能力清单附表](../reference/核心能力清单.md)"零售默认"列；
`FOOD`/`BEAUTY` 行按两包 `capabilities()+requiredCapabilities()` 展开。

## 2. 判定（唯一入口，三态口径写死）

```java
public interface CoreCapabilityApi {          // SPI 已定稿，此处为实现规格
    boolean enabled(String storeNo, String capability);
    Set<String> enabledCaps(String storeNo);
}
// 实现三态：mch_store_capability 有行→按行；无行→查该店 industry_pkg 的 default_on；再无→关。
// 唯一例外：APPOINTMENT 沿用「一个时段都没开 = 放行」（不许长第二条，注释里写明出处）。
```
缓存：按 store 缓存 `enabledCaps` 结果，写路径（开关变更/改行业）主动失效；TTL 兜底 60s。

## 3. 展开与变更（唯一允许读 `industry_pkg` 的地方）

```java
class StoreProvisionService {
    /** 开店：把 sys_industry_capability(industry_pkg) 展开成 mch_store_capability 行。幂等。 */
    void provision(String storeNo);
    /** 改行业：重展开【新增缺失行】；已存在的行（含商家手动改过的）一律不动 —— 已开能力不自动关。 */
    void reprovision(String storeNo, String newIndustryPkg);
}
```

## 5. 端点（ops/biz）与闸门

```
GET/PUT /ops/stores/{storeNo}/capabilities     运营开关（留痕）
GET     /biz/store/capabilities                B 端自查（工作台按它渲染）
```
闸门：① ArchUnit —— 除 `StoreProvisionService` 外引用 `industry_pkg` 即失败；
② **两态测试模板**：每条能力开/关各一条用例，撤掉判定必须变红；
③ 种子完整性测试：`Capabilities.ALL` ⊇ 全部 `sys_industry_capability.capability`。

## 6. 施工任务
迁移（表+列+种子，注意撞号）→ 实体字段 → `Capabilities` 类 → Api 实现+缓存 → Provision 服务接入开店/改店 → 两端点+权限登记 → 三条闸门。
