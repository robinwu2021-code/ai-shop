## 这一轮改了什么方向

三次转向，按时间：

1. **诉求版**：标题写店主的诉求（「回头客再来，不抽成」「先收钱，后干活」）。
2. **中立版**：去掉口语与营销腔，改为可核对的陈述（「店铺码进店的订单，佣金 0%」「先付款，后履约」）。
3. **能力版（现行）**：首页按能力维度组织，删掉操作细节与流程说明；
   「简单」「低门槛」只作为意图，不写进文案；不作免除资质的宣称。

第 3 步之后，`site/content/README.md` §六 增加了一条规则把前两点固化下来 ——
否则下一个改文案的人会照着旧例子往回写。
