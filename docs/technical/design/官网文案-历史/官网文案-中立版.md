# 官网文案 · 中立版

**与前一版的区别只在措辞，不在信息。** 中心思想逐段沿用
[官网信息架构.md](官网信息架构.md)，事实、数字、边界一处未改。

改的是三件事：

1. **去掉口语与俏皮**：「先收钱，后干活」「账不混、货不串、人不乱看」这类靠语气取胜的句子，
   换成能直接对照系统行为的陈述。
2. **去掉营销腔**：「0 元起步」「不止一家店，不止一笔收入」这类带情绪的短语，
   换成事实描述。
3. **主语从「你」退到中性**：正文不再用「你会这样用」组织，改为「主要功能」。
   第二人称只保留在确实需要指认商家的地方（「由商家设定」）。

**代价要说清楚**：中立化之后记忆点会弱。上一版的标题冲击力来自口语和立场，
换成陈述句之后可信度上去了，但商家扫一眼记住一句话的概率下降。这是取舍。

## 2.9 怎么开店 `/how-it-works/`

> # 手机端提交申请，审核通过后上架
>
> 手机号登录即注册，选择行业与身份后提交审核。
>
> ［免费开店］［查看收费］

### 三步

1. **提交申请** —— 选择行业，再选择开店身份：**个人（无需执照）** / 个体工商户或企业（需上传执照）。可勾选「本店同时作为自提点」。
2. **平台审核** —— 人工审核。驳回会写明缺少项，可在原页补齐后重新提交，无需重填。
3. **上架经营** —— 商品审核通过后为下架状态，**由商家自行决定何时开售**。

### 收款需单独申请一次

**审核通过即可上架与接单；收款需单独提交一次申请。**
两件事分开办理。收款未通过前，工作台会持续列出待补项。
个人身份开设的门店，货款进入微信零钱，无需对公账户；多家门店可分别绑定。

### 需要准备的材料

| 个人身份 | 手机号 · 身份证。**无需营业执照，无需对公账户** |
|---|---|
| 个体工商户 | 营业执照 |
| 企业 | 营业执照 · 对公账户 |
| 特定品类 | 按类目要求的资质（如药房） |

可用身份由行业决定 —— 选定行业后，不允许的身份直接置灰，不会在填写完成后才被拒。

### 常见问题

**审核需要多久？**
人工处理。表单本身约十几分钟填写完毕，审核时长不作承诺。

**上架后无人下单？**
取决于服务范围：申请覆盖了哪些小区，仅那些小区可见该门店。

**可否先行试用？**
免费版一家门店长期免费，单店功能完整。付费档另有 14 天免费试用。

# 三、中立化之后失掉的东西

如实记一笔，便于日后判断是否要调回去。

| 失掉的 | 说明 |
|---|---|
| 首页的钩子 | 「个人也能开店」直接回答商家心里的问题；「面向社区门店的线上经营系统」是一句自我介绍，商家要读完导语才知道与自己有关 |
| 便利页的立场 | 「回头客再来，不抽成」是站在商家一边说话；「店铺码进店的订单，佣金 0%」是陈述规则，正确但不站队 |
| 自提点的转化力 | 「不卖货，也能挣钱」直接说出商家的动机；「代收按件计服务费」只说了机制 |
| 连锁页的具体 | 「账不混，货不串，人不乱看」是店主的原话；「独立收款、独立库存与权限」是系统的说法 |

**折中方案（如果需要）**：标题保留中立，导语第一句放诉求。
例如便利页 —— 标题「店铺码进店的订单，佣金 0%」，导语「你自己带来的顾客再次下单不计佣金」。
这样扫标题的人得到事实，读导语的人得到理由。
