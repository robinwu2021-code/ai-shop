## L1 · 这份怎么用

**先有清单，再开发** —— 每条写清楚：改哪个页面、调哪个接口、
**做不成会怎样**。最后一栏不是修辞：它决定这条要不要现在做。

标注含义：
- **🟢 后端已就绪** —— 接口在，纯前端工作
- **🟡 需后端配合** —— 接口还要改或新增
- **🔴 阻塞** —— 依赖通道凭证等外部条件

改完任何页面**都要重跑界面清单生成器**并提交 JSON（见 CLAUDE.md）。

## L2 · 一、b-app（商家端）

商家端缺的是**「钱的可见性」**：他最关心的两个数字
（这单我拿多少、我押的钱还剩多少）今天都看不全。

| # | 功能 | 页面 | 接口 | 就绪 | 不做会怎样 |
|---|---|---|---|:---:|---|
| **A1** | **结算单详情** | 新增 `pages/settle-detail` | `GET /biz/settle/bills/{settleNo}` | 🟢 | 只能看列表和总额，<b>点不进去看单笔怎么算的</b>（成交额 − 佣金 − 通道费 ± 补贴）。商家问「这单为什么少了」时客服也答不出 |
| **A2** | **提现申请 + 记录** | 新增 `pages/withdraw` | `GET/POST /biz/settle/withdraw` | 🟢 | 后端刚做完申请入口，<b>端上没有的话这条能力没有任何商家能触达</b> |
| **A3** | **保证金余额与流水** | 新增 `pages/deposit` | `GET /biz/deposit` · `/txns` | 🟢 | 不知道自己押了多少、冻结多少、还差多少 —— 而准入档位的限额就是按保证金算的 |
| **A4** | **渠道按区域显示** | 改 `pages/payment` | `GET /biz/merchant/pay-channel` | 🟢 | 后端 V288 已按市场筛，端上不用改也能生效；<b>要加的是把「为什么只有这几个」说清楚</b> |
| **A5** | 对账单 | 新增页 | `GET /biz/settle/statement` | 🟢 | 看不到按期汇总的账 |
| **A6** | 开票申请 + 抬头 | 新增页 | `GET/POST /biz/settle/invoices` · `invoice-title` | 🟢 | 无法为结算款申请发票 |
| **A7** | 按门店开通收款 | 改 `pages/payment` | `POST /biz/merchant/payment/store/{storeNo}` | 🟢 | 多门店商家无法给某家店单独开通 |
| **A8** | 进件驳回原因（中文） | 改 `pages/payment` | 同上，响应加字段 | 🟡 | 商家看到的是一串英文码 |

### 优先级

**A1 + A2 + A3 先做。**三条都 🟢、都不依赖后端改动，
而且它们回答的是商家每天都在问的三个问题。

A2 尤其：**后端今天刚做完，端上没有入口的话它等于没做。**

运营端与后端基本对齐，缺的是**新能力的配套界面**。

## L3 · 四、这一轮做什么

按「🟢 且不依赖别的」筛出六条，它们互不阻塞：

```
b-app     A1 结算单详情      ← 商家每天问的问题
          A2 提现申请        ← 后端刚做完，不做等于没做
          A3 保证金余额

ops-web   O3 渠道 × 区域配置  ← 不做的话区域标签只能改库
          O4 测试渠道开关与警示
          O5 提现审批显示可提余额快照
```

**C 端这一轮不动** —— 它阻塞在下单链路接网关，那是另一件事。

## L4 · 五、验收方式

前端没有后端那样的 1600 条测试，所以验收要靠别的：

| 层 | 怎么验 |
|---|---|
| 类型 | `npx vue-tsc --noEmit`（b-app / c-app）· `npx tsc --noEmit`（ops-web）。<b>`.vue` 必须用 vue-tsc</b>，`tsc` 一行都不检查 |
| 契约 | 新接口先进 `endpoints.ts`，守卫比对两边 |
| 界面清单 | `python3 scripts/gen-ui-catalog.py`，pre-push 有闸门 |
| 真实渲染 | ops-web 起 dev server 自己看一遍；b-app 用 H5 mock 验交互 |

**b-app 的原生能力（定位、相机）在 H5 mock 里验不了**，
但这六条都是纯数据页面，H5 足够。
