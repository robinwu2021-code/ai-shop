## 〇、先更正上一版的判定方法

上一版 §3.2 列了「三条真缺口」，依据是**在平台端功能清单全文里 grep 关键词、0 命中**。
这个判据是错的：那份文档比代码旧，而本仓库的规矩是**代码是事实、文档是规格**。

按代码重验之后：

| 上一版说 | 实际 |
|---|---|
| C-GD-05 搜索词干预 —— 完全没有 | 词表与运营维护面都已有；而**接到搜索这件事需求侧从没要过**，已撤回（§二） |
| C-FF-06 上门预约 —— 完全没有 | **时段已建**；爽约代码 0 处但**设计齐全**（10 篇文档，美业包 TDD 定到端点级），归属在行业包 + 门店级配置。我判「平台定」是错的，见 §三 |
| B-14.10 增值包 —— 完全没有，且涉及收钱 | **不是缺口。**`SysMerchantPlanDef` / `MchEntityPlan` / `PlanExpiryJob` / `OpsMerchantPlanController` + ops-web `plans-tab.tsx` 全部已建，运营端「档位定义」「增值包授予」两个菜单都在 |

**教训写在这里而不是脚注**：上一版 §〇 自己写着「别用平台端提没提到它当判据」，
然后 §3.2 就是那么做的。文字反查只能证明「文档没写」，不能证明「东西没有」——
两者之间隔着一份陈旧的文档。**「不存在」这种结论必须去它该在的地方看一眼**，
而那个地方是代码，不是另一篇文档。

## 二、C-GD-05 搜索词干预：撤回，这条是我编的

> ⚠️ **2026-09-09 二次更正。** 本节最初建议「给禁售词表加一列作用面、接到搜索」。
> 再查一层之后撤回 —— **需求侧从来没有要过这件事**，而它也不解决任何真实风险。

三条证据：

1. **需求矩阵里 `敏感词` 只出现在两处**：P-10.1 店招/公告合规审核、P-13.1 评价审核。
   两处都是 **UGC**（商家写的、买家写的），且**都已经建好**
   （`ServiceScopeServiceImpl` 查门店公告、`OpsBannedWordController` 维护词表）。
   搜索不在其中。
2. **C-GD-05 自己的描述**写着「社区只有三五家店、**几十个 SKU**」。
   搜索能返回的只有已过 P-3.2 审核的商品 —— 目录本身是白名单，
   搜索侧没有一个独立的治理对象。
3. **`V312__banned_word.sql` 的作者已经想过这件事**：
   「只做商品标题这一个场景，不预留 scene 列……加一列而只有一个取值，
   就是又一张『建了表没人读』的表（inv_uom 的教训）」。
   我提的正是那一列，而我给不出第二个取值的业务理由。

**已改**：C-GD-05 在三端对齐里从「定」改成「—」，
理由是「搜索结果只可能是已过审商品（P-3.2），搜索侧无独立治理对象」。


## 三、C-FF-06 上门预约：归属早就定了，是我判错了

> ⚠️ **2026-09-09 二次更正。** 本节最初写「预约域 TDD 说『留行业』、

### 设计侧已经定完的部分

`爽约` 在代码里确实 0 处（backend java / sql / shared / ops-web 全 0），
但**在文档里有 10 篇**，其中 [TDD-美业包-场景与工作流](./TDD-美业包-场景与工作流.md) 定到了实现级：

| 扣不扣次 / 扣不扣定金 **按门店规则** | 「规则问题不是技术问题」 |

### 所以要改的是判定，不是排期

我在三端对齐里把 C-FF-06 判成「定」，理由是「谁承担损失是跨商家共用规则」。
那个理由本身站得住，但**设计给了另一个同样站得住的答案**：
被浪费的是这家店自己的资源与时段，所以由门店自己配罚则更合理。
既有设计已经落到端点级，我没有理由用一句判断去推翻它。

**已改**：C-FF-06 在[三端功能对齐](../../requirements/三端功能对齐-运营端职责推导.md)
里从「定」改成「—」，理由写明归属在行业包 + 门店级配置。
判定分布随之变成 定 67 / 兜 27 / 裁 16 / — 68。

### 剩下的不是决策，是开发

### 这份文档自己的教训

初版的四条建议里，**三条是我在没有需求依据时自己推出来的「缺口」，
再查一层就全部蒸发**：一条早已实现、一条早已定好归属、一条需求侧从未要求。
唯一站住的那条（P-4），内容也从「缺处置面、要开发」缩成了「缺验收、走一遍」。

共同的形状：**我拿自己的业务判断当成了缺口的证据。**
「平台应该管 X」是一个合理的推论，但它不等于「X 没人管」——
中间隔着「去看一眼谁在管」，而那一步我三次都跳过了。
下次给方案之前，每一条「缺」都要先答上一句：**我是在哪儿查到它不存在的？**
