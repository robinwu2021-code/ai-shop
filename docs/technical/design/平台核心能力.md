# 平台核心能力

真源：`site/lib/capabilities.ts`（14 域 79 条）。本文是**能力维度的梳理**，
不是功能清单 —— 回答「这个平台在哪几个维度上是可选的」，而非「一共有多少个功能」。

措辞按陈述句写，供官网、招商材料与销售话术共用。

---

## 概览

面向社区门店的线上经营系统。支持**个人、个体工商户、企业**三种商户身份，
覆盖**零售、服务、代收、团购**四类经营模式与十余个行业，提供**六种交付方式**；
商家可加购**自有品牌微信小程序**，同时保留平台入口带来的新客。

| # | 维度 | 取值数 | 一句话 |
|---|---|---|---|
| 一 | 商户身份 | 3 | 个人身份无需营业执照，可用身份由行业决定 |
| 二 | 经营模式 | 4 | 卖货、做服务、代收货、团购，可同时进行 |
| 三 | 行业 | 十余类 | 药房等需资质品类按类目提交材料 |
| 四 | 交付方式 | 6 | 到店、上门、自提三条线，共六种具体方式 |
| 五 | 品牌与获客 | 2 条入口 | 平台入口带新客，自有入口沉淀老客，费率不同 |

## 一、支持多种商户身份

| 身份 | 需要的材料 | 收款方式 |
|---|---|---|
| **个人** | 手机号 · 身份证 | 货款进入微信零钱，无需对公账户 |
| **个体工商户** | 营业执照 | 按执照开设，可使用对公账户 |
| **企业** | 营业执照 · 对公账户 | 同上 |

- 手机号登录即注册，小程序端支持微信一键登录。
- **可用身份由行业决定**：选定行业后，不允许的身份直接置灰，不会在填写完成后才被拒。
- 收款需单独提交一次申请，与开店审核是两件事。
- 多家门店可分别绑定收款。

> 依据：能力域「开店与资质」「收款与结算」。

---

## 二、支持多种经营模式

四类可**同时进行**，同一个后台、同一批商品与订单。

| 模式 | 做什么 | 关键能力 |
|---|---|---|
| **零售** | 卖实物商品 | 多规格 SKU、门店级库存、定时截单、售罄自动下架 |
| **服务** | 到店或上门服务 | 先付款后履约、核销码、时段与地址必填、多规格定价 |
| **代收** | 承接社区自提点 | 履约总览、分拣两种视图、批量到货与批量核销、按件计服务费 |
| **团购** | 商家发起团 / 顾客求团报价 | 成团人数、截止时间、团购价、改价留痕 |

另有两种**经营规模**上的形态：

| 形态 | 说明 |
|---|---|
| **单店** | 免费版含 1 家门店，长期免费，单店功能完整 |
| **多门店 / 连锁** | 各门店独立收款、独立库存与权限，支持跨店对比，按档位订阅 |

> 依据：能力域「商品管理」「履约与物流」「自提点作业」「团购与报价」「门店与员工」。

## 三、支持多行业

生鲜果蔬 · 便利日用 · 烘焙咖啡 · 餐饮外带 · 酒水 · 花店文创 ·
药房个护 · 美业美甲 · 宠物洗护 · 家电维修 · 五金家居 · 洗衣家政 ·
社区自提点 · 多门店连锁

- **需资质品类**（如药房）按类目提交材料，有相应资质方可上架。
- 其余品类个人身份即可开设。
- 行业不仅决定可上架的类目，也决定**可用的商户身份**与**可用的交付方式**。

> 平台不按行业组织功能，按交付方式组织 —— 同一套系统，行业之间的差异体现在
> 类目、资质与交付方式的组合上。

## 四、支持到店、上门与自提

六种具体方式，按商家申请开启：

| 交付线 | 具体方式 | 说明 |
|---|---|---|
| **到店** | 到店自提 | 顾客到门店取货 |
| | 到店核销 | 服务类，顾客报码或商家扫码 |
| **上门** | 商家自送 | 按商家设定的起送价、配送费、免配送门槛与覆盖范围 |
| | 上门预约 | 服务类，预约时间与上门地址为必填项 |
| | 第三方快递 | 填写运单号 |
| **自提** | 社区自提点代收 | 由代收点核销，按件计 ¥0.30，供货方支付 |
| | 邻里自提 | 送至团购发起人处 |

配套规则：

- 逾期未取顺延一段时间后作废，作废前顾客收到提醒。
- 生鲜类支持每日定时截单，截单后的订单排入下一批。
- 一笔订单包含多家门店的商品时自动拆单，拆分后每单仅属一家。

> 依据：能力域「履约与物流」「自提点作业」。

## 五、支持自有品牌，与平台导流并行

### 自有品牌入口

按年加购。形态为**微信小程序**（`对接中`）。

| 归商家独有 | 与虹选共用 |
|---|---|
| 名称、图标、品牌 | 商品与库存 |
| 入口与二维码 | 订单与拆单 |
| 首页装修 | 履约与售后 |
| 顾客名单 | 结算与费率 |
| 自有活动 | 员工与权限 |

- 与入驻虹选不冲突，可同时开通。
- 自营类目**无需办理 ICP 经营许可证（EDI）**；平台型才需办理，通常 2–6 个月，个人身份无法办理。
- 开通流程：注册公司 → 小程序认证 → 选类目 → 配域名 → 提审 → 发布。

> **待确认：自有品牌 App。** 当前真源中自有品牌只有微信小程序一种形态，
> 没有可挂商家自有招牌的 App。仓库里的 Android 壳工程是虹选自己的顾客端与商家端，
> 不属于自有品牌能力。**在补齐之前，对外材料不写「自有品牌 App」。**

### 平台导流

两条入口并行，**费率不同**：

| 入口 | 顾客从哪来 | 佣金 |
|---|---|---|
| **商家自有渠道** | 店铺码（包装袋、小票、门口贴纸）、自有小程序 | **0%** |
| **平台入口** | 平台首页、附近发现 | **2%** |

- 费率按下单时快照，调整不追溯，三个档位一致。
- 工作台单列老客占比，显示来自扫码进店的订单数与对应少付的佣金。
- 服务范围由商家申请，仅所覆盖的小区可见该门店。

> 依据：能力域「店铺与获客」「收款与结算」「数据与报表」。

## 六、边界

对外材料里出现下列任一项，必须带角标。

| 状态 | 项 |
|---|---|
| **对接中** | 微信 / 支付宝支付通道 · 微信订阅消息 · 自有小程序开通链路 |
| **规划中** | OCR 识别 · 线上提现 · 分拣单打印导出 · 对账与客户导出 · 数据留存分档 · 专属客服通道 · iOS App |
| **待确认** | 自有品牌 App（见 §五） |

另有三条口径上的限制：

1. **不承诺审核时长** —— 审核由人工处理。可写「表单约十几分钟填写完毕」。
2. **不出现到账、提现、T+N** —— 一期只记账、线下结算。
3. **活动只有四类** —— 店铺券、满减、限时特价、买赠。模型中没有百分比折扣、没有 N 件优惠。

## 七、可直接用于官网的表述

供首页、招商页与销售话术共用。**五句话，一句一个维度。**

> **商户身份** —— 个人、个体工商户、企业均可开店。个人身份无需营业执照，货款进入微信零钱。
>
> **经营模式** —— 卖货、做服务、代收货、团购，四类可同时进行，共用同一批商品与订单。
>
> **行业** —— 生鲜、便利、烘焙、餐饮、酒水、药房、美业、宠物、维修、洗衣家政等十余类。
> 需资质品类按类目提交材料。
>
> **交付方式** —— 到店自提、到店核销、商家自送、上门预约、第三方快递、社区自提点代收，共六种。
>
> **品牌与获客** —— 可按年加购自有品牌微信小程序，顾客名单归商家；
> 平台首页与附近发现继续带来新客，两条入口费率不同。
