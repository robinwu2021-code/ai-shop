## 「算不算自己画」的判据（8 条）

这些不是建议，是 `pre-push` 上的闸门（`check-handrolled-ui.mjs`）。
**每一条都判声明不判名字** —— 按名字归类在这个仓库里误命中过十三次。

| id | 报什么 |
|---|---|
| `sheet` | 弹层 / 遮罩 |
| `sysmodal` | 系统弹框 |
| `stat` | 统计数字格 |
| `kv` | 键值行 |
| `addbtn` | ＋ 加一项按钮 |
| `candchip` | 虚线药丸 |
| `uploader` | 图片上传格 |
| `fab` | 悬浮新建按钮 |
