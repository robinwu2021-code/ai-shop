## 「算不算自己画」的判据（9 条）

| id | 报什么 |
|---|---|
| `tabs` | 分栏切换 |
| `sheet` | 弹层 / 遮罩 |
| `sysmodal` | 系统弹框 |
| `stat` | 统计数字格 |
| `kv` | 键值行 |
| `addbtn` | ＋ 加一项按钮 |
| `candchip` | 虚线药丸 |
| `uploader` | 图片上传格 |
| `fab` | 悬浮新建按钮 |
