# 一 · 总览

```
资源      mch_resource（TABLE/STAFF/SEAT/ROOM/VEHICLE，可占单元）
开放占用   mch_resource_occupation（开台式：占住直到释放）
人员      mch_staff + mch_staff_skill（可无登录账号；技能=谁能做哪个商品）
排班      mch_schedule_rule → 生成 → mch_appointment_slot（滚动，JobHandler）
时段      mch_appointment_slot（+resource_no；capacity/booked 计数真源）
占位单    mch_booking_hold + mch_booking_hold_unit（N格×M资源×n份，原子·TTL·幂等释放）
留痕      mch_schedule_change_log
```

| 左表 | 关系 | 右表 | 说明 |
|---|---|---|---|
| `mch_staff` | 1─N | `mch_staff_skill` | 谁能做哪个商品（可约查询第一层过滤） |
| `mch_staff` | 1─0..1 | `mch_resource` | `ref_no`（STAFF 行）——**类型化引用，不用 attrs 藏业务键** |
| `mch_resource` | 1─N | `mch_appointment_slot` | `resource_no` **可空 = 门店级时段（旧行为）** |
| `mch_resource` | 1─N | `mch_resource_occupation` | 开放占用（开台式，不知何时结束） |
| `mch_schedule_rule` | 1─N | `mch_appointment_slot` | 规则滚动生成（JobHandler，幂等） |
| `mch_booking_hold` | 1─N | `mch_booking_hold_unit` | **回退与释放的最小单位** |
| `mch_booking_hold_unit` | N─1 | `mch_appointment_slot` | `booked += qty`，条件 UPDATE（B1） |

# 二 · 表结构（终版完整 DDL）

约定同前两册：`id` 物理主键不对外、审计四列+乐观锁+软删+`tenant_no` 不再重复。

```sql
-- ── 资源 ──────────────────────────────────────────────
CREATE TABLE mch_resource (
  resource_no VARCHAR(32) NOT NULL,
  entity_no   VARCHAR(32) NOT NULL,
  store_no    VARCHAR(32) NOT NULL,
  resource_type VARCHAR(16) NOT NULL COMMENT 'TABLE/STAFF/SEAT/ROOM/VEHICLE（取值域 ResourceTypes）',
  name        VARCHAR(64) NOT NULL COMMENT '「A3 桌」「李师傅」「3 号床」「竹间包房」',
  ref_no      VARCHAR(32) NULL COMMENT '类型化引用：STAFF=staff_no；其余多为空。不用 attrs 藏业务键',
  capacity    INT NOT NULL DEFAULT 1 COMMENT '并发占用上限：STAFF 恒 1；ROOM 团课教室可>1（时段格容量另算）',
  attrs       JSON NULL COMMENT '展示属性（楼层/朝向），不放业务键',
  status      VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/SUSPENDED（停用不删：历史占用还指着它）',
  UNIQUE KEY uk_resource (resource_no),
  KEY idx_resource_store (store_no, resource_type, status)
) COMMENT='可占单元。与 mch_station（产出路由）两表两义，不合并';

-- ── 开放占用（开台式，不知何时结束）───────────────────
CREATE TABLE mch_resource_occupation (
  occupation_no VARCHAR(32) NOT NULL,
  resource_no   VARCHAR(32) NOT NULL,
  store_no      VARCHAR(32) NOT NULL,
  biz_type      VARCHAR(16) NOT NULL COMMENT 'CHECK(餐台)/WORK_ORDER/…（行业业务键的类型）',
  biz_no        VARCHAR(32) NOT NULL,
  occupied_at   DATETIME NOT NULL,
  released_at   DATETIME NULL COMMENT 'NULL=活动占用。释放=条件 UPDATE 置时间',
  operator      VARCHAR(64) NOT NULL,
  UNIQUE KEY uk_occupation (occupation_no),
  KEY idx_occ_resource (resource_no, released_at),
  KEY idx_occ_biz (biz_type, biz_no)
) COMMENT='占用/释放靠条件 UPDATE：同一资源活动占用至多一个（B5），转台先占后放';

-- ── 人员 ──────────────────────────────────────────────
CREATE TABLE mch_staff (
  staff_no  VARCHAR(32) NOT NULL,
  entity_no VARCHAR(32) NOT NULL,
  store_no  VARCHAR(32) NOT NULL,
  user_no   VARCHAR(32) NULL COMMENT '⚠️ 可空：技师可能根本不登录系统——硬绑账号=逼商家给每个师傅开号',
  name      VARCHAR(64) NOT NULL,
  level_code VARCHAR(24) NULL COMMENT '等级（指定加价的 Modifier 选项按它分档）',
  avatar    VARCHAR(255) NULL,
  status    VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
  UNIQUE KEY uk_staff (staff_no), KEY idx_staff_store (store_no, status)
) COMMENT='被顾客选择的人。与登录账号(mch_account)、权限角色(mch_store_role)是三件事';

CREATE TABLE mch_staff_skill (
  staff_no VARCHAR(32) NOT NULL,
  goods_no VARCHAR(32) NOT NULL,
  PRIMARY KEY (staff_no, goods_no)
) COMMENT='谁能做哪个项目。可约查询的第一层过滤';

-- ── 排班 ──────────────────────────────────────────────
CREATE TABLE mch_schedule_rule (
  rule_no     VARCHAR(32) NOT NULL,
  store_no    VARCHAR(32) NOT NULL,
  resource_no VARCHAR(32) NULL COMMENT 'NULL=门店级时段的规则',
  days_mask   CHAR(7) NOT NULL COMMENT '周一→周日 1111100',
  start_min   INT NOT NULL, end_min INT NOT NULL COMMENT '跨夜拆两条',
  granularity_min INT NOT NULL DEFAULT 30 COMMENT '格粒度；寄养按晚=1440',
  capacity    INT NOT NULL DEFAULT 1 COMMENT '每格份数：技师 1、团课 20、场次 8',
  valid_from  DATE NOT NULL, valid_to DATE NULL,
  status      VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
  UNIQUE KEY uk_schedule_rule (rule_no), KEY idx_rule_store (store_no, status)
) COMMENT='规则→滚动生成时段（提前 N 天，JobHandler，幂等）。改规则只影响未来未占用格（B8）';

CREATE TABLE mch_schedule_change_log (
  log_no    VARCHAR(32) NOT NULL,
  store_no  VARCHAR(32) NOT NULL,
  resource_no VARCHAR(32) NULL,
  action    VARCHAR(16) NOT NULL COMMENT 'LEAVE 请假/ADD 加班/CLOSE 闭店/REOPEN',
  slot_from DATETIME NULL, slot_to DATETIME NULL,
  affected_holds INT NOT NULL DEFAULT 0 COMMENT '影响的活动占位数——前台据此逐个改约，不自动取消',
  reason    VARCHAR(128) NULL, operator VARCHAR(64) NOT NULL,
  UNIQUE KEY uk_schedule_log (log_no), KEY idx_sclog_store (store_no)
) COMMENT='调班留痕（上收自 bty_schedule_log）';

-- ── 时段（既有表，目标态）─────────────────────────────
-- ALTER：加 resource_no、granularity_min；其余列沿用
CREATE TABLE mch_appointment_slot (
  slot_no   VARCHAR(32) NOT NULL,
  entity_no VARCHAR(32) NOT NULL, store_no VARCHAR(32) NOT NULL,
  resource_no VARCHAR(32) NULL COMMENT 'V2 加列：NULL=门店级（旧行为原样）',
  rule_no   VARCHAR(32) NULL COMMENT '由哪条规则生成；手工建格为空',
  start_at  BIGINT NOT NULL, end_at BIGINT NOT NULL,
  granularity_min INT NULL,
  capacity  INT NOT NULL COMMENT '本格份数',
  booked    INT NOT NULL DEFAULT 0 COMMENT '已占份数。与 capacity 两列，不存「剩余」——满格和没开过要分得开',
  status    VARCHAR(16) NOT NULL DEFAULT 'OPEN' COMMENT 'OPEN/CLOSED（停约不删行：已约的单还指着它）',
  UNIQUE KEY uk_slot (slot_no),
  UNIQUE KEY uk_slot_grid (store_no, resource_no, start_at),
  KEY idx_slot_query (store_no, resource_no, status, start_at)
) COMMENT='占位计数唯一真源。booked+=n 只能条件 UPDATE（B1）';

-- ── 占位单（V2 核心新增）──────────────────────────────
CREATE TABLE mch_booking_hold (
  hold_no   VARCHAR(32) NOT NULL,
  store_no  VARCHAR(32) NOT NULL,
  status    VARCHAR(16) NOT NULL COMMENT 'HELD/CONFIRMED/RELEASED/EXPIRED（图见 §三）',
  biz_type  VARCHAR(16) NULL COMMENT '确认时回填：APPOINTMENT/ORDER/SESSION…',
  biz_no    VARCHAR(32) NULL,
  expire_at DATETIME NULL COMMENT 'HELD 的 TTL；CONFIRMED 置空（B4）',
  idem_key  VARCHAR(64) NOT NULL,
  operator  VARCHAR(64) NOT NULL,
  UNIQUE KEY uk_hold (hold_no), UNIQUE KEY uk_hold_idem (idem_key),
  KEY idx_hold_expire (status, expire_at), KEY idx_hold_biz (biz_type, biz_no)
) COMMENT='一次占位的聚合根。N格×M资源×n份原子成败（B2）';

CREATE TABLE mch_booking_hold_unit (
  hold_no  VARCHAR(32) NOT NULL,
  slot_no  VARCHAR(32) NOT NULL,
  resource_no VARCHAR(32) NULL,
  qty      INT NOT NULL DEFAULT 1 COMMENT '本格占几份：团课报名=1、拼场 n 人=n、包场=余量全部',
  released_at DATETIME NULL COMMENT '先标记后减数 → 释放幂等（B3/9）',
  PRIMARY KEY (hold_no, slot_no)
) COMMENT='回退与释放的最小单位';
```

**订单侧加列**：`ord_sub_order.booking_hold_no VARCHAR(32) NULL`（单时段旧径 `appointment_slot_no` 原样保留）。

# 三 · 状态机

> 用表格而非状态机图：本仓库为 mermaid 丢过图（写错一个字符整张图静默不渲染、不报错，`doc-standard.test.ts` 有闸）；
> 且状态迁移表与代码里的 `Map<状态, Set<可达状态>>` 同形，逐行可核。

**占位单**（`mch_booking_hold.status`）

| 从 | 可迁移到 | 触发 |
|---|---|---|
| `HELD` | `CONFIRMED` · `RELEASED` · `EXPIRED` | 确认（清 TTL）/ 主动释放 / **TTL 到期（Job 逐单元还量）** |
| `CONFIRMED` | `RELEASED` | 取消 / 爽约 / 退款 |
| `RELEASED` `EXPIRED` | —— | 终态 |

**开放占用**无状态机：`released_at IS NULL` = 活动中，一列 + 条件 UPDATE（B5：同一资源活动占用至多一个）。
**时段格**无状态机：`OPEN`/`CLOSED` 两态 + 计数。
**行业的预约单/工单状态永不进本域。**
开放占用无状态机：`released_at NULL=活动`，一列 + 条件 UPDATE。
时段格无状态机：`OPEN/CLOSED` 两态 + 计数。**行业的预约单/工单状态永不进本域。**

# 四 · 领域对象

```java
// ── 聚合根 BookingHold（全系统唯一占位判定处）─────────
class BookingHold {
    HoldNo no; StoreNo store; HoldStatus status;
    List<HoldUnit> units;                       // 格×资源×份
    Optional<BizRef> biz; Optional<Instant> expireAt; IdemKey idem;
    // 创建即占：对每个 unit 条件 UPDATE booked+=qty，第 k 个失败 → 前 k−1 逆序还量，零残留（B2）
    void confirm(BizRef ref);                   // 置 CONFIRMED、清 TTL
    void release(Reason r);                     // 幂等：unit 先标 released_at 再减数（B3）
}
record HoldUnit(SlotNo slot, Optional<ResourceNo> resource, int qty, Optional<Instant> releasedAt) {}

// ── 聚合根 Slot / Resource / Staff / ScheduleRule ─────
class Slot { SlotNo no; StoreNo store; Optional<ResourceNo> resource;
             TimeRange range; int capacity; int booked; SlotStatus status; }
class Resource { ResourceNo no; ResourceType type; Optional<RefNo> ref; int capacity;
                 Occupation occupy(BizRef ref, Operator op);   // 条件 UPDATE，同资源活动占用至多一（B5）
                 void release(OccupationNo no); }
class Staff { StaffNo no; Optional<UserNo> account; LevelCode level; Set<GoodsNo> skills; }
class ScheduleRule { RuleNo no; Optional<ResourceNo> resource; DaysMask days;
                     TimeWindow window; int granularityMin; int capacity; DateRange valid;
                     List<Slot> materialize(LocalDate day); }   // 幂等生成；不触已占用（B8）

// ── 领域服务 ─────────────────────────────────────────
class AvailabilityCalc {
    /** 可约查询：技能 ∩ 排班 ∩ 余量 ∩ (duration+buffer 折算格数×resource_count) */
    List<SlotView> query(StoreNo s, GoodsNo g, Optional<StaffNo> staff, LocalDate day);
    int spanUnits(ServiceTrait t, int granularity);   // ceil((duration+buffers)/granularity)
}
class BookingInvariants { /* B1–B10 集中于此 */ }
```

# 五 · Service 层（完整签名）

```java
public interface ResourceService {                       // biz
    ResourceVO upsert(UpsertResourceCmd cmd);
    List<ResourceVO> list(String storeNo, String type);
    OccupationVO occupy(String resourceNo, BizRef ref, String operator);   // 开台/转台（先占后放由调用方编排）
    void releaseOccupation(String occupationNo, String operator);
}
public interface StaffService {                          // biz（STAFF_PROFILE 能力）
    StaffVO upsert(UpsertStaffCmd cmd);
    void bindSkills(String staffNo, Set<String> goodsNos);
    List<StaffVO> canServe(String storeNo, String goodsNo);
}
public interface ScheduleService {                       // biz（STAFF_SCHEDULE 能力）
    RuleVO upsertRule(RuleCmd cmd);
    GenerateResult generateAhead(String storeNo, int days);        // JobHandler 滚动调，幂等
    AdjustResult adjust(AdjustCmd cmd);                  // 请假/加班/闭店：改未来未占用格 + 留痕 + 返回受影响占位数
}
public interface BookingService {                        // ★ 唯一占位判定处
    HoldResult hold(HoldCmd cmd);
    /* HoldCmd 两种形态：
       bySlots(slotNos×qty)                    显式格清单（团课报名、拼场）
       bySpan(storeNo, resourceNos[], startAt, spanMin, qty)   由跨度折算覆盖格（美业连占） */
    void confirm(String holdNo, BizRef ref);
    void release(String holdNo, String reason);
    int expireDue();                                     // JobHandler：HELD 过期逐单元还量
    // 兼容：AppointmentSlotPort.tryBook/release 签名不动，内部改走 1 格 hold
}
public interface AvailabilityQueryService {              // 读（mp/biz 共用）
    List<SlotViewVO> slots(SlotQuery q);                 // storeNo+goodsNo(+staffNo)+date：四输入一次算完
    DayScheduleVO daySchedule(String storeNo, LocalDate d);   // 资源×格×占用的排程视图（B 端）
}
```

**跨域**：行业经 `CoreBookingApi/CoreResourceApi/CoreStaffApi`；
商品域供 `ServiceTrait`（时长/缓冲/资源类型与数量）；订单确认时 `confirm(ORDER, orderNo)`、
取消/退款时 `release`；基座对行业只发事件：`hold.expired`、`schedule.adjusted(affectedHolds)`。

# 六 · API

```
# 资源与人员（biz）
GET/POST /biz/resources                      资源 CRUD（TABLE/STAFF/SEAT/ROOM/VEHICLE）
POST /biz/resources/{no}:occupy|:release     开放占用（开台/结台/转台由行业编排先占后放）
GET/POST /biz/staffs                         人员档案
PUT  /biz/staffs/{no}/skills                 技能绑定

# 排班（biz）
GET/POST /biz/schedule-rules
POST /biz/schedule-rules:generate            手动补生成（日常由 Job）
POST /biz/schedule:adjust                    请假/加班/闭店 → 返回受影响占位数
GET  /biz/schedule/day?date=                 排程视图（资源×格×占用）

# 时段与占位
GET  /mp/booking/slots?storeNo=&goodsNo=&staffNo=&date=    可约查询（对 C 端）
GET  /biz/stores/{storeNo}/appointment-slots               既有，沿用
POST /biz/bookings:hold                      { bySlots | bySpan, qty, ttlSec, idemKey }
POST /biz/bookings/{holdNo}:confirm          { bizType, bizNo }
POST /biz/bookings/{holdNo}:release          { reason }
```

报文示例 —— **美业双人 90 分钟**：
```jsonc
POST /biz/bookings:hold
{ "bySpan": { "storeNo":"S1", "resourceNos":["RES-07","RES-12"],
              "startAt":"2026-08-29T14:00", "spanMin":105 },      // 90 服务 + 15 清洁
  "qty":1, "ttlSec":900, "idemKey":"appt-x1" }
→ { "holdNo":"H-88", "units":8, "expireAt":"…14:15" }             // 4 格 × 2 资源，原子
```

# 七 · 行业数据对标（五张占位单）

| 场景 | HoldCmd | units | 说明 |
|---|---|---|---|
| **美业·双人 90min** | bySpan 2 资源 ×105min（粒度 30） | 4 格 ×2 = **8**，qty=1 | 第 5 单元失败 → 前 4 逆序还量，零残留 |
| **餐饮·包间预定** | bySpan ROOM ×120min | 4，qty=1 | 到店 confirm → 转开放占用（开台），hold release |
| **健身·团课报名** | bySlots [周三 19:00 格]，qty=1 | 1 | 格 capacity=20 由排班规则生成；第 21 人 FULL |
| **剧本杀·拼场 3 人 / 包场** | bySlots [场次格]，qty=3 / qty=余量 | 1 | 同一格混拼；包场=占满剩余份数 |
| **宠物·寄养 6 晚** | bySpan VEHICLE?→ROOM ×6×1440min（粒度 1440） | 6，qty=1 | 日期区间=天粒度连占，零新机制 |
| **零售·预约自提**（旧径） | tryBook（内部 1 格 hold） | 1 | 存量行为逐字节不变 |
| **餐饮·开台**（开放占用） | occupy(TABLE, CHECK/chk-A3) | — | 无格无 TTL；转台=先 occupy 新桌再 release 旧桌 |
