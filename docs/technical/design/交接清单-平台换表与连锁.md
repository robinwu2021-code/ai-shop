## 5 环境与坑

| 事 | 做法 |
|---|---|
| 跑后端测试 | **一定带 `-am`**：`mvn -q -o -pl shop-app -am test -Dtest=...`；不带会用旧 jar，表现为启动失败或「构造器找不到」 |
| 要 MySQL 9 的测试（收款 `PAYMENT_SSE_*`、商城审批 `COMMERCE_MYSQL_*`） | 只认 `jdbc:mysql://127.0.0.1:3308/?...`。本机 MySQL 9.7.4 在 3306：起一个 3308 → 3306 的 TCP 转发（几行 Python，见本会话做法）即可，`root` 空口令；跑完关掉。若本机已有容器 `ai-shop-mysql97` 映射在 3308，直接用它（`root` 口令见容器环境变量） |
| 推 v2 前 | `git fetch` + `git rebase origin/v2`；`node scripts/check-generated-docs.mjs` **单独看返回码**（别接在管道里，失败会被吞掉）；过期就跑对应生成器单独提交 |
| 推送 | `git push --no-verify origin HEAD:v2`，每次推送要用户明说 |
| 本机演练库 | `prd_rh_trade`、`prd_rh_member`（商品搬迁演练）；源 `ai_shop_uni_up` |
