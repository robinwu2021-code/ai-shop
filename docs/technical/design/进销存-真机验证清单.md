## 「需要人来点」这个前提是错的

本文此前的抬头写着「待人工执行 —— 需要商家账号登录，写这份清单的人没有」，
于是它挂了一整天。**而真机一直用 USB 连着，一条命令就能看见：**

```bash
ADB=/opt/homebrew/share/android-commandlinetools/platform-tools/adb
$ADB devices -l          # e7d0764c  device usb  model:2510DRK44C
$ADB -s <serial> install -r ~/Downloads/虹选商家-0.4.37-164.apk
$ADB -s <serial> shell input tap <x> <y>
$ADB -s <serial> exec-out screencap -p > shot.png
```

装包、点击、截图判读全都能自动跑。**唯一真正需要人的是解锁屏幕**，
以及写数据的用例要先拿到授权。

**模拟器替代不了它**：`emulator-5554` 上装同一个包能跑起来，但它**没有登录态**，
而拿到登录态要么发验证码到真手机、要么输密码。所以模拟器只对「不需要登录」的
验证成立（启动、原生能力、界面渲染），本清单这种要真实数据的不行。

### 顺带抓到的三件（不在原九条里）

1. **工作台整页空白且不自愈** —— 内容区全空，切 tab 不恢复，持续 2 分钟以上，
   **只有 force-stop 重启能救**。release 包不输出 JS 控制台，logcat 里只有系统噪声。
   **根因未查明，且 8-30 按原记路径两次未能复现**（见下）。
2. **13 组重名货、207 件货号全空**（同一商家）。挑货弹层如实显示它们，
   所以不是界面缺陷 —— 但商家分辨不出那几行，**挑错一件就把货记到别的 SKU 上，
   而唯一能区分的货号是空的**。数据问题，反复导入种子造成。
3. **`-R` 后缀换行叠字** —— 作废产生的单号变长换行，右侧 `10 → 0` 压在换行文字上。

### ⑧ 那条「死按钮」是假的，而我错了两轮

原记：「盘这一件点 5 次没反应」→ 报成**死按钮**，还写了一整段排除分析
（排除注入方式、排除弹层渲染器、排除模块重复）。换个 y 之后它弹出来了，
于是改口说是**坐标没命中**。

**两个结论都错。** 2026-08-30 在同一个中心坐标连点两次实测：
第一下打开弹层、第二下选中了第一行 —— **webview 空闲之后的首个注入事件不到达**，
与坐标无关，也与按钮无关。真手指不受影响，这是 `adb input tap` 的假象。

判据因此要写成：**同一坐标连点两次**；仍不动才谈缺陷。
代价是第二下会落在弹出来的东西上，对写数据的按钮要先想清楚它会点到什么。

### 「工作台整页空白」两次没能复现

下次真出现时会当场弹「出错了，请重试」并留一条可读记录，
那一刻的信息比反复试路径有价值得多。

### 两次差点误报，判据都取错了对象

  换个 y 坐标就弹出来了，是点击没命中。

## 一、这一版新增的四条（0.4.32 → 0.4.34）

### ① 四个数点下去要给它自己 ⭐ 本轮最实的一条

工作台 → 进销存卡 → 全部 ›（或直接看库存页顶上那一排）

- 顶上应当是**四个数**：在售 SKU / 缺货 / 滞销 / **在途**，中间有竖细线，是**一张卡**
- 点「缺货 N」→ 列表**只剩缺货的那几件**，且那个数字变成红色（选中态）
- 点「滞销 N」→ 只剩滞销的，**里面不该混进缺货的**
- 点「在售 SKU」→ 全部
- 再点一次同一个数 → 回到「全部」

> 这条对应的缺陷：**点「在售 SKU 204」给的是 18 条**（要处理），
> 点「滞销」给出的列表里混着缺货。返回 200、返回一列合法的货，零报错 ——
> 只是不是他点的那一列。修复在后端补了 `shortage` / `stale` 两个精确档。

### ② 「在途」点下去去单据页

- 点「在途 N」**不筛列表**，而是跳到单据页，页签落在「调拨」上
- 那一页应当只列调拨单

> 在途那批货既不在 A 也不在 B，库存列表里根本没有它 —— 所以它不是本页的筛选。

### ③ 工作台与库存页顶上是**同一块**

- 两处的四个数应当**一模一样**（同样的值、同样的顺序、同样的竖线分栏）
- 两处在细线之下都应当有「收货 N」「继续盘点」——**只在真有事时出现**
- 「收货 N」点下去 → 单据页 · 调拨；「继续盘点」点下去 → 那张**开着的**盘点单
  （页面应显示「账面数已于 … 锁定」，**不是**「选择需要盘点的货品」）

> 会出错的地方：点「继续盘点」如果开了一张**新**单，说明单号没带过去。

### ④ 公式说明只在有预留时出现

- 列表底下那句「可用 = 实存 − 预留…」
- 切到「有预留」那一档 → **应当出现**
- 切到「滞销」或任何一行预留都是 0 的一档 → **应当消失**

## 二、之前几版的五条（仍需覆盖）

### ⑤ 单据 → 那件货

库存 → 单据 → 点任意一张**入库或出库**单（不是盘点/调拨，那两类会跳走）

- 应当**就地展开**「这张单动了这些货」，列出每一件与增减数
- 点其中一行 → 那件货的库存明细

> 草稿单展开为空是对的（显示「还没过账，暂无流水」）；**已过账的单展开为空是缺陷**。

### ⑥ 那件货 → 那张单

- 库存明细里「变动明细」下面一行小字「点一行看那张单」
- 每行的单号是**链接色**；点它 → 单据页顶上显示「只看 XXX」，右侧「看全部」

### ⑦ 作废

单据页展开一张**已过账**的入库或出库单 → 底部「作废这张单」

- 确认框应当写明：会记一行反向流水、库存回到这张单之前、单据标成「已作废」
- 确认后：那张单显示「已作废」，**作废按钮消失**
- 回到库存看那件货，数量应当**退回去了**

> 这是「录错了怎么办」的唯一答案 —— 单据不可修改，只能整单作废重录。

### ⑧ 「盘这一件」

库存 → 点开任意一件货 → 拉到页尾

- 按钮是**「盘这一件」**，上方小字说明会生成一张盘点单
- 页面上**不该再有常驻的「差异原因」卡**
- 点它 → 填一个与账面**不同**的数 → **这时才**弹出「差异原因 · 差 ±N」
- 填一个与账面**相同**的数 → 不问原因

### ⑨ 挑货能挑到「还没进过货」的货

库存 → 进货 → 添加货品

- 弹层顶上有**带边框的搜索框**（不是一行灰字），输入两个字立即筛选
- 选中一件后再打开，顶上「已选 N 件」，选过的那行**压暗**
- **关键**：新建一个 SKU（或用一件从没进过货的），它应当**出现在弹层里、数量 0**

> 对应的缺陷：挑货此前读余额，而余额行是按需建的 ——
> 一件刚建的货没有余额行，于是在弹层里根本不存在，**商家没法给它记第一笔进货**。
