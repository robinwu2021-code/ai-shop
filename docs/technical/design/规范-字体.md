## 一句话

**字号只用下面这几档，字重只有三种，层级靠颜色与留白，不靠字号。**


这条规矩的来历是数出来的：收编之前 C 端有 **33 个不同字号**（19–104rpx），而字重只出现过 500/600/700 —— 600 与 700 合计 97 处、500 仅 1 处，也就是**全站没有一处显式的常规字重**。首页 ≥12px 的文本里 76% 是粗体：读者眼里没有轻重之分，等于全都不重要。


## 字阶（9 档）

|---|---:|---:|---:|---:|---|---:|
| `.txt-mega` | 60rpx | 30px | 700 | 1.1 | **收款台那一档**：商家照着它收钱、对账，隔着柜台一米要读准 | 3 / 0 |
| `.txt-hero` | 48rpx | 24px | 700 | 1.15 | 整页只有一个的大数（详情页主价、评分） | 4 / 0 |

| `.txt-title` | 34rpx | 17px | 600 | 1.3 | 区块标题 | 95 / 0 |

## 三条硬规矩

1. **700 只给价格**，600 只给标题与按钮，其余一律 400。
2. **行高按用途分档，不按语言分档。** 中文要 1.5 以上才不挤，拉丁 1.4 就够；
   取中文的下限对英文也不难看，而按语言切换行高会让同一个列表在中英文下高度不同，
   横滑卡、等高栅格全要跟着变。
3. **字阶里不含 `letter-spacing`。** 负字距是拉丁字母的排版习惯，中文小字号下收紧会让笔画粘连，
   而同一个类要同时承载中 / 英 / 阿三种文字 —— 少一个轴，三种语言就少三种试错。

## 密度变量：同一个类，两端两个值

C 端是顾客逛店（松一点显精致），B 端是店主一天扫几十次的作业台，**密度即效率**。

| 变量 | C 端 | B 端 | 管什么 |
|---|---:|---:|---|
| `--sh-pad-card` | 32rpx | 24rpx | 卡片内边距 |
| `--sh-pad-page` | 28rpx | 24rpx | 页面左右/上内边距 |
| `--sh-pad-empty` | 72rpx | 48rpx | 空态上下留白 |
| `--sh-gap-tabs` | 20rpx | 16rpx | 筛选条间距 |
| `--sh-fs-sub` | 26rpx | 24rpx | 次要文字字号 |

⚠️ **`.txt-*` 字阶目前只在 B 端落了地。** C 端 9 档合计只有 1 个调用点，
而 `.sh-h1` / `.sh-h2` 那两个旧名在 C 端还有 26 处 —— 
也就是说这份规范对 C 端还只是**纸面上的**，那 26 处是明账。

## 数字与 RTL

`.sh-num`：等宽数字，且在 RTL 下强制 LTR 方向 —— **金额、百分比、倒计时是 LTR 序列**，
跟着 RTL 走会把符号甩到另一端（`-25%` 变成 `25%-`）。
