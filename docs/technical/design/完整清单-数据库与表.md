# 完整清单：数据库与表

状态：清单稿。创建：2026-11-26。
这是清理、抽象、分库之后的**目标清单**：14 个库、411 张表。库里的表和代码都还没有动；表的合并与归属按列结构和业务含义定，没有对着代码验证。
排序：库按业务顺序排——先开店、再登录、再卖货、再收钱算账、最后看报表；库内的分组按业务顺序排；组内的表按重要性排，最核心的在前。
相关：[清理后的表清单](清理后的表清单-按业务模块.md)（每个库的定义与边界）、[逐表明细](schema/db-split-manifest.csv)（原有 1078 张表各自的去向）。
