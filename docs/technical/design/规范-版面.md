## 画布

基准 **375pt**，`1rpx = 0.5px`。
H5 与 App 都把 rpx 编译成 rem，运行时 `html font-size = 屏宽 / 23.4375`（375 → 16px）。
**两端产物里这套换算逐字节相同** —— 2026-08-28 对比过 `build:h5` 与 `build:app`。

## 间距（11 档）

| 档 | rpx | px |
|---|---:|---:|
| `hair` | 4rpx | 2px |
| `xxs` | 8rpx | 4px |
| `xs` | 12rpx | 6px |
| `sm` | 16rpx | 8px |
| `s` | 20rpx | 10px |
| `md` | 24rpx | 12px |

| `lg` | 32rpx | 16px |
| `l` | 40rpx | 20px |
| `xl` | 48rpx | 24px |
| `xxl` | 64rpx | 32px |

**圆角只用这五档。** 差 4rpx 的两个圆角没人分得出，只会让人各写各的 —— 
`typography.test.ts` 有断言守着，越档推不上去。


⚠️ **间距那张表不是白名单，是一张 4rpx 网格。**
此前它被写成「五档 8/16/28/40/64」并配着一句「只用这几档」，
而全仓 1292 处间距取值里落在那五档上的只有 **39%** —— `20rpx` 用了 205 次，
而档位里的 `64rpx` 只有 2 次。按用量排下去就是「4 的倍数全都在用」。
闸门查的是**网格**，上表只是把网格上真正在用的成员列出来给人看。
加一个新数之前先问：它和邻居差的那 4rpx，有没有人分得出？


真正决定「间距该多大」的是**语义变量** —— `--sh-pad-page` / `--sh-pad-card` /
`--sh-pad-empty` / `--sh-gap-block` / `--sh-gap-tabs`，它们按端有不同的值（见《规范·字体》的密度表）。


## 页面框

所有页面走 `sh-scaffold`：它管标题、内边距（`--sh-pad-page`）、底部菜单占位、
宽屏收窄（>600px 收成 375 版心）与安全区。**`position: fixed` 的悬浮条不用各自处理宽屏** ——
scaffold 的 transform 让它们以应用框为包含块，漏改一处就会横跨整屏。


## 容器：四个，页面不自己画

一屏东西装在**四种盒子**里，全部由库件给。页面在 `sh-scaffold` 顶层自己写
`background: var(--sh-surface)` 或 `var(--sh-*-tint)` 而不挂容器类 —— 断言直接红。

| 件 | 什么时候用 | 别拿它当 |
|---|---|---|
| `.sh-card` | 一条内容一张卡：列表行、表单分区、统计块 | 块内还要分小节时用 .sh-block |
| `.sh-block` | 标题与内容同属一个白块 —— 灰缝只剩块与块之间那一道 | 只有内容没有标题时用 .sh-card |
| `.sh-cells` | 一组设置项/入口挤在一块白底上，行间只留 2rpx 缝 | 行与行要分开成卡的用 .sh-card |
| `.sh-notice` | 一段话压在语义色 tint 底上：主色档（说明、进行中） | 可点的用 .sh-btn，短标签用 .sh-chip |

提示条有 **5 档**（主色 / danger / muted / success / warning），底与字成对翻 —— 只改底色会得到一段读不清的字。


## 行与列表

| 件 | 什么时候用 | 别拿它当 |
|---|---|---|
| `.sh-center` | 内容摆正中间的方块 | 只要横向居中用 text-align |
| `.sh-fill` | 占满剩余宽度并允许被压缩（`flex:1;min-width:0`） | 定宽的那一侧别挂 |
| `.sh-hit` | 把点按面积撑到 88rpx 以上，而不改变它看上去的大小 | 本来就够大的别挂 |
| `.sh-hit::after` | `.sh-hit` 撑开的那块看不见的点按区 | 不要单独挂，它是上一条的一半 |
| `.sh-row` | 一行之内的横排：图标 + 文字 + 右侧值，纵向居中，缝 16rpx | 会折行的一堆用 .sh-wrap |
| `.sh-row--baseline` | 两端对齐但按**基线**：左右字号不同时用它，两段字才坐在同一条线上 | 字号一样就别加，center 更稳 |
| `.sh-row--between` | 左右两端对齐，且左右**字号一样** | 字号不一样再叠 .sh-row--baseline |
| `.sh-row--divided` | 连排的行之间画一道发丝线（第一行不画） | 行与行之间要留白的用 .sh-cells |
| `.sh-row--top` | 两端对齐但顶对齐：右边的值会折成两行时用 | 单行值用 .sh-row--between |
| `.sh-scrollx` | 横向滚动一排（隐藏滚动条） | 会折行的用 .sh-wrap |
| `.sh-scrollx::-webkit-scrollbar` | `.sh-scrollx` 藏滚动条用 | 同上 |
| `.sh-seg` | 分段/筛选里的一格：弱色底、选中翻主色 | 整块可选的卡用 sh-option |
| `.sh-seg--fill` | 分段格平分整行宽度 | 个数不定时别用，会挤扁 |
| `.sh-seg--off` | 分段格的不可选态：压暗且不响应 | — |
| `.sh-seg--on` | 分段格的选中态 | — |
| `.sh-wrap` | 会折行的一堆：标签组、筛选 chip 组、一排动作，缝 12rpx | 一行装得下的横排用 .sh-row |

间距**由项自己挂 `.sh-mt-* / .sh-mb-*`**，不是容器给 gap —— 
36 个列表里 35 个的容器还装着分组标题与说明，容器一改 gap，标题与第一项的距离也跟着变。


## 浮层层级

| 层 | z-index | 说明 |
|---|---:|---|
| `sh-tabbar` | 90 | 底部菜单 |
| `sh-actionbar` | 40 | 悬浮内缩通栏 |
| `sh-sheet` | 100 / 150 | 底部弹层 |
| `sh-dialog` | 200 | 居中对话框 |

对话框永远在最上面 —— 它是要人立刻回答的那一个。弹层叠弹层用 `sh-sheet` 的 `stacked`。


### 投影（2 档）

| 档 | 值 | 用在哪 |
|---|---|---|
| `--sh-shadow-up` | `0 -6rpx 20rpx rgba(10, 12, 16, 0.08)` | 贴屏幕边缘的条（底部菜单）—— 分界主要靠 `--sh-hairline`，投影只补一点纵深 |
| `--sh-shadow-float` | `0 8rpx 24rpx rgba(10, 12, 16, 0.16)` | 真的浮在内容之上、可被拖动的（FAB、拖起来的行） |

⚠️ **别拿 `--sh-scrim` 当投影色。** 它是**蒙层**色（45% 的黑，活是压暗弹层背后的整屏）—— 当投影用会得到一条又黑又宽的灰带。此前全仓 5 处投影全都抓了它，2026-09-06 用户直接报了「底部工具栏阴影太多」。`ui-package.test.ts` 有两条断言守着。


深色态不另给一份：黑投影压在深色面上几乎看不见，而这是对的 ——深色界面靠面色的明度差表达高度，不靠投影。


浮层的**壳**由三个积木给，件只管自己的内容与层级：

| 件 | 什么时候用 | 别拿它当 |
|---|---|---|
| `.sh-grip` | 面板顶上那道短横 —— 在说「这是浮上来的一层，下面还有页面」 | 它不可点，别挂手势 |
| `.sh-mask` | 浮层的遮罩：铺满、压 scrim 色。点它＝取消 | 整屏的容器不是它，是件自己的 fixed 层 |
| `.sh-panel` | 贴底弹上来的面板：44rpx 上圆角、surface 底、自带安全区 | 居中的对话框用 sh-dialog |

**三个件此前各画了一份**（`sh-sheet` / `sh-prompt` / `sh-theme-sheet`）——
遮罩逐字节相同，抓手条的下外边距却是 32 / 28 / 28 三个数。


## 深浅与皮肤

9 套皮肤 × 明暗两态。切换要**同时**翻两处：
H5/App 改 `<html data-skin data-theme>`，小程序改 `.sh-root.skin-*.mode-*`（`sh-scaffold` 统一注入）。


⚠️ **明暗归我们的 `mode` 管，不跟系统走。** uni 自带的 `--UI-*` 变量在 App 产物里
**只在 `@media (prefers-color-scheme: dark)` 里定义过** —— 系统浅色时它们根本没有定义，
用到它们的整条声明会被丢弃（内置件掉底色），系统深色时又跟 `--sh-*` 撞成两套色。
`base.css` 因此无条件补了一份浅色默认，位置在 uni 那段之后。
