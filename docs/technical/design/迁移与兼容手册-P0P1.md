## 三 · M11 改名专节（唯一高危项，协同迁移）

1. **锁窗口**：与并行会话约定时段（共享工作区协议），期间不动 `prd_store_goods`；
2. 全仓清点引用：`@TableName`、手写 SQL、测试 schema（`schema-test.sql`/`job-h2`）、生成器（ERD/表清单）、文档；
3. **一次提交**内完成：`RENAME TABLE` 迁移 + 实体 `@TableName` + 全部引用 + 生成物重跑（ERD/数据库表清单）；
4. 验收：全量测试绿 + `grep -r prd_store_goods` 仅剩历史文档命中；
5. 回退：反向 RENAME 同一批引用还原（保留回退补丁在工单附件）。

## 四 · 禁令与检查清单

- **双源禁令**：M12–M14 的旧源在死期后必须物理退役 —— 「兼容读」不许无限期活着；
- 每条新表迁移都要有对应实体/Mapper 或明确标注"P1 才接"；
- 迁移文件头注释写清所属工单号（M01…），回滚脚本同目录 `rollback/` 存档；
- 上线顺序：M01–M10 可乱序小批，**M11 单独一批**，M12+ 按阶段。
