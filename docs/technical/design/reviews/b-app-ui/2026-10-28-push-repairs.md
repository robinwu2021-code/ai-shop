> 状态：修复已实现并通过提交前检查；正式远端推送仍受完整 pre-push 门禁约束，结果以 Git 远端分支及本地门禁回执为准。

## 实际变更

- 运营端新增打印监控和按权限控制的对账入口，补齐积分账户、交易及区间快照查询；接入真实适配器、错误重试、分页及中英文文案。演示模式不伪造监控事实，也不执行对账。菜单与开关通过新增 V553 迁移注册，继承既有同范围只读授权，不改历史迁移。
- 打印会话先验证运营数据域，再读取归属事实；三条只读查询的租户、主体、门店约束由源码合同和反向权限用例共同守护。买家商品收藏注册 SELF 数据域；仅买家读取的表不要求虚构运营锚点，新增运营读取会重新进入锚点检查。
- SQL解析支持多行定义、CHECK与转义引号；SQL直接持久化表按真实生产SQL与列验证，排除注释、日志、绑定值及其他表。统一结构关系真源，修正枚举、角色后续迁移对账、参数校验和带参错误文案，未增加失败基线。
- 零元支付使用支付账本的真实通道成交编号；订单投影失败后复用原回执恢复，并重验原支付封存金额、币种、归属及成交事实。结算、积分、退款、权益和通知测试使用真实持久化事实，保留原子性和重复投递检查。
- 三个打印页及其他相关B端页面采用现有字号、填充和语义色工具类；运营端重试、分页、复选框与筛选动作使用明确间距和折行，移除技术性长说明。
- 测试上下文缓存上限为2；仅测试内的H2内存库按实际上下文隔离并随池释放，保留同库别名和动态参数，原生数据库及生产配置不变。
- 修正文档断链、27张库存表事实、SVG可访问说明；生成清单与源码同步。原有共享检查基线从12条减少至3条，剩余阈值保持原值。
