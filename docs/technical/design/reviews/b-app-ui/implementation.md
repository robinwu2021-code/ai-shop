## 二、实际改动

### 文案与 i18n

- 通用保存、取消、确定、启停、编辑、改名、搜索、加载更多、未保存反馈和同业务入口标题复用统一key。
- 退货验收、隔离库存、整单退款、期初对齐批次、库存同步结果和核销数量改为完整三语词条与命名插值。
- 同步结果区分未找到规格、需独立门店库存、已处理不重复调整；未知状态使用待核实，保留零库存，不伪造成功。
- 名称、日期/次数、金额精度、重复档位的保存错误分类提示，原有储值草稿验证、持久化命令、重试键和原修订号不变。
- 37条长文案同步精简三语；4条低频说明改为按需查看；保留12条决策所需信息，另外分别拆解打印读数与校验提示、移除重复导语、保留未渲染兼容文案。

### 组件与 Layout

- 移除资质页输入框76rpx高度覆盖，字段沿用88rpx/24rpx/24rpx公共规格；移除多页重复字段间距定义，局部排版改用业务class。
- 商品标准品搜索从自建蒙层/面板迁移到 sh-sheet，保留搜索、选用、关闭与滚动职责。
- 打印页面的原生按钮、输入与字段标签纳入公共样式；主/次动作、选中态、主题色和长文案换行保持区分。打印统计改为两行四个读数。
- 移除无效 sh-between、sh-btn--ghost、sh-error、txt-muted；退货质检、盘点和打印样式不再写死颜色。
- 新增 biz-rule-help 复用 sh-sheet，给入驻、人群、库存报表提供按需说明。小程序宿主节点间距规则同步维护。

### 防回退

`npm run check:ui -w ai-shop-b-app` 检查三语一致、静态key、直写中文、公共类存在性、裸原生控件和布局覆盖；B端 `npm test` 自动先执行这道检查。

扫描覆盖 `t/$t/tt/i18n.global.t`，将动态表达式与静态key分开。29项独立fixture验证注释、tt包装、动态前缀、缺词、占位符差异、未知类、例外边界与组件组合；其中19项针对布局。CSS类只从实际样式规则中读取。

例外按文件、选择器、属性和值逐项登记在 `b-app/scripts/ui-exceptions.json`，不按整页豁免。保留的B端布局只有：全局field密度、经营区域2处标记微调、切店幕布、拖动手柄补偿、库存更多菜单点击关闭层。

## 四、实施边界与取舍

- 当前工作区保留原有未提交业务实现，使用改前快照核对本轮变更；没有提交混合变更、部署或改动后端状态机。
- 动态/共享UI仍需要的44个旧key保留兼容。删除它们会造成实际页面缺词，台账保留目标映射供后续业务改造引用。
- 12条长文案包含金额/数量、库存冻结、不可撤销、到期只读或URL/公式等必要信息；有意保留，不能为减少字数隐藏后果。
- 生成版ui-lib的历史pages数组同时包含页面与业务组件扫描面；本专项96页/42组件按实际目录分别统计，详见 [当前源码清单](./inventory.md)。
- 浏览器检查使用本地演示环境，只覆盖代表页，不是96页全量视觉或真实后端联调验收。

- 已复现并消除共享 `icon-chars`、`input-bounds` 两项失败，未调整检查阈值或添加例外。全量共享检查从535通过/31失败变为537通过/29失败。

## 六、截图反馈后的布局修正（2026-10-26）

旧阿语截图虽没有横向溢出，但三个输入框间距为0，不能判作视觉验收通过。已按用户反馈切换中文并复现，新的 [中文截图](../../../../../output/b-app-ui/qualifications-zh-layout.png) 与 [全页截图](../../../../../output/b-app-ui/qualifications-zh-layout-full.png) 取代旧截图作为本页布局依据。

- 资质表单改成 `field → field__label + field__input`；字段组上距20rpx、标签到输入12rpx，说明采用sh-hint。照片区单独分组，按钮间16rpx、操作区上距24rpx；卡头使用现有sh-card__head。
- 上传入口与操作条按钮分开布局，去掉导致“去传证”撑满半行的flex规则。删除残留kv布局类。
- 复核所有B端sh-kv内的输入：商品编辑的截单时间、到货说明两处同步改为field组。只读信息保留sh-kv。
- 修复资质、入驻、收款设置3处上传器参数名，使用实际width/height；资质页实际显示80×56px（375px视口），不再落入商品图104rpx方形默认值。
- 检查器改用PostCSS实际规则解析已定义类；注释里的旧field__hint、声明字符串不再蒙混过关，两项新增fixture先失败后通过。
- 浏览器中文320/375/430px：输入框间距分别约30.83/36.14/41.42px（含标签），均无粘连、无横向溢出；标签到输入、操作按钮之间均有正间距。原始测量见 [间距记录](../../../../../output/b-app-ui/qualifications-spacing.json)。
- B端54文件282项通过；9项扫描fixture通过；类型检查及H5/小程序/App构建通过。共享全量538通过/28失败；其中环境变量检查转绿来自当前混合工作区，未归因于本轮布局修改。真机验收仍未执行。
