## 三、本次不重复创建的共享能力

| 表或能力 | 处理方式 |
|---|---|
| `prd_goods`、`prd_sku`及商品价格库存 | 复用现有商品能力，不复制 |
| `ord_order`、`ord_sub_order`及订单行、支付售后 | 复用现有订单资金权威，不改现有表 |
| 账号、主体、商户、门店、营业时间 | 复用当前底座，不建餐饮副本 |
| `prn_device`、`prn_template`、`prn_route`、`prn_job`、`prn_attempt` | 共享打印候选表，本次未创建 |
| `rpt_food_metric_daily` | 共享报表候选投影，本次未创建 |

完整设计仍有79张候选表，本次仅创建餐饮拥有的73张。共享打印/报表的6张不包含在73张业务表中，`fnb_flyway_history`也不计入业务表数量。
