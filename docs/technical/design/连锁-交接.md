## 3 改表清单（按期）

### 3.1 第二期

**D1 主体属于集团**（平台基础库；列定稿已有，只回填）

```sql
-- 规则：主体的所有人账号（mch_account.is_owner = 1、在用）对应的 actor 就是某集团的 owner_actor_no，
-- 则该主体属于该集团。actor 口径以 ManagementScopeServiceImpl.ownerAccounts 为准（MCH: 账号号 / 用户号）。
-- 先只读列出：一个主体对上 0 个或多个集团的，交用户逐个定，不自动写。
SELECT e.entity_no, COUNT(DISTINCT g.management_no) AS groups
  FROM mch_entity e
  JOIN mch_account a ON a.tenant_no = e.tenant_no AND a.entity_no = e.entity_no
                    AND a.is_owner = 1 AND a.status = 'ACTIVE' AND a.deleted = 0
  LEFT JOIN mch_group g ON g.tenant_no = e.tenant_no AND g.deleted = 0
                       AND g.owner_actor_no IN (CONCAT('MCH:', a.mch_account_no), CONCAT('USER:', a.user_no))
 WHERE e.deleted = 0
 GROUP BY e.entity_no;
-- 唯一对上的再写：UPDATE mch_entity SET management_no = ? WHERE tenant_no = ? AND entity_no = ? AND management_no IS NULL;
```

> `owner_actor_no` 的前缀：B 端账号是 `MCH:` + 账号号，关联了 C 端用户的是 `USER:` + 用户号（`BrandStoredValueActivityAuthority` 第 26 行）；执行前再核对一次。
