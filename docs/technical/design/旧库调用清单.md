# 旧库调用清单

> 由 `scripts/gen-legacy-db-usage.py` 生成，不要手改。迁完一个模块（绑新库、改表）后重跑。

目标：业务不再访问旧库（用户 2026-11-27）。旧库 = 主库 `spring.datasource`（线上 `ai_shop_ume`）及复用它地址的支付池、密钥池，加上进销存、任务、报表各自的独立旧库。新库 = .61 上的 `n_*`，表名快照见 `docs/technical/design/legacy-db/new-db-tables.json`。

当前已绑新库的模块（`shop.modules.*.datasource`）：`invoice` → `service`

选库规则与运行时一致：句柄标记（`PlatformTableMapper` 等）→ 句柄；句柄没绑新库就落回主库（支付拆出来的两个句柄落回支付池）；发票、打印、会员营销按包名；支付包其余 → 支付池；其余 Mapper → 主库。
