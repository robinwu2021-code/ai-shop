# 一 · 表结构（终版完整 DDL）

```sql
-- ── 卡定义（商品侧 Trait，挂 CARD 商品）───────────────
CREATE TABLE prd_trait_redeemable (
  goods_no    VARCHAR(32) NOT NULL,
  card_kind   VARCHAR(8)  NOT NULL COMMENT 'VALUE 储值面额 / TIMES 次卡 / PERIOD 期限卡（核销记账）',
  face_value  BIGINT NULL COMMENT 'VALUE：面额（分）',
  bonus_value BIGINT NULL COMMENT 'VALUE：赠金（充100送20 → face=10000, bonus=2000）',
  total_times INT    NULL COMMENT 'TIMES：总次数',
  valid_days  INT    NULL COMMENT '自发卡起有效天数；NULL=不过期',
  scope_type  VARCHAR(8) NOT NULL DEFAULT 'ALL' COMMENT 'ALL / CATEGORY / GOODS',
  scope_refs  JSON NULL COMMENT '类目号或商品号白名单',
  store_scope VARCHAR(8) NOT NULL DEFAULT 'ENTITY' COMMENT 'ENTITY 全店通用 / STORE 限发卡店（A4）',
  transferable TINYINT NOT NULL DEFAULT 0 COMMENT '可转让（记账，本期恒 0）',
  UNIQUE KEY uk_trait_redeemable (goods_no)
) COMMENT='卡定义。卖卡=普通订单，发卡=履约';

-- ── 储值账户（VALUE 载体，归主体）─────────────────────
CREATE TABLE mbr_asset_account (
  account_no      VARCHAR(32) NOT NULL,
  member_no       VARCHAR(32) NOT NULL,
  entity_no       VARCHAR(32) NOT NULL,
  principal_minor BIGINT NOT NULL DEFAULT 0 COMMENT '本金池（预收款，A1）',
  bonus_minor     BIGINT NOT NULL DEFAULT 0 COMMENT '赠金池（营销费用）；扣减按比例（A3），退卡只退本金',
  status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/FROZEN',
  UNIQUE KEY uk_asset_account (account_no),
  UNIQUE KEY uk_account_member (member_no, entity_no)
) COMMENT='余额恒等于流水之和（M1，对账 Job 日切校验）。扣减只能条件 UPDATE（M2）';

-- ── 卡实例（TIMES/PERIOD 载体）────────────────────────
CREATE TABLE mbr_card (
  card_no       VARCHAR(32) NOT NULL,
  member_no     VARCHAR(32) NOT NULL,
  entity_no     VARCHAR(32) NOT NULL,
  goods_no      VARCHAR(32) NOT NULL COMMENT '→ 卡定义（快照语义：定义改了不影响已发卡）',
  card_kind     VARCHAR(8)  NOT NULL,
  total_times   INT NULL, remain_times INT NULL COMMENT 'TIMES：条件 UPDATE 扣（M8）',
  expire_at     DATETIME NULL,
  status        VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/FROZEN/EXPIRED/REFUNDED —— 非 ACTIVE 不可耗（M5）',
  source_order_no VARCHAR(32) NOT NULL COMMENT '发卡来源订单，唯一 → 发卡幂等（M7）',
  UNIQUE KEY uk_card (card_no), UNIQUE KEY uk_card_source (source_order_no, goods_no),
  KEY idx_card_member (member_no, entity_no, status)
);

-- ── 流水（唯一变更入口）───────────────────────────────
CREATE TABLE mbr_asset_txn (
  txn_no        VARCHAR(32) NOT NULL,
  subject_type  VARCHAR(8)  NOT NULL COMMENT 'ACCOUNT / CARD',
  subject_no    VARCHAR(32) NOT NULL,
  member_no     VARCHAR(32) NOT NULL, entity_no VARCHAR(32) NOT NULL,
  biz_type      VARCHAR(16) NOT NULL COMMENT 'RECHARGE 充值/ISSUE 发卡/CONSUME 耗用/REVERSE 冲正回补/REFUND 退卡/EXPIRE 过期/NO_SHOW 爽约扣/ADJUST 运营调整(审批)',
  principal_delta BIGINT NOT NULL DEFAULT 0,
  bonus_delta     BIGINT NOT NULL DEFAULT 0,
  times_delta     INT    NOT NULL DEFAULT 0,
  order_no      VARCHAR(32) NULL COMMENT '关联订单（耗用=那张实收 0 的单）',
  payment_no    VARCHAR(32) NULL COMMENT '关联收款（TIMES_CARD/STORED_VALUE 那笔）',
  reversal_of   VARCHAR(32) NULL COMMENT '冲正指向原流水，且原流水只可被冲一次（M3）',
  idem_key      VARCHAR(64) NOT NULL,
  operator      VARCHAR(64) NOT NULL,
  UNIQUE KEY uk_txn (txn_no), UNIQUE KEY uk_txn_idem (idem_key),
  UNIQUE KEY uk_txn_reversal (reversal_of),
  KEY idx_txn_subject (subject_type, subject_no), KEY idx_txn_order (order_no)
) COMMENT='余额与余次的唯一变更入口。绝不无流水 UPDATE';
```

# 二 · 领域对象与不变量

```
AssetAccount(双池; deduct(amount)→按比例拆池条件扣; recharge; refundPrincipal)
Card(kind; consume(n) 条件扣; guard: 非 ACTIVE/过期不可耗; freeze/expire)
AssetTxn(不可变; reverse() 生成反向流水, 原流水唯一被冲)
Applicability(scope 校验 → 下单五步第②步调用)
AssetInvariants: M1 流水恒等 · M2/M8 条件扣 · M3 冲正唯一 · M4 比例扣退本金 ·
                 M5 状态守卫 · M6 下单期校验 · M7 发卡幂等
```

# 五 · 行业数据对标（三张单）

**① 充 100 送 20 → 消费 30**
```
卖卡单: CARD(VALUE) 商品 place+markPaid ¥100 → onPaid → RECHARGE 流水(principal+10000, bonus+2000)
消费: deduct(3000) → 按比例扣 principal−2500, bonus−500（拆分进小票）
     → markPaid(STORED_VALUE), payAmount=0, asset_deduct=3000
```
**② 疗程 10 次 → 耗 3 → 退卡（A2 默认 LIST）**
```
卖卡: ¥1000 单（收入在此确认）→ ISSUE 发卡 total=10
耗 3 次: 各一张实收 0 单 + CONSUME(times−1) ×3
退卡: 已耗核销 3×¥120(原价)=360 → 应退 640 → payment 冲正 → REFUND 流水(remain 清零, 状态 REFUNDED) → 售后退款 640
```
**③ 爽约扣次**：行业规则调 `deductAsset(NO_SHOW, times=1)` —— 一条流水，无特殊链路。
