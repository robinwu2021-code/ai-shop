# 支付库 `n_pay`：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/10-支付库.md)。

## 这个库是什么

**收单：这一笔钱收到了没有、退了没有。**

| 项 | 说明 |
|---|---|
| 库名 | `n_pay` |
| 表前缀 | `pay_` 收单：收款、退款、渠道交易、收银班次 |
| 管什么 | 现金的收款与退款；渠道与支付产品、收款策略与入口；渠道交易的执行、账单与对账；异常工单、告警（退款审批走独立的审核服务）；通知与订阅扣款；收银班次与现金收支 |
| 不管什么 | 钱记在谁名下、怎么结算（账务结算库）；谁有资格收钱、用哪个渠道（支付商户库）；订单本身（门店交易库）；储值与卡券（会员营销库）；渠道与支付产品的定义（基础能力库的统一字典）；给接入方的结果通知（统一事件）；监控告警（平台服务库的风控） |
| 谁在用 | 支付服务读写；其他库通过支付接口发起收款、退款，通过公共事件拿到结果。 |
| 和其他库的关系 | 收款、退款成功后发事件，账务结算库据此记账、进结算；商户与渠道配置从支付商户库读。 |
| 现状 | 已有（正式库 nearpay_prod，线上约 114 万行）。拆成三个库：本库留收单。shop 库里与它重名的表是早期遗留副本，不带进新库。 |
