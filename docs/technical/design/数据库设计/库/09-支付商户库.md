# 支付商户库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/09-支付商户库.md)。

## 这个库是什么

**谁有资格收钱、用哪个渠道、在哪台终端。**

| 项 | 说明 |
|---|---|
| 管什么 | 平台商户与渠道商户号、开通的支付产品；门店投影、门店与商户的关系、来源映射及其变更；出款账户；终端、渠道设备绑定、操作员会话、终端配置与验收；进件：主体资料、进件申请与版本、渠道进件请求；支付运营的权限映射与数据范围授权，由支付服务自己判；渠道费率：费率档、档内各渠道各产品的费率、门店在哪一档；渠道向平台收的成本费率是一种特殊的档 |
| 不管什么 | 交易本身（支付库）；商户主体与门店的主数据（平台基础库；这里只是支付侧的一份投影）；开放应用本身的登记（基础能力库）；运营人员是谁、有什么角色（统一认证）；渠道凭据等密钥（密钥库；这里只存密钥的编号）；主体资料的原件（平台基础库；进件版本上只留当时的快照）；终端上的登录令牌（平台基础库的 B 端会话） |
| 谁在用 | 运营端做进件与商户管理；支付库每次收款时读它（可缓存）。 |
| 和其他库的关系 | 平台基础库的主体、门店变更后同步过来；进件通过后才能在支付库收款。渠道凭据通过密钥服务取用，可在内存里短时缓存；统一认证只告诉支付“这是谁、有什么角色”，能做什么由支付按本库的映射与数据范围判。 |
| 现状 | 新建，从支付库拆出。是配置类数据，和交易没有同事务要求，建议最先拆。 |
