## 这个库是什么

**定时任务：有哪些任务、现在什么状态、每次跑的结果、处理到哪了。**

| 项 | 说明 |
|---|---|
| 管什么 | 任务定义；任务现状；每次运行的记录；任务游标 |
| 不管什么 | 任务处理的业务数据（在各业务库） |
| 谁在用 | 所有库的后台任务；运营端查看与手动触发。 |
| 和其他库的关系 | 各库原来各自的任务状态、游标、任务锁都收到这里。 |
| 现状 | 已有（正式库 ai_shop_ume_job_pilot）。 |
