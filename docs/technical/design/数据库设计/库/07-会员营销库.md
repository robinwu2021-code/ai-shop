# 会员营销库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/07-会员营销库.md)。

## 这个库是什么

**商家和顾客的关系，以及给顾客的优惠与预付资产。**

| 项 | 说明 |
|---|---|
| 管什么 | 会员、来源、门店档案、标签与分群；触达；活动及其范围、版本、报名；额度与预留；卡券：券、次卡、储值卡共用的模板、发放、持有、流水、核销；储值发行方；归因；品牌活动成本的分摊规则与依据；专题与运营位；单位客户；收藏与到店足迹；拼团的团与团成员；卡券与支付之间的对接与对账；评价、点赞、申诉与内容（帖子、问答、素材）；顾客档案；会员等级规则 |
| 不管什么 | 钱的结算（支付库）；一张订单里优惠怎么分摊到每一行（门店交易库的报价分摊）；用户账号（平台基础库）；卡券与支付的对账运行（任务库）与对账差异（账务结算库） |
| 谁在用 | 商户端做活动、发券、管会员；C 端领券、充值、用卡；门店交易库下单时来算优惠、核销卡券。 |
| 和其他库的关系 | 储值从支付迁到这里，作为卡券的一种；储值产生的门店间应付交给支付库结算。 储值由商户发行、钱在商户，所以整套（规则与账）都留在本库，作为卡券的一种；积分是平台的、作为资金结算，在账务结算库（用户 2026-11-26 确认）。 |
| 现状 | 新建，从 shop 库拆出。 |
