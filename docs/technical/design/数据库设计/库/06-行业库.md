# 行业库 `n_industry`：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/06-行业库.md)。

## 这个库是什么

**餐饮、美业各自特有的营业过程；商品和订单不在这里。**

| 项 | 说明 |
|---|---|
| 库名 | `n_industry` |
| 表前缀 | `fnb_` 餐饮特有的营业过程；`bty_` 美业特有的服务过程；`ind_` 行业公用的经营策略与配置 |
| 管什么 | 餐饮：桌台与占台、订位与时段容量、厨房工位与出品单、制作任务与厨房事件、厨显、人头权益、道次、排队、宴会、寄存与交接；美业：服务步骤与服务执行；两个行业共用的门店经营策略、配置修订、指派、门店设备 |
| 不管什么 | 菜品、服务项目（是门店交易库的商品）；账单、工单、订单与支付（门店交易库）；技师的占用（门店交易库的资源预约）；扫码入座、到店核验的票据（账号认证库） |
| 谁在用 | 餐饮、美业的商户端与门店设备。 |
| 和其他库的关系 | 只通过编号引用门店交易库的订单、到店单、预约单；下单后出品这类联动靠公共事件。公用化之后只剩 17 张，用户确认仍单独成库（2026-11-26），以后新增行业（如酒店、教培）也放这里。 |
| 现状 | 新建，从 shop 库拆出。 |

餐饮部分按 [TDD-餐饮域迁移新库](../../../TDD-餐饮域迁移新库.md) 定稿（2026-11-28），27 张表的结构与代码测过的一致，见 [DDL](../../schema/ddl/06-n_industry.sql)；旧表去向见 [餐饮库表清单](../餐饮-库表清单.md)。美业部分未变。
