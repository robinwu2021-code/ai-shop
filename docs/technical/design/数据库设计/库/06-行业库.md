# 行业库 `n_industry`：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/06-行业库.md)。

## 这个库是什么

**餐饮、美业各自特有的营业过程；商品和订单不在这里。**

| 项 | 说明 |
|---|---|
| 库名 | `n_industry` |
| 表前缀 | `fnb_` 餐饮特有的营业过程；`bty_` 美业特有的服务过程；`ind_` 行业公用的经营策略与配置 |
| 管什么 | 餐饮：桌台布局与座位、厨房工位与出品单、厨显、人头权益、道次、宴会；美业：预约的排程方案、服务步骤；两个行业共用的门店经营策略、门店设备（屏类与离线收银） |
| 不管什么 | 菜品、服务项目（是门店交易库的商品）；账单、工单、预约、排队、寄存、指派与执行、提成（都是门店交易库的公用能力）；桌台与技师的占用（门店交易库的资源预约）；扫码入座、到店核验的票据（账号认证库） |
| 谁在用 | 餐饮、美业的商户端与门店设备。 |
| 和其他库的关系 | 只通过编号引用门店交易库的订单、到店单、预约单；下单后出品这类联动靠公共事件。公用化之后只剩 17 张，用户确认仍单独成库（2026-11-26），以后新增行业（如酒店、教培）也放这里。 |
| 现状 | 新建，从 shop 库拆出。 |
