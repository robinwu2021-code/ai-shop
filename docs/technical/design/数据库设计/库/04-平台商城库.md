# 平台商城库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/04-平台商城库.md)。

## 这个库是什么

**平台卖给商户的东西：商户作为买家，在这里买套餐、订阅和硬件。**

| 项 | 说明 |
|---|---|
| 管什么 | 商城的类目、商品、SKU 与组成；plan 及其版本、包含哪些端；B 端订单、线下付款与凭证、退款、发货；订阅：账户、周期、预留、折算、额度；端权益定义：平台可以卖哪些端 |
| 不管什么 | 门店卖给顾客的商品与订单（门店交易库）；订阅的结果——门店开通了哪些端（平台基础库） |
| 谁在用 | 商户端购买与续费；运营端管理商品、审核线下付款。 |
| 和其他库的关系 | 订阅生效后，把“这家店在这段时间开通了哪个端”写到平台基础库。 |
| 现状 | 新建，从 shop 库拆出。代码上已经是独立模块。 |
