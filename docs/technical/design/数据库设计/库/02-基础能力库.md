# 基础能力库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/02-基础能力库.md)。

## 这个库是什么

**各业务库共用的公共能力，不属于任何一个业务。**

| 项 | 说明 |
|---|---|
| 管什么 | 运营端的角色、功能点、接口资源与授权；开放应用：对接平台的外部系统及其授权，支付和库存的对外接口共用；统一事件：各库共用的一套事件收发；统一字典：主体类型、行业、市场、行政区划、计量单位等；统一审批（轻量）：店内和运营的快速审批；公共发号与单据号登记；统一审计；系统设置 |
| 不管什么 | 任何业务数据；B 端的角色与授权（平台基础库）；三端的账号与会话（平台基础库）；App 的版本与功能目录（由单独的 App 项目管理）；入驻等重的审核、客服工单（独立的审核与工单服务）；接入申请（独立的审核与工单服务）；防重放的一次性随机数（放缓存，不建表）；密钥与凭据（密钥库）；支付运营的权限映射与数据范围（支付商户库） |
| 谁在用 | 所有库；网关读它判运营端的权限。 |
| 和其他库的关系 | 业务库不再各建事件、发号的表，都用这里的一套；防重不建表，由应用层做，加业务表唯一键兜底。 |
| 现状 | 新建。由支付库和 shop 库里各自的一套合并而来。 |
