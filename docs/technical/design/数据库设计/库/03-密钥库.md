# 密钥库 `n_secret`：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/03-密钥库.md)。

## 这个库是什么

**全平台的密钥与凭据，只有密钥服务能读写。**

| 项 | 说明 |
|---|---|
| 库名 | `n_secret` |
| 表前缀 | `sec_` 密钥与凭据 |
| 管什么 | 支付渠道的凭据；开放应用调接口的签名密钥；运营人员的接口密钥；打印、通知、发票通道等的凭据；主密钥、轮换策略、密钥事件与访问记录 |
| 不管什么 | 密钥属于的那个对象本身（应用在基础能力库，渠道商户号在支付商户库）；登录密码与会话令牌（平台基础库）；防重放的一次性随机数（放缓存，不建表） |
| 谁在用 | 只有密钥服务直接连这个库；支付、打印、通知、网关都通过密钥服务取用，每次取用都留访问记录。 |
| 和其他库的关系 | 其他库只存密钥的编号，不存密文。支付取渠道凭据依赖密钥服务，所以密钥服务要高可用，支付侧要有短时缓存。 |
| 现状 | 新建。支付库的一套（线上约一千一百把，主要是渠道凭据）和 shop 库的一套合成一套。 |
