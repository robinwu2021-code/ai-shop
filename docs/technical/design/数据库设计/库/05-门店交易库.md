# 门店交易库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/05-门店交易库.md)。

## 这个库是什么

**门店卖给顾客：卖什么、怎么下单、怎么算钱、怎么交付。零售是底座，餐饮和美业复用。**

| 项 | 说明 |
|---|---|
| 管什么 | 商品域：分类、商品、规格与选配、门店目录、可售量；订单域：购物车、支付单与商家订单、到店单、预约单；资源、班表与预约占用；计价与报价分摊；订单的收款记录；售后；履约与物流；渠道连接；社区团购；询价求购；指派与执行、提成规则；同行人、排队、分摊方案、顾客寄存；商品的交付要求 |
| 不管什么 | 真正的收款与结算（支付库）；实物库存（库存库）；优惠规则与卡券资产（会员营销库）；桌台、厨房、人员安排这些行业过程（行业库）；评价与内容（会员营销库）；物流的运单与轨迹（平台服务库；履约单只存运单号和最新状态）；小区（平台服务库） |
| 谁在用 | C 端下单；商户端收银、管商品与订单；餐饮、美业的行业功能。 |
| 和其他库的关系 | 订单保留两层：支付单是一次付款，商家订单是各商家各自的履约与售后。渠道来的订单就是带渠道来源的普通订单。 预约单和资源占用放在同一个库，下预约单和占住技师、桌台是同一个事务，避免重复预约；人员档案在平台基础库。 预约单和资源占用放在同一个库，下预约单和占住技师、桌台是同一个事务，避免重复预约；人员档案在平台基础库。 |
| 现状 | 新建，从 shop 库拆出。 |
