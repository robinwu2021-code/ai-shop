# 库存库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/08-库存库.md)。

## 这个库是什么

**实物库存的唯一事实来源：有什么货、在哪、进出过多少。**

| 项 | 说明 |
|---|---|
| 管什么 | 物料、库位、单位、货主、供应商；库存余额、流水、批次、序列号、日快照；出入库、调拨、盘点、退货单据；库存占用；需求计划与分发；配方（物料清单） |
| 不管什么 | 门店的可售量与下单锁量（门店交易库，那是简单库存）；商品的介绍与价格（门店交易库） |
| 谁在用 | 进销存服务；门店交易库下单、售后时通过接口占用、扣减、归还。 |
| 和其他库的关系 | 餐饮不再自带第二套库存账，出品消耗按配方走本库。 |
| 现状 | 已有（正式库 ai_shop_ume_inv）。 |
