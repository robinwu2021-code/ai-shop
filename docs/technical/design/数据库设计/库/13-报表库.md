# 报表库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/13-报表库.md)。

## 这个库是什么

**每日经营数据：从各业务库汇总出来给人看的数字，不是业务的事实来源。**

| 项 | 说明 |
|---|---|
| 管什么 | 每日指标与指标定义；日报的发布与每次发布的版本；构建记录、来源清单、待重算的日子；从各业务库摄入的事件与读到的位置 |
| 不管什么 | 任何业务的原始数据（都在各自的业务库）；导出文件（平台基础库的共用导出） |
| 谁在用 | 商户端、运营端看日报；后台任务每天构建。 |
| 和其他库的关系 | 只读各业务库的数据；数据晚到或被改时，把那一天标记为待重算。 |
| 现状 | 已有（正式库 ai_shop_ume_report_pilot）。 |
