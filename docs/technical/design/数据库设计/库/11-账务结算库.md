# 账务结算库 `n_settle`：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/11-账务结算库.md)。

## 这个库是什么

**钱记在谁名下、该分给谁、什么时候给。**

| 项 | 说明 |
|---|---|
| 库名 | `n_settle` |
| 表前缀 | `led_` 账务内核；`stl_` 结算与出款；`pts_` 积分 |
| 管什么 | 账：账户、凭证、分录（现金、积分、保证金、欠款共用）；结算：结算单、结算明细、出款（现金结算、储值跨店应付、积分门店对账、品牌成本、渠道对账、日结共用）；结算发票：进项票登记、结算开票申请；积分：积分类型、头寸、配置与事实、资金证据；分账费率规则；提成的结算；单位客户挂账的应收；全平台的对账差异 |
| 不管什么 | 每一笔收款、退款的执行（支付库）；商户与渠道配置（支付商户库） |
| 谁在用 | 支付服务的记账与结算部分；运营端做结算、出款、对账。 |
| 和其他库的关系 | 只接收事件：支付库的收退款、会员营销库的储值清分与品牌成本、门店交易库的日结。和收款不在同一个事务里，靠对账保证最终一致。 积分作为资金结算，所以积分的账、资金池、门店对账都在本库；储值是商户自己发、钱在商户，不在本库，只有跨店消费产生的门店间应付进结算（用户 2026-11-26 确认）。结算时按支付商户库的费率档算手续费，并在结算明细上记下用的是哪一档的哪一版；平台佣金率规则在本库。 |
| 现状 | 新建，从支付库拆出。统一账务、统一结算两个内核落地后再拆。 |
