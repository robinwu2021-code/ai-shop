# 平台服务库：表说明

状态：设计稿。创建：2026-11-26。上一层：[清单](../01-清单.md)。下一层：[表字段](../字段/12-平台服务库.md)。

## 这个库是什么

**平台替各业务做的事：通知、打印、发票、风控、地理与文件。**

| 项 | 说明 |
|---|---|
| 管什么 | 通知：渠道、模板、场景、消息、发送记录、推送、门店的通知设置；常见问题；打印：打印机、模板、路由、策略、请求到投递的全过程；发票：税制与通道、号段、申请、发票、折让、上传；风控：规则、命中、事件、黑名单、违禁词；地址库、图片记账、短链、导出文件；物流：承运商、运单、轨迹，商城发货、售后退货、调拨共用；小区等地理主数据；全平台的监控告警：规则、触发、认领与处置，支付的资金告警也在这里 |
| 不管什么 | 触发它们的业务本身（订单在门店交易库，收款在支付库）；商户与门店的主数据（平台基础库）；客服工单、门店待办、内容审核（由独立的审核与工单服务承担） |
| 谁在用 | 各业务通过公共事件触发；商户端管理打印机与开票；运营端管理通知与风控。 |
| 和其他库的关系 | 都是被业务事件触发的，对商户和门店只按编号引用，不需要和业务同事务。 |
| 现状 | 新建，从 shop 库拆出。 |
