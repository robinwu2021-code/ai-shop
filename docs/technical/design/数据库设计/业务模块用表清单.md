# 业务模块用表清单

状态：清单稿。创建：2026-11-26。上一层：[数据库设计](README.md)。
这份清单从业务出发：每个业务模块用到哪个库的哪些表。表名是规范名，见[表名对照](03-表名对照.md)。
它只按业务含义整理，没有对着代码核对；代码模块和库的对应是另一份，见[业务模块对齐](业务模块对齐.md)。

两种用法：
- **主用**：这个模块负责读写这张表，是它的归属模块。每张表只有一个主用模块。
- **还用到**：这张表归别的模块，这个模块要读它，或通过它的接口、事件用到它。只列主要的，不求全。

共 33 个业务模块、376 张表。
