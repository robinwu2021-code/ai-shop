# 清单：库、分组与表

状态：设计稿。创建：2026-11-26。上一层：[数据库设计](README.md)。
这一层只列出每个库有哪些分组、每组有哪些表。每张表是什么，点库名进入表说明。

共 14 个库、414 张表。库内的分组按业务顺序排，组内的表按重要性排。
