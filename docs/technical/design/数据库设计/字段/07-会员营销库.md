# 会员营销库 `n_member`：表字段

状态：字段草案。创建：2026-11-26。上一层：[表说明](../库/07-会员营销库.md)。
保留的表沿用现有的列；合并和新建的表的字段按并入的旧表推出，没有对着代码核过。
“来源”一栏：公共 = 每张表都有的公共字段，见[命名与字段规范](../02-命名与字段规范.md)；原有 = 原表就有的列；并入自 = 从被并入的旧表带过来；新增 = 这次设计新加的。

## 1 会员

### mbr_member

会员：顾客在某个商家或范围下的会员身份，含当前等级
（原表 `mbr_member`）

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| `id` | bigint unsigned | 主键，自增 | 公共 |
| `member_no` | varchar(32) | 会员号，会员关系的业务唯一编号 | 原有 |
| `entity_no` | varchar(32) | 所属商家主体号；同一人在同一主体下各门店算一个会员 | 原有 |
| `scope_type` | varchar(16) | 会员范围类型：ENTITY 按主体 / BRAND 按品牌 / STORE 按门店（某店自己的往来与分层） | 并入自 mbr_scope_member |
| `scope_no` | varchar(32) | 范围对象编号：主体号、品牌号或门店号，与 scope_type 对应 | 并入自 mbr_scope_member |
| `person_no` | varchar(32) | 平台人档号（平台基础库）；不存 user_no 与手机号，需要时从人档取 | 原有 |
| `status` | varchar(10) | 会员状态：LEAD 线索（不可触达、不进受众）/ ACTIVE 正常 / BLOCKED 被商家拉黑 | 原有 |
| `source` | varchar(16) | 首次来源：ORDER 下单 / SHARE 分享 / SCAN 扫码 / MANUAL 手工录入 / FAVORITE 收藏 / SEARCH 搜索；逐次明细在 mbr_member_source | 原有 |

| `first_order_at` | bigint | 首单时间（毫秒） | 原有 |
| `last_order_at` | bigint | 最近一单时间（毫秒） | 原有 |

| `level_rule_version_no` | varchar(32) | 定出当前等级所用的等级规则版本号 | 新增 |
| `has_recharge` | tinyint | 是否有过成功到账的储值 | 并入自 sv_customer_issuer_index |
| `last_recharge_at` | datetime(3) | 最近一次实际储值时间，B 端储值会员列表默认按它排序 | 并入自 sv_user_store_index |
| `last_consume_at` | datetime(3) | 最近一次储值或卡券实际核销时间 | 并入自 sv_user_store_index |
| `reach_opt_out` | tinyint | 买家是否关掉了这家店的消息；商家看得到状态，看不到原因 | 原有 |

唯一键与索引：会员号唯一；租户 + 范围类型 + 范围编号 + 人档号唯一（同一人在同一范围下只有一个会员身份）；主体 + 分层、主体 + 最近下单时间索引，用于分层筛选与列表。

留意：会员与门店 / 品牌范围的关系合成这一张，靠 scope_type 区分，原 mbr_member_store 的门店行变为 scope_type=STORE 的行；sv_customer_identity 的人档与账号绑定由平台人档承担，不再在此存 customer_no / user_no。
