# 平台基础库：表字段

状态：字段草案。创建：2026-11-26。上一层：[表说明](../库/01-平台基础库.md)。
保留的表沿用现有的列；合并和新建的表的字段按并入的旧表推出，没有对着代码核过。
每张表都有的公共列（`id`、`created_at`、`updated_at`、`created_by`、`updated_by`、`version`、`deleted`）不重复列出。
“来源”一栏：原有 = 原表就有的列；并入自 = 从被并入的旧表带过来；新增 = 这次设计新加的。

## 1 主体与门店

### mch_group

商户集团：一个老板或总部名下的多个主体、品牌、门店；授权以它为根。它在主体之上，一个集团可以有多个主体，不等于经营主体
（原 `mch_management_space`）

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| `tenant_no` | varchar(32) | 服务端可信租户号 | 原有 |
| `management_no` | varchar(64) | 商户集团号（沿用原管理空间号），品牌、主体、授权都以它为根 | 原有 |
| `name` | varchar(64) | 集团名称，给老板与运营看的总部名 | 原有 |
| `owner_actor_no` | varchar(64) | 集团的有效所有人（老板）的认证主体号，变更需走审计 | 原有 |
| `status` | varchar(24) | 集团状态：ACTIVE 正常 / SUSPENDED 暂停（暂停后其下授权全部失效） | 原有 |
| `bootstrap_source_account_no` | varchar(64) | 创建集团时核验过的所有人账号关系号，只证明创建资格，不因此授予其余主体权限 | 原有 |
| `auth_revision` | bigint | 集团授权版本号，每次授予或撤销授权递增，用于判断权限缓存是否过期 | 原有 |

唯一键与索引：租户 + 集团号唯一；按所有人查其名下集团的索引。

留意：原表的 bootstrap_key、bootstrap_hash 是创建幂等用的技术列，已去掉；字段名 management_no 沿用旧称，品牌、授权表里引用的也是它。
