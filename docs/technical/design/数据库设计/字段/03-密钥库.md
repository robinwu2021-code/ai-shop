# 密钥库 `n_secret`：表字段

状态：字段草案。创建：2026-11-26。上一层：[表说明](../库/03-密钥库.md)。
保留的表沿用现有的列；合并和新建的表的字段按并入的旧表推出，没有对着代码核过。
“来源”一栏：公共 = 每张表都有的公共字段，见[命名与字段规范](../02-命名与字段规范.md)；原有 = 原表就有的列；并入自 = 从被并入的旧表带过来；新增 = 这次设计新加的。

## 1 密钥

### sec_key

密钥：属于谁、做什么用、当前哪一版；渠道凭据、开放应用的签名密钥、运营人员的接口密钥、打印与通知的凭据都是其中一种
（原表 `sec_key`）

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| `id` | bigint unsigned | 主键，自增 | 公共 |
| `tenant_no` | varchar(32) | 租户编号 | 并入自 pay_channel_env_credential |
| `key_alias` | varchar(64) | 密钥别名，供业务表引用和人识别，唯一 | 并入自 pay_channel_env_credential |
| `namespace` | varchar(24) | 命名空间：PAY / LOGISTICS / INVENTORY / NOTIFY / PRINT / PLATFORM | 原有 |
| `name` | varchar(128) | 名称（给人看，这把钥匙给了谁） | 原有 |
| `owner_type` | varchar(24) | 归属类型：PAY_MERCHANT 收款商户调渠道 / CHANNEL_PLATFORM 渠道平台公钥 / PARTNER_APP 第三方应用 / INTERNAL_APP 内部系统 / TERMINAL 刷卡机 / PRINTER 云打印机 / OPS_STAFF 运营人员接口密钥 / PROVIDER 其他外部服务商 | 原有 |
| `owner_id` | bigint | 归属对象 id（同库或存量引用） | 原有 |

| `direction` | varchar(24) | 使用方向：OUTBOUND 我方调外部 / INBOUND 外部调我方时验证 / COUNTERPARTY_VERIFY 验对端响应与回调 | 原有 |
| `key_usage` | varchar(24) | 用途：SIGN 签名 / VERIFY 验签 / HMAC / ENCRYPT 加解密 / MTLS 双向证书 / API_KEY 接口密钥 / ACCESS_TOKEN 访问令牌 | 原有 |

| `env` | varchar(24) | 环境：SANDBOX / PRODUCTION，生产密钥永不进入沙箱 | 原有 |
| `status` | varchar(10) | 状态：DRAFT 草稿 / ACTIVE 生效 / SUSPENDED 暂停 / REVOKED 吊销 / EXPIRED 过期 | 原有 |
| `current_version` | int | 当前生效版本号；0 = 尚无 | 原有 |
| `sec_key_policy_id` | bigint | 适用策略 sec_key_policy.id；空 = 按命名空间 + 归属类型 + 环境取默认 | 原有 |
| `origin_ref` | varchar(96) | 密钥的来源单据，如进件单号（蓝新进件返回的商户密钥） | 并入自 pay_onboarding_newebpay_credential |
| `evidence_ref` | varchar(255) | 登记或核验证明的文件引用 | 并入自 pay_channel_env_credential |
| `expires_at` | datetime(3) | 当前版本到期时间（证书有效期或策略最长使用期取早者） | 原有 |
| `last_used_at` | datetime(3) | 最近使用时间（异步刷新） | 原有 |
| `use_count` | bigint | 累计使用次数（异步累加，近似值） | 原有 |

| `updated_at` | timestamp | 更新时间，每次修改自动更新 | 公共 |
| `updated_by` | varchar(32) | 更新人 | 公共 |

唯一键与索引：密钥别名唯一；命名空间 + 归属类型 + 归属编号 + 对端 + 用途 + 环境查密钥；按状态 + 到期时间扫描到期提醒。

留意：只有密钥服务能读写本库；业务表只存 sec_key_id。运营接口密钥、开放应用的 AppSecret 只存哈希，放在版本表 secret_hash。易特付访问令牌当作 ACCESS_TOKEN 类密钥，按版本轮换。

| `verify_evidence` | varchar(128) | 测试调用证据引用，如 PAY:pay_channel_call_log:123 | 原有 |
