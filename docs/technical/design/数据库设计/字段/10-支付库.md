# 支付库：表字段

状态：字段草案。创建：2026-11-26。上一层：[表说明](../库/10-支付库.md)。
保留的表沿用现有的列；合并和新建的表的字段按并入的旧表推出，没有对着代码核过。
每张表都有的公共列（`id`、`created_at`、`updated_at`、`created_by`、`updated_by`、`version`、`deleted`）不重复列出。
“来源”一栏：原有 = 原表就有的列；并入自 = 从被并入的旧表带过来；新增 = 这次设计新加的。

## 1 渠道与支付产品

### pay_product_capability

支付产品的能力：某个产品在哪个市场可用、币种与限额、接入方式、开户方式、支付方式，各有启停
（新建）

| 字段 | 类型 | 说明 | 来源 |
|---|---|---|---|
| `product_code` | varchar(64) | 支付产品，引用统一字典“支付产品”的编码 | 新增 |
| `capability_type` | varchar(24) | 能力类型：MARKET 可用市场 / CURRENCY 币种限额 / ACCESS_METHOD 接入方式 / ACCOUNT_MODE 开户方式 / PAYMENT_METHOD 支付方式 | 新增 |
| `capability_code` | varchar(64) | 这一类里的取值，如市场代码、币种、接入方式的编码 | 新增 |
| `market` | varchar(16) | 适用市场；空表示不分市场 | 并入自 pay_channel_product_market |
| `currency` | varchar(8) | 币种；只对币种限额有意义 | 并入自 pay_product_currency_limit |
| `min_amount_minor` | bigint | 单笔最低金额，最小货币单位 | 并入自 pay_product_currency_limit |
| `max_amount_minor` | bigint | 单笔最高金额，最小货币单位 | 并入自 pay_product_currency_limit |
| `enabled` | tinyint | 是否启用 | 新增 |
| `sort_no` | int | 展示顺序 | 新增 |
| `remark` | varchar(255) | 备注 | 新增 |

唯一键与索引：支付产品 + 能力类型 + 取值 + 市场唯一。

留意：产品本身的定义在基础能力库的统一字典，这里只放它下面一对多、各自要开关的能力。
