## 1. 需求摘要

买家点进详情页要回答的是「这件货多少钱、送不送得到我、什么时候到、怎么买」。
现状把这些排在第五张卡以后，首屏却放着库存数、数量步进器和一串「没有」
（已售 0 / 暂无评价 / 限购：不限购）。

用户确认的四条：
1. 保留分享（底栏）。现状那颗分享按钮 `@tap="() => {}"` 是空的，这次要真能分享。
2. 单规格商品点「加入购物车」直接加 1 件；多规格才弹规格面板。
3. 库存 ≤ 10 件显示「仅剩 N 件」，平时不露库存数。
4. 已售为 0 时不显示。

## 2. 改动

只动 c-app 前端 + 一个共享组件的可选参数，**不动接口、不动库表**。

| 块 | 现状 | 改后 |
|---|---|---|
| 主图 | 带边距圆角、图上压「-9%」 | 通栏；右下角「1/N」；折扣挪到价格区 |
| 价格 | 标题在上、价格在下；已售恒显示 | 价格在上（划线价 +「省 ¥X」）、标题 + 卖点在下；已售 > 0 才显示 |
| 配送卡（新） | 配送方式在事实区最下面；销售范围塞在商家卡里 | 首屏一张卡三行：送至（当前位置，点了去收货地址）/ 配送（方式 · 到货说明）/ 范围 |
| 领券 + 已选（新） | 领券一行；规格矩阵 + 库存 + 步进器常驻页面 | 一张卡两行：领券（前两张券的规则 + 领取）/ 已选（规格 · 件数，点开规格面板） |
| 规格面板（新） | — | 底部面板：缩略图、价格、已选；规格矩阵；数量 + 「仅剩 N 件」；两个按钮 |
| 商家 | 首屏第二张卡，带「暂无评价」 | 挪到下方；没人评过时不显示那一行（`biz-merchant-bar` 新增可选参数 `quietNoRating`，默认关，商家列表 / 搜索页不受影响） |
| 事实区 → 商品参数 | 配送方式 / 到货 / 参数 / 产地 / 限购（含「不限购」） | 标题「商品参数」；配送相关挪去配送卡；限购只在真有限购时出现 |
| 评价 | 空态两行 | 空态一行 |
| 底栏 | 分享（空）/ 购物车 / 两个按钮 | 店铺 / 分享（小程序原生 `open-type="share"`）/ 购物车，图标带字；两个按钮 |

预约类（日期时段）、集单、拼团进度、买赠提示、虚拟商品说明**原样保留**，只调位置。

## 3. 买的动作

- 单规格（`skus.length === 1`）：加入购物车 = 直接加当前数量（默认 1）；立即购买 = 直接去结算。
- 多规格：两个按钮都先弹规格面板，面板里的按钮才真正执行。
- 拼团商品底栏仍是「单买 / 开团」，单买按上面同一条规则走。
