### 测试（与 T 同步写，每条做一次消融）

| AC | 用例 | 消融 |
|---|---|---|
| AC-7 | 截单前撤单退款、截单后拒 | 注掉 `isCutOff` 判断 → 截单后也能撤 → 红 |
| AC-8 | 子单 `arrive_date` = 提货日；非集单单仍按下单日 | 去掉 `COALESCE` → 看板错一天 → 红 |
| AC-9 | 汇总与订单明细逐行对得上 | 汇总不滤退款行 → 红 |
| AC-10 | 未达起订：商家照常 / 取消退款；超时自动取消 | 取消不调 `refundAll` → 子单不转 REFUNDED → 红 |
| AC-11 | 预售 SKU 进集单被拒 | 注掉互斥校验 → 红 |
| 边界 | 截单前 1 秒下单属今天；截单后下单进下一期；提前截单后下单进下一期 | 把 `>=` 改 `>` → 红 |
| 数据域 | `/biz/periods` 跨商家不可见（**走真 HTTP**）；买家下单能取到期 | 去掉 Port 里的绕域 → 下单拿不到期 → 红 |
| 并发 | 两单同时建同一期只建一行 | 去掉 DuplicateKey 回读 → 红 |
| 幂等 | 同一期取消两次只退一次 | 去掉「已有退款在路上」判断 → 退两次 → 红 |

## 横切约束（每一批都要过）

|---|---|

| 共享工作区 | 未完成的活放分支，不留在工作区；提交用 `git commit -- <路径>` 并核 `--stat` |
