### 为什么又改一次

这是这块的**第三次**决定，写下来是为了下一个人不再改回去：

| 日期 | 决定 | 理由 |
|---|---|---|
| 2026-09-19（v2） | 去掉「已选 / 范围」，详情页不说配送 | 还没决定买就问件数；配送是订单的事 |
| 2026-09-28（v3） | 恢复「已选 / 配送 / 保障」选购卡 | 参照淘宝京东首屏 |
| **2026-09-29（v4）** | **再去掉三行** | 这时消费者**在看货，还没选**：已选是替他做决定，配送在结算 / 订单页确认，保障等售后整块重新设计 |

v4 与 v2 的方向一致，但理由更完整：详情页的职责限定为**展示阶段只回答「要不要买」**；凡是「怎么买、怎么拿、出了问题怎么办」的确认项都放到下单阶段。
