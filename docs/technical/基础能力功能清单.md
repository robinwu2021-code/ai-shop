# 基础能力功能清单

> 基础能力库（`n_common`）承载的公共能力，以及它们在代码里的落点与完成状态。
> 来源：[TDD-基础能力库对齐](TDD-基础能力库对齐.md) §1.1 的八组 + 本轮新增的事件与中间件能力；
> 设计依据 [ADR-067](ADR/ADR-067-异步事件统一走RabbitMQ与发件箱只补提交缺口.md)。
> 状态截至 2026-11-27（v2 @ db01df756）。各业务模块怎么用这些能力（餐饮、商城等走哪些事件），由各模块自己定，不在本清单。

**状态标记**：✅ 已完成（代码与测试在 v2）· 🟡 部分完成 · ⏸ 等决定 · ⬜ 未开始。
“已完成”的能力若还缺真实环境验证，在“验证”列注明。
