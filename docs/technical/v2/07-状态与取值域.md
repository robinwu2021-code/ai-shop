# 07 · 状态与取值域（速查）

> 基座 25 状态 + 4 相位**一个不许行业增删**；行业状态自由加，但必须全射映射到相位。

## 1. 基座状态机

| 状态机 | 迁移图 |
|---|---|
| 主单 | WAIT_PAY→{PAID,CANCELLED,CLOSED} ｜ WAIT_OFFLINE_PAY→{PAID,CANCELLED}（超时按门店配置，台账未结不取消） |
| 子单 | WAIT_PAY→{WAIT_FULFILL, FULFILLING(SERVICE_LIKE), CANCELLED}；WAIT_FULFILL→{FULFILLING,COMPLETED,REFUNDED}；FULFILLING→{COMPLETED,REFUNDED}；COMPLETED→REFUNDED |
| 售后 | APPLIED→{REFUNDING,REFUNDED,REJECTED,CLOSED}；REFUNDING→{REFUNDED,CLOSED}；REJECTED→{ARBITRATING,CLOSED}；ARBITRATING→{REFUNDING,REFUNDED,CLOSED} |
| 收款 | PENDING→{SUCCESS,FAILED}；SUCCESS→REVERSED（仅一次） |
| 占位 Hold | HELD→{CONFIRMED,RELEASED,EXPIRED}；CONFIRMED→RELEASED |
| **工作流相位** | OPEN↔SETTLING→CLOSED；OPEN→VOIDED（final） |

## 2. 行业状态 → 相位映射（全射，契约测试锁死）

| 单据 | 状态 → 相位 |
|---|---|
| 餐饮台账 | OPEN/SETTLING/CLOSED/VOIDED=同名；**MERGED→CLOSED 特化** |
| 美业工单 | CREATED/SERVING/FINISHED→**OPEN 子态**；SETTLED→CLOSED；CANCELLED→VOIDED |
| 美业预约单 | PENDING/CONFIRMED/CHECKED_IN/NO_SHOW/CANCELLED —— **不继承 Engagement，不映射** |
| 餐饮制作行 | QUEUED/HELD/MAKING/READY/SERVED/VOIDED —— **行级内容物，不映射** |
| 零售收银票 | 恒等使用四相位 |

## 3. 取值域常量（表=数据 · 类=代码，各自唯一定义处）

| 常量 | 取值 | 位置 |
|---|---|---|
| `Fulfillments` | STORE_PICKUP · NEIGHBOR_PICKUP · MERCHANT_DELIVERY · EXPRESS · STORE_VERIFY · APPOINTMENT · **DINE_IN**(V2) | shop-base 常量类 |
| `PayModes` | ONLINE · OFFLINE | 同上 |
| `Trait` | SCHEDULED_SERVICE · METERED · PREORDER · BUNDLE · REDEEMABLE · DAILY_PRICED | 代码枚举，type.traits 启动校验 |
| `MeterDimension` | WEIGHT（今） · TIME · DISTANCE（记账） | 同上 |
| `SalesChannels` | DINE_IN · TAKEOUT · DELIVERY · HOME · ONLINE | 待定稿（08 §待确认） |
| `LineKinds` | PRODUCT · FEE · GIFT | 订单域 |
| `PaymentRefTypes` | ORDER · CHECK · WORK_ORDER · CASHIER | 订单域 |
| `AfterSalePolicies` | STANDARD · NO_RETURN · BY_CANCEL_RULE | 商品定义、订单消费 |
| `ResourceTypes` | TABLE · STAFF · SEAT · ROOM · VEHICLE | 资源域 |
| `sys_pay_channel`（表） | +MIXED · CASH · TIMES_CARD · STORED_VALUE 行 | **加行不加码** |
| 能力码 | 见[核心能力清单](../reference/核心能力清单.md)附表 | 开关三态口径唯一判定 |
