## 关键路径与并行

```
A ─┬─▶ 1 ─▶ 2 ─▶ 3 ─▶ 4 ─▶ 5 ─▶ 6
   │                    └──▶ 7（K01–K03 可在 5 中段开始）
0 ─┘（与 A 并行，F01–F08 必须在 2 的 C06 回填之前完成）
```

- **必须串行**：F01/F02 → C06（回填依赖旧解析先正确）；C07 → C08（比对为 0 才读切）；E03 → E06（唯一入口先在，再迁调用方）
- **可并行**：阶段 0 与 A；B05 与 B04；D03 与 E 系列后半；G01 / G02 / G03 三家；H03 与 H01
- **多会话协作**：同一时刻只让一个会话改 `MerchantPortImpl` / `PaymentLedgerServiceImpl` / `SettlePortImpl`（三处高冲突文件）
