02 — Geometry

几何：六条规则管住全部形态

改任何一条，改的是整个体系。这也是它区别于「随便一个 H」的地方。

母题 Motif · 一道弧线

取「虹」的字义。扁圆弧（竖半径 ÷ 横半径 = arc_flat 0.65；原为正半圆 1.00，2026-08-20 压扁 —— 横向占位不变，纵向省 31%），固定在字符正上方。H 档没有弧线。

字形 Letterform · H 与 X 同源

笔画等宽 0.267 × 字高、直角切口。X 按 H 的参数反推。中文用思源黑体 Bold，不重绘。

容器 Container · 四态

透明 → 圆章 → 圆角方章（圆角 0.275 × 边长）→ 镂空。字形与弧线参数不随容器变化。

层级 Hierarchy

单字符 → 双字符 → 词标 → 全称 → 母品牌。场合越小，层级越低。

分隔符 Separator

· 表并列，｜ 表分组。域名全小写。

颜色 Color · 四种

主色 / 墨 / 反白 / 主色描边。不用渐变，不用灰。

05 — Platforms

各端制版

母版为 1024×1024 满幅方章：底色出血到边，弧线与字符按参数缩放，圆角交给平台遮罩——自己预切会二次圆角，边缘被削一圈。

用途尺寸做法
App Store / Play1024 × 1024满幅底 + HX。不自带圆角、不留白边、不透明——iOS 带 alpha 通道直接拒
iOS 桌面180 / 120由 1024 母版导出，圆角交系统遮罩
Android 自适应432 前景 / 背景前景放 HX（占 66%），背景层纯色。H 四角距中心须 < 33，否则圆形遮罩削角
小程序方形144 × 144满幅底 + HX，微信端自动裁圆
小程序中文版144 × 144「虹」方章，弧线收窄至 0.40 × 边长
通知 / 状态栏76 / 48去弧线，仅 H，保证 16px 可辨
favicon48 / 32 / 16H 圆章；16px 用纯色 H，无弧线

最小尺寸：方章 28px · H 圆章 16px · 字标字高 20px。字标小于 20px 时改用「虹」方章或圆章。

06 — Product UI

界面用色

C 端 / B 端新增 brand 皮肤并设为默认，其余八套皮肤一个不动——换肤是产品既有能力，也是「虹」这个名字的由来。运营端例外，见下。

c-app / b-app · brand 皮肤

light #e1251b / dark #ff5a4d；--sh-on-primary 由生成器按对比度自动选（浅色档白、深色档墨），不手填。

改 tokens.ts → npm run gen:skins → npm test。base.css 是生成物，手改会被覆盖。

ops-web · 品牌红不进 --primary

运营端 --primary 保持近黑 #18181b。品牌红只出现在左上角标识、登录页、页脚署名三处。

为什么：运营端 --destructive 是 #d92d20，与品牌红肉眼几乎同色。密集表格里主按钮和删除按钮同色，是会真出事故的。

主色是红，危险色也是红——这条必须处理

颜色不能是唯一的信息载体（WCAG 1.4.1）。在红色主色的产品里，这条从「建议」变成「必须」。

危险操作：描边按钮 + 墨字 + 明确动词

两个按钮形态不同，不靠颜色区分。

两个红并排：用户分不清确认和删除

红实心只留给二次确认弹窗——那时页面上不会同时出现主色按钮。

08 — Misuse

禁止事项

每一条后面都跟着「防住什么」。防不住任何东西的规则，多半是可以删掉的。

不动几何

不拉伸、不倾斜、不改圆角比例、不换弧线形状或角度。参数一变，全体系失去可复现性。

不加效果

不加渐变、阴影、外发光、描边、立体、纹理。渐变无法算对比度，也无法单色印刷。

不改结构

弧线不脱离「虹」或 HX 单独使用，不移到字标右侧或下方。它是字义符号，不是装饰条。

不改配色

底色只用主色 / 墨 / 反白。不用灰底红字（对比不足），不在照片上直接放标识。

不侵安全区

四周 0.25 × 边长内不放任何文字、图形或裁切边。

不在代码里写死色值

一律 var(--sh-*) / var(--hx-*)。.vue 的 <style> 里出现 hex 会被规范测试拦下。
