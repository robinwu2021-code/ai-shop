3. **[P2] Calculate lease and retry deadlines per item, using completion time for backoff.** `backend-plugins/shop-industry-beauty/beauty-core/src/main/java/ai/neargo/shop/beauty/service/impl/ReceptionRecovery.java:24` captures `now` once for the whole scan; line 27 uses it for every 30-second lease and line 44 uses it again for all 30/60-second retry times. Reproduction: a 50-item scan takes over 30 seconds because earlier reconcile calls are slow. Targeted missing test: `WalkInRecoveryIT#slowBatchRetainsPerItemLeaseAndCompletionBackoff`, using a controllable clock, with later-item lease and failure retry assertions relative to actual claim/completion.

4. **[P2] Do not convert explicit owner authorization failures into release-required PENDING.** `backend-plugins/shop-industry-beauty/beauty-core/src/main/java/ai/neargo/shop/beauty/service/impl/ReceptionCoordinator.java:210` catches every RuntimeException from `appointments.releasedHold` and returns a pending result.
