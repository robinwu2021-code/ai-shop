Self-review completed by static rereading and targeted source checks:

Any later same-task/unit retry requires authoritative sealed no-effect proof, fresh authority and an explicit M4/M5 writer.

A valid late APPLIED result after suspension records actual resource effect as STARTED_SUSPENDED; it proves no human service, participation, start acknowledgement, performed quantity or current permission.
- The forward/reverse bindings include the actual source line, ordinal, permanent task, grant, attempt, source revision/hash and frozen plan. A resource-group match alone cannot substitute for unit/task proof. Human and ORIGINAL routes cannot substitute for one another.
- Existing manual hash inputs and source observation behavior remain intact. Grant-only transitions do not bump them or subtract quantity a second time. The shared-reader extraction, old counter hash wrapper and original Facts component order are explicit compatibility obligations.
- The actual manual progress/suspension path and generic cancel/refund/after-sale/completion writers are listed with source methods. Existing appointment guards prevent their legacy group release/replacement routes from reaching an opened work order; no unnecessary appointment implementation edits are proposed.
- Corrected the preparation method names to the actual `fromAppointment`, `unassigned`, and `verifyLocked`; avoided unconsumed M4/M6 API shells. The proposed ORIGINAL digest has no self-reference and requires typed strict codecs. New schema checks run at capability use, not through a broad constructor/startup query.
- Genuine asset SERVICE_USE remains C11. Manual receipt/grant state never creates paid provenance, Pay callback behavior, settlement/refund protection or generic managed completion.
