#
# 逐条读完 CSS 之后，这 10 处其实是**五种东西**，判据把它们收成了一类：
#
#   开关圆点 ×2   address「设为默认」/ order-confirm「使用积分」→ sh-switch（上一笔）
#   chip     ×1   store 的类目行 —— 而它挂的 `pb-tag` **全仓没有定义**：
#                 未选中的是一行裸文字、选中的是个**直角**绿方块，
#                 而同屏「已认证」「-25%」都是正经药丸。判据说它「选中态自画」，
#                 其实错得更早：连未选中态都没画出来。→ sh-chip + --primary
#   分段块   ×5   me ×2 / after-sale.reason / goods.spec/.date/.time
#                 → **新建 `.sh-seg`**。五处内边距没有两处相同
#                 （22/0、20/30、20/32、18/28、16/26），同一个 App 里做同一件事。
#   选项卡   ×1   after-sale 的类型（两行、描边）→ sh-option
#   死样式   ×1   group 的 `.tier` —— 多档拼团改成单档之后，模板里一处都没有了，
#                 7 条规则留在文件里，判据照样把它算成欠账
#
# 剩下两处（community 的自提点行、pay 的支付方式行）**不是 chip，是列表行** ——
# 它们的选中态同样铺主色，但收进 chip 会把一整行的布局弄没。

# 不再算「有件不用」。收窄后拿一个手画 chip 探过针，确认它仍然会报（不是变成恒绿）。
