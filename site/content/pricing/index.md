## 到期是降级，不是关店

```yaml
type: table
tone: dark
```

| 到期 | 先给 7 天宽限期，能力全保留 |
|---|---|
| 宽限期结束 | 超额门店转只读：不接新单，但**历史订单可查、未完成的单照常核销** |
| 哪几家转只读 | 保留默认门店，其余按建店时间倒序 |
| 补缴之后 | 原样恢复，门店和授权都不用重配，数据不删 |
| 升档 / 降档 | 升档立即生效；降档到期时生效 |

降级前提醒三次：到期前 7 天、前 1 天、当天，并写明哪几家店转成了只读。
