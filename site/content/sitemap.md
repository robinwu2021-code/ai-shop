# 站点地图

> 每一页只做一件事。**一页两个目的，等于没有目的。**
> 「转化目标」那一列决定该页的主 CTA —— 页面上其余按钮都是次级的。

---

## 一、结构

```
/                          首页 · 支不支持我这种店 · 用着方便吗 · 多少钱
│
├─ /scenarios/             支持哪些店 · 六类入口
│   ├─ /scenarios/fresh/          生鲜果蔬
│   ├─ /scenarios/convenience/    便利 · 日用 · 烘焙
│   ├─ /scenarios/service/        到店与上门服务
│   ├─ /scenarios/pickup-point/   社区自提点
│   ├─ /scenarios/chain/          多门店与连锁
│   └─ /scenarios/own-brand/      自有品牌经营
│
├─ /how-it-works/          怎么开店 · 三步 + 要准备的材料
├─ /pricing/               收费与套餐 · 两笔钱与三个档位
│   └─ /capabilities/      功能总览（附录 · 销售支持，不进主导航）
├─ /mini-program/          自有品牌小程序 · 加购项
├─ /download/              下载 · 顾客端与商家端两组入口
└─ /privacy/ /terms/       隐私政策 · 用户协议（占位：正式文本随 App 版本发布）
```

## 二、每页的定位

| 页面 | 受众 | 这页回答什么 | 转化目标 |
|---|---|---|---|
| `/` | 所有来访商家 | 「支不支持我这种店？用着方便吗？」 | **免费开店** |
| `/scenarios/` | 不确定自己算哪类的 | 「我这种店支持吗？」 | 点进对应类型 |
| `/scenarios/*` | 明确业态的店主 | 「我会怎么用它？」 | **免费开店** |
| `/how-it-works/` | 已经动心，想知道要做什么 | 「从现在到收到第一笔钱，我要干什么？」 | 免费开店 |
| `/pricing/` | 在比价 | 「一共几笔钱？不续费会怎样？」 | 免费开店 / 联系报价 |
| `/capabilities/` | 销售对话中的商家、内部话术 | 「到底包含哪些功能？」 | 回到 `/pricing/` |
| `/mini-program/` | 想要自己品牌的 | 「独有的是什么，共用的是什么？」 | 咨询开通 |
| `/download/` | 顾客与商家 | 「我该下哪个？」 | 下载对应的那一端 |

> 这是**唯一一页混两种受众**的地方，而且是有意的：两个 App 名字相近，
> 商家下成顾客端是常见的第一次失败。与其各开一页让人自己找对，不如并排放着让他看清区别。
| `/privacy/` `/terms/` | 访问者、应用商店审核 | 「本站收不收集信息？官网写的算不算数？」 | — |

## 三、导航

**顶栏**（五项，与上表的前五行对应）

```
支持哪些店  ·  怎么开店  ·  收费与套餐  ·  自有小程序  ·  顾客入口
                                              [免费开店]
```

- 「支持哪些店」跳 `/scenarios/`，**排第一** —— 它回答商家的第一个问题
- 「功能总览」**不进顶栏**：它是附录，进了顶栏就会把宣传站变成说明书
- 主 CTA 全站统一四个字：**免费开店**。
  国内同类招商页普遍把「免费」放进按钮里，因为商家最先要确认的就是这一点；
  而它属实 —— 开店本身不收费。**只许这一种写法**：同一个动作写成「立即入驻」
  「马上开店」「申请入驻」，商家会以为它们通向不同的地方

**页脚**

| 列 | 内容 |
|---|---|
| 店铺类型 | 生鲜果蔬 · 便利日用 · 到店服务 · 社区自提点 · 多门店 · 自有品牌 |
| 产品 | 怎么开店 · 收费与套餐 · 功能总览 · 自有小程序 |
| 顾客 | 下载 App · 微信小程序 |
| 关于 | 隐私政策 · 用户协议 · 联系我们 |

> 两个法务页是**占位**：本站不收集信息这一条是实的，
> 而入驻协议与 App 隐私政策的正式文本随各自版本发布 —— 页面明写了这一点，
> 不用一段含糊的条款去冒充它。

## 四、页与页之间怎么走

```
首页 ──「这些店都能开」──→ 类型页 ──→ 免费开店
  │                                  │
  │                                  └──→ 价格与套餐 ──→ 功能总览（想看细节的少数人）
  │
  ├──→ 怎么开店（还在犹豫流程的）
  └──→ 自有小程序（已经有品牌的）
```

**每个类型页的末尾只放两个出口**：免费开店（主）、看价格（次）。
放第三个出口的代价是读者在这里停下来做选择，而不是往下走。

## 五、暂不做

| 页 | 为什么 |
|---|---|
| 关于我们 / 团队 | 商家不因为这个入驻。等有融资或资质背书再说 |
| 客户案例 | **一个真实案例都还没有**。编造案例是最快毁掉信任的方式 |
| 博客 / 帮助中心 | 帮助中心属于已入驻商家，应该在 B 端里，不在宣传站 |
| 数据大屏 / 覆盖地图 | 数字未到位（见内容契约 §六 红线 3） |
