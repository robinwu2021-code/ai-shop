## 三步

```yaml
type: timeline
```

1. **提交申请** —— 手机号登录即注册。选行业，再选用什么身份开：
   **个人（不用执照）** / 个体户或公司（传执照）。可勾选「本店同时作为自提点」。
2. **平台审核** —— 人工审核。驳回会写明缺什么，在原页补齐重提，不用重填。
3. **上架经营** —— 商品过审后是下架状态，**什么时候开卖你自己点**。

## 收款要单独申请一次

```yaml
type: prose
tone: dark
```

**审核通过就能上架、能接单；但要收到钱，还得单独交一次收款申请。**

两件事分开办。收款没通过之前，工作台会一直列着你还缺什么。
个人身份开的店，钱进你的微信零钱，不用办对公账户；几家店可以分别绑定。

## 要准备的材料

```yaml
type: table
```

| 用个人身份开 | 手机号 · 身份证。**不用营业执照，不用对公账户** |
|---|---|
| 有个体户执照 | 营业执照 |
| 有公司执照 | 营业执照 · 对公账户 |
| 特定品类 | 按类目要求的资质（如药房） |

能用哪种身份由行业决定 —— 选完行业，不允许的那几种会直接变灰，不会让你填完才被拒。
