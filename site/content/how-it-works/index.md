## 三步

```yaml
type: timeline
```

1. **提交申请** —— 选择行业，再选择开店身份：个人 / 个体工商户 / 企业。可勾选「本店同时作为自提点」。
2. **平台审核** —— 人工审核。驳回会写明缺少项，可在原页补齐后重新提交。
3. **上架经营** —— 商品审核通过后为下架状态，**由商家自行决定何时开售**。

## 收款需单独申请一次

```yaml
type: prose
tone: dark
```

**审核通过即可上架与接单；收款需单独提交一次申请。**

两件事分开办理。收款未通过前，工作台会持续列出待补项。
个人身份开设的门店，货款进入微信零钱；多家门店可分别绑定。

## 常见问题

```yaml
type: faq
```

### 审核需要多久？

人工处理。表单本身约十几分钟填写完毕，审核时长不作承诺。

### 上架后无人下单？

取决于服务范围：申请覆盖了哪些小区，仅那些小区可见该门店。

### 可否先行试用？

免费版一家门店长期免费，单店功能完整。付费档另有 {{plan.trialDays}} 天免费试用。
