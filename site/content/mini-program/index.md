## 哪些归你，哪些共用

```yaml
type: table
columns: 2
```

| 归你独有 | 与虹选共用 |
|---|---|
| 小程序名称、图标、招牌 | 商品与库存 |
| 入口与二维码 | 订单与拆单 |
| 首页装修 | 履约（自提 / 自送 / 快递 / 核销 / 预约） |
| 顾客名单 | 售后与评价 |
| 自己的活动 | 结算与费率 |
| | 员工与权限 |

一套商品、一套订单，不用两边各录一遍。

## 上架我们陪着走

```yaml
type: prose
tone: dark
```

注册公司 → 小程序认证 → 选类目 → 配域名 → 提审 → 发布。

**关键在类目**：自己卖自己的货算「自营」，**不用办 ICP 经营许可证（EDI）**。
平台型才要，那一项通常 2–6 个月，而且个人身份办不了。

其余是标准流程：公司执照、对公账户、微信认证（官方 300 元/年，以微信公示为准）、域名与备案。
清单给你，能代办的代办。

## 常见问题

```yaml
type: faq
```

### 和入驻虹选冲突吗？

不冲突，同一批货，两个入口。

### 顾客算谁的？

从你的小程序进来的顾客，名单归你。

### 多少钱？

按年计费，现阶段不公开标价 —— 门店数和用量不同报价也不同，联系我们聊。

### 能改下单页样式吗？

首页装修可以自定义；下单、支付、履约这些流程页与虹选共用，不做单店定制。
