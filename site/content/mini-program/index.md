## 开通流程

```yaml
type: prose
tone: dark
```

注册公司 → 小程序认证 → 选类目 → 配域名 → 提审 → 发布。

**关键在类目**：自营商品属于「自营」类目，**无需办理 ICP 经营许可证（EDI）**。
平台型才需办理，通常 2–6 个月。

其余为标准流程：公司执照、对公账户、微信认证（官方 300 元/年，以微信公示为准）、域名与备案。
提供完整清单，可代办部分由我们代办。

## 常见问题

```yaml
type: faq
```

### 与入驻虹选是否冲突？

不冲突，同一批商品，两个入口。

### 顾客归属如何划分？

从自有小程序进入的顾客，名单归商家。

### 费用如何计算？

按年计费，现阶段不公开标价 —— 门店数与用量不同报价不同，可联系我们。

### 下单页样式可否修改？

首页装修可自定义；下单、支付、履约等流程页与虹选共用，不做单店定制。
