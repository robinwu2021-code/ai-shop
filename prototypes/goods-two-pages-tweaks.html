商品两页的微调

大布局不动：列表还是「搜索 → 状态页签 → 商品卡 → 悬浮新建」，编辑还是一页几张卡往下排。只动积木与细节，让它和营销那几页（活动、优惠券、建活动、建券）说同一种话。以生成版规范 规范-字体 / 版面 / 组件 为准，原型里的每个元素都对得上一个真类名。

五

明确不动的

列表：搜索框、七个状态页签、「图 + 名 + 价/库存」加下排按钮的两段卡、右下悬浮新建、「更多」的收纳规则。悬浮新建不挪进底部通栏 —— 全仓只有商品列表是带底部菜单的一级页，通栏叠在底部菜单上会吃掉 130px。

编辑：八张卡的顺序与内容、「标签在上、输入在下」的表单形态、类目与规格的 chip 选择、图片上传。营销的编辑页用 sh-cells（标签左、值右），那是另一种布局，不在这次范围。

数据与接口：一个都不动。

六

顺带查出来的一处闸门盲区

「可点元素不小于 88rpx」这条闸门只扫页面自己 CSS 里同时写死 width 与 height 的类。靠 padding 撑开的库件（sh-btn--sm、sh-chip）它一个都看不到 —— 所以商品列表那三颗 30px 的按钮闸门全绿，改之前 25px 的 .mini 也全绿。第 3、7 条修的就是它漏掉的那一类。闸门本身要不要补，是另一件事，这份不动它。
