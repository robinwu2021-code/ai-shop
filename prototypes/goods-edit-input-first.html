商品编辑页：快速识别录入 · 提交历史

接着 商品两页的微调（已落地）与 规格原型（已落地）画，页面骨架与参数布局一律不动：卡的顺序、卡内标题、sh-actionbar 贴底保存、页顶 sh-notice--warning 草稿提示、价格的 sh-seg 切换，全照现在。没改的卡在图里用「⋯ 省略 ⋯」一行带过。这版只加两件事：① 第一张卡「快速录入」撑开成能用的输入区并配确认层；② 新增提交历史。十二屏。

一

动了什么、没动什么

位置这版
没动卡的顺序与卡内标题基本信息 → 图文详情 → 类目与配送 → 规格 → 商品参数 → 价格 → 库存 → 商品编码，一字不改
没动保存条与草稿提示仍是贴底 sh-actionbar（取消 / 保存）＋ 页顶 sh-notice--warning「在售中 · 保存为草稿，发布后生效」
没动价格卡 / 商品参数卡价格仍是 sh-seg 三选一 + 每档一行；参数仍是「一行一个维度 · 一排 chip · ＋加值」
动第一张卡「快速录入」由一行入口 → 撑开成输入区：多行输入 + 相册 / 拍照 / 压缩包 + 一颗「识别」。识别完收回成一行
加识别之后确认层：首次在页内占满一屏，追加 / 改口在 sh-sheet 只给变更。确认前一个字不落表单
加识别填过的字段值后面挂一枚「识别」sh-chip（tint，不改行结构）；长按可单字段重认
加压缩包导图按目录名与文件名数字分主图 / 详情，分不准的进图位确认可拖动
加提交历史（新）导航右侧「历史」→ 逐版列表（提交 / 发布时间 · 改了哪几项 · 谁）→ 某版的字段级变更 → 就地发布

提交历史：改了什么 · 谁提的 · 什么时候发的

在售商品的每次保存都是一版草稿，发布才换线上（这是微调稿里「保存为草稿，发布后生效」那条的另一半）。此前这条轴上只看得见「当前有没有草稿」，发过什么、什么时候发的、改了哪几项，一概查不到。

六

落地要补什么

屏现在有的要补的
02 — 05 识别录入/biz/goods/parse-text（规则 + LLM 文字抽取，已上线）、/biz/goods/describe、restrictedRegions 已落库并两端下发确认层本身（勾选 / 原文片段 / 只落勾中项）；图像识别也按标准参数清单回（见 prompt 方案）
06 — 07 多次输入applyParamPicks 已放开「识别值可不在模板」变更集语义（add / update / remove + evidence）；单字段重识别的作用域参数
08 图位classifyZip（目录名 + 文件名数字排序）分不准时调模型的兜底；图位确认页
09 — 12 提交历史prd_goods_draft 只存当前一份草稿；PublishPreviewVO.DiffRow(field,label,before,after) 已有字段级差异；发布走 publishDraft / swapFromDraft新表（如 prd_goods_revision）：一次提交一行 —— 版本号 · payload 快照 · 变更摘要 · 提交人/时间 · 发布人/时间 · 状态（草稿/线上/已替换/驳回）· 来源（手填 / 快速录入 + 原话）

提交历史是唯一需要新存储的：现在发布不留痕，发完就只剩「线上是什么」，不知道「发过什么」。差异的形状不用重造，DiffRow 就是现成的。
