商品编辑页：加一层快速识别录入

页面骨架与参数布局一律不动：八张卡（快速录入 / 基本信息 / 类目与配送 / 规格 / 商品参数 / 价格 / 库存 / 商品编码）的顺序、每张卡里的行、参数区的 chip 排布，全照现在。这版只做一件事：把本来就在第一位的「快速录入」那一行撑开成能用的输入区（文字 + 加图 + 压缩包 → LLM 识别），并给识别结果配上确认层。八屏。

一

动了什么、没动什么

位置这版
没动八张卡的顺序与展开方式一字不改：基本信息 → 类目与配送 → 规格 → 商品参数 → 价格 → 库存 → 商品编码，仍是全展开往下排
没动商品参数卡的布局仍是「一行一个维度 · 一排 chip · ＋加值」，TEXT 维度仍是一行输入框；加参数仍在标题行右边
没动价格 / 库存 / 规格 / 编码各卡行、控件、顺序都照旧
没动底部保存条仍是「存草稿 / 保存」（在售商品保存后弹「立即发布」那套也不变）
动第一张卡「快速录入」由一行入口 → 撑开成输入区：多行文字框 + 相册 / 拍照 / 压缩包 + 一颗「识别」。位置没变，还是第一张
加识别之后确认层：首次在页内占满一屏，追加 / 改口在弹框只给变更。确认前一个字不落表单
加被识别填过的字段值后面挂一枚「识别」小标（只多一个标，不改行的结构）
加压缩包导图按目录名与文件名数字分主图 / 详情，分不准的进图位确认可拖动
