商品编辑页：快速识别录入 · 提交历史

页面骨架与参数布局一律不动：八张卡的顺序与展开方式、商品参数卡的 chip 排布、价格/库存/规格/编码各卡、底部保存条，全照现在。这版加两件事：① 把本来就在第一位的「快速录入」卡撑开成能用的输入区（文字 + 加图 + 压缩包 → LLM 识别）并配确认层；② 新增提交历史——每次改了什么、谁提的、什么时候发布的，逐版可查。十二屏。

一

动了什么、没动什么

位置这版
没动八张卡的顺序与展开方式一字不改：基本信息 → 类目与配送 → 规格 → 商品参数 → 价格 → 库存 → 商品编码，仍是全展开往下排
没动商品参数卡的布局仍是「一行一个维度 · 一排 chip · ＋加值」，TEXT 维度仍是一行输入框，「加参数」仍在标题行右边
没动价格 / 库存 / 规格 / 编码各卡、底部保存条行、控件、顺序都照旧（在售商品保存后弹「立即发布」那套也不变）
动第一张卡「快速录入」由一行入口 → 撑开成输入区：多行文字框 + 相册 / 拍照 / 压缩包 + 一颗「识别」。位置没变，识别完收回成一行
加识别之后确认层：首次在页内占满一屏，追加 / 改口在弹框只给变更。确认前一个字不落表单
加被识别填过的字段值后面挂一枚「识别」tint 标（只多一个标，不改行的结构）；长按可单字段重认
加压缩包导图按目录名与文件名数字分主图 / 详情，分不准的进图位确认可拖动
加提交历史（新）导航右侧一个「历史」入口 → 逐版列表（提交时间 / 发布时间 / 改了几项 / 谁）→ 某一版的字段级变更 → 待发布的那版就地发布

五 · 09 — 12

提交历史：改了什么 · 谁提的 · 什么时候发的

在售商品的每次保存都是一版草稿，发布才换线上。此前这条轴上只看得见「当前有没有草稿」，发过什么、什么时候发的、改了哪几项，一概查不到。这四屏把它补上。

六

落地要补什么

屏现在有的要补的
02 — 05 识别录入/biz/goods/parse-text（规则 + LLM 文字抽取，已上线）、/biz/goods/describe、restrictedRegions 已落库并两端下发确认层本身（勾选 / 原文片段 / 只落勾中项）；图像识别也按标准参数清单回（见 prompt 方案）
06 — 07 多次输入applyParamPicks 已放开「识别值可不在模板」变更集语义（add / update / remove + evidence）；单字段重识别的作用域参数
08 图位classifyZip（目录名 + 文件名数字排序）分不准时调模型的兜底（prompt 方案 Prompt 1）；图位确认页
09 — 12 提交历史prd_goods_draft 只存当前一份草稿；PublishPreviewVO.DiffRow(field,label,before,after) 已有字段级差异；发布走 publishDraft／swapFromDraft新表（如 prd_goods_revision）：一次提交一行 —— 版本号 · payload 快照 · 变更摘要 · 提交人/时间 · 发布人/时间 · 状态（草稿/线上/已替换/驳回）· 来源（手填/快速录入 + 原话）。发布时写一行、过审/驳回回填状态

提交历史是这四屏里唯一需要新存储的：现在发布不留痕，发完就只剩「线上是什么」，不知道「发过什么」。差异的形状不用重造，DiffRow 就是现成的。
