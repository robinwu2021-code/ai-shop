商品编辑页：输入占主位

同一页现在有八张卡（快速录入 / 基本信息 / 类目与配送 / 规格 / 商品参数 / 价格 / 库存 / 商品编码），全展开往下排，填一件货要滚三四屏。这版只改三件事：输入搬到页顶主位、填过的卡收成一行摘要、识别结果一律先确认再落（首次在页内、追加在弹框）。八屏。

一

改的是什么

位置现在这版为什么
页顶「快速录入」是第一张卡里的一行小字入口输入区占主位：新建时展开（文字 + 加图 + 压缩包），编辑时收成一条细条商家手里本来就有一段群消息和几张图，先收下它比先问他类目省事
八张卡全部展开往下排，填一件货滚三四屏填过的卡收成一行摘要（价格 ¥12.80 · 库存 200 · 限购 2），点开才展开编辑一件在售商品时，大多数卡他只是路过，不该每次都铺开
还差什么只有点保存时才被挡下来，提示在底部一闪页顶一条待填条：还差 2 项 · 库存 · 类目，点一下跳到那张卡把「还不能保存」提前到进页面就看得见，而不是按了保存才知道
商品图图在第二张卡里，只能一张张加三个入口并排（相册 / 拍照 / 压缩包），长按拖排，首张标「封面」压缩包是真实场景（供应商给的图包），拖排是因为详情长图的顺序就是展示顺序
商品参数第五张卡，只能一项项点开选识别落的项挂「识别」小标；标准参数点 chip、自由文本直接填、每条可删参数是最常被识别出来的一类，也是最需要让人一眼看出「这是机器填的」的一类
识别结果文字边输边静默改属性，图识别直接覆盖名称 / 详情先进勾选确认：字段 · 值 · 原文片段。首次在页内，追加 / 改口在弹框错填比不填贵，而商家不易察觉——价格、限购这类更是
再补一句要退回去重新识别，整段重来，覆盖已填细条常驻页顶；第二次起只给变更（新增 / 旧值→新值 / 删除），没提到的不动「改成12.8元」只该动价，不该把他手填的库存冲掉
二 · 01 — 02

整页：现在 vs 这版

左边是现在的编辑页（八张卡全展开）；右边是这版的首屏（新建态）。页里的节一个没删，只是换了顺序与展开程度。

三 · 03 — 04

这版的编辑页全貌（编辑一件在售商品）

识别确认完、或者打开一件已有商品时的样子。上下两屏拼起来是整页：细输入条 → 待填条 → 商品图 → 其余七节的摘要行 → 保存条。
