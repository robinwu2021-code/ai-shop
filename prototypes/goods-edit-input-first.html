商品录入：输入占主位

一件货最少要做几下：贴一段话或丢几张图 → 勾一遍 → 保存。所以把「输入」搬到首屏主位，表单退到后面；识别结果只当草稿，首次识别在页内确认（那时识别就是主任务），追加与改口在弹框确认（不把人赶出表单）。支持多次输入、只给变更、单字段重识别。七屏。

一

改的是什么

位置现在这次为什么
新建首屏先选类目，再一页卡往下填（名称 / 图 / 价 / 库存 / 规格…）一个输入区占主位：一段文字 + 加图 + 压缩包，一颗「识别并填表」商家手里本来就有一段群消息和几张图，让他先交出来，比先问他类目更省事
识别结果文字边输边静默改属性，图识别直接覆盖名称 / 详情一律先进勾选清单：字段 · 值 · 原文片段；确认后才落表单错填比不填贵，而商家不易察觉——价格、限购这类更是
确认在哪（没有确认层）首次在页内（主任务）；追加 / 改口在弹框（局部更新，不离开表单）首次识别时页面上还没别的东西，占满一屏最省；填到一半时弹框才不丢上下文
再补一句要退回去重新识别，结果整段重来识别后输入区收成常驻一条细输入条，随时补话 / 加图商家是想起来一点说一点，不是一次说全
第二次识别整份结果重算，覆盖已填只给变更：新增 / 旧值→新值 / 删除，没提到的字段不动「改成12.8元」只该动价，不该把他手填的库存冲掉
某一项错了只能手删重填，或整段重识别点那一行 →「重识别这一项 / 粘一段只认它 / 手填」一个字段错了不必整段重来
压缩包图按目录名分主图 / 详情，分不出就全当主图分不出时才问模型，结果仍进图位确认，可拖动改位置规则能办的不花钱；图位错了商家一眼看得见，给他改的手把
二 · 01 — 03

第一次录入：输入 → 识别 → 页内确认

这三屏是主线。注意第 1 屏上没有任何表单：类目、价格、库存都不在这儿问，它们是识别之后的结果，或者是确认完之后补的。

三 · 04 — 06

多次输入 · 只给变更 · 局部重识别

确认完就进表单，但输入不退场：它收成页顶一条细条，随时能再说一句。第二次起只给变更，弹框确认，不把人赶出表单。
