C 端门店化：店铺页、门店门户、分享、商品详情 v4

C 端展示与交互的单位从「主体」换成「门店」。四件事：店铺页按「我的店 → 附近」排；门店主页做成独立的门店门户；分享收成一个入口、落到具体那家店；商品详情去掉还没到时候的「已选 / 配送 / 保障」。十二屏，末尾附取舍表与契约变更。

01 — 02

店铺页：先「我的店」，再「附近」

一行是一家门店，不是一个主体。同一个主体下的四家店各占一行、各叫各的名字。「平台推荐」一块移出（2026-09-29 拍板），运营想推的店改走首页位。

03 — 07

门店门户：一家店自己的地盘

取代现在的两个页面（扫码进的 pages/store 与列表进的 pages/merchant）。所有入口进来都是同一个门户、按 storeNo 取数。结构：门头 → 店招 → 公告 → 领券 → 标签页（商品 / 评价 / 店铺）。商品用「左分类 · 右列表」，逛完在底栏直接结算。

08 — 09

分享：一个入口，两条路

门户与商品详情都只有一颗「分享」。点开是面板：发给朋友（微信转发）/ 生成海报（发朋友圈、存相册）。海报不再单独占一个入口——它的目的就是分享（2026-09-29 拍板）。

10 — 11

商品详情 v4：展示阶段只回答「要不要买」

这时消费者还在看货，没有选规格、没有下单。「已选」「配送」「保障」三行都属于下单阶段：规格在点「加入购物车 / 立即购买」后的面板里选；配送方式、到货时间在订单页确认；售后说明将来作为完整的一块重新设计（2026-09-29 拍板）。
