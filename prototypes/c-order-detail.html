订单详情：一眼看懂「货到哪、我该做什么」

重排订单详情页，参考京东/淘宝与 B 端 App 的物流卡。四态各一屏：待付款 / 待发货 / 已发货(含物流) / 已完成。核心是把「状态 + 物流 + 收货」提到最顶，操作沉到底部常驻条。

四个状态，同一套骨架

从上到下恒定：① 状态头（大字状态 + 一句「接下来」）② 物流卡（已发货才有，整卡可点进轨迹）③ 收货地址 ④ 店铺 + 商品 ⑤ 订单信息（单号/下单时间，可复制）⑥ 金额 ⑦ 底部操作条（随状态变）。
