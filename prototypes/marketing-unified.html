营销：活动统一模型

一个模型覆盖所有玩法：商家填一张表、确认发布；玩法是表里的一个字段。团是规则开出来的实例，单独一页。拼团与社区集单并存：拼团拉新，集单以销定采。券、平台活动与 C 端露出都用同一套约定。三十七屏。

约定

全部屏共用的七条

场合只用这一种
新建 / 主操作底部操作栏：左次按钮、右主按钮。导航栏右侧不放任何东西
列表顶部下划线分栏筛状态；卡片三行：名称 + 状态 / 一行信息 / 一行指标；卡内不放按钮，操作都在详情页
表单与只读信息分组列表，左标签右值；同一个组件，只读时去掉 ›
互斥选项≤ 3 个用分段控件；> 3 个用选择行（›）进下一级
开关只用于是 / 否
状态标签绿 = 进行中 / 已成功，黄 = 需要处理，灰 = 其它。玩法类型不做标签，写在信息行里
文字标签 ≤ 4 字，按钮是 2–4 字的动词；每屏最多一条提示，且只在会出错的地方出现
